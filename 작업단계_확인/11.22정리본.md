## 1. 현재 결론

11.20 정리본 8장 "다음 순서" 1~5번(Codex 파일 통합, CSV 반영, 테스트 재실행, 3→4단계 전달, 오류 기록)은 끝났다. Codex 파일은 이 PC로 가져오지 못해 정리본 4장 "통합할 때 고칠 것"대로 **다시 만들었다.** 3→4단계를 에이전트로 세 번 돌려(조건 세트 A · B, 사람1 수정 요청 반영 확인) 지침을 보완했고, 최신 3 · 4단계 지침 · 홍보문구 스킬 · 테스트 자료는 **PR #8로 integration/stage-1-5에 merge**됐다. 남은 큰 결정은 **G5 · G17(통계 표현 · 문구에 수치)** 이고, 그 뒤 통합 버전에서 A · B를 다시 돌린다.

## 2. 확정된 기본 조건 (11.20에서 바뀐 것 굵게)

- MVP 지역: 대구광역시 중구 (동구는 선택지). 담당자 범위: 관광 + 홍보, 문화 부서 제외
- 번역 우선순위: 일본어 + 영어 (조건 세트 A). 중국어 번체는 두 번째 실행(조건 세트 B)
- 코스 시작: 1일차 동대구역 10:00 / **코스 종료: 2일차 대구근대역사관 14:00 (관람 후 종료) — 시범 확정**
- 1일차 순서: 근대골목 → 서문시장(점심) → 김광석길 → 저녁 → (토요일) 서문시장 야시장 → 숙박 반월당역 권역
- **식사 방식: 점심 · 저녁 · 2일차 점심 모두 자유식** (사람1 수정 요청 반영). 저녁 추천 후보는 산호찜갈비 · 봉산찜갈비(순서는 순위 아님). 2.6에서 고른 산호찜갈비는 실행 사례이고 고정 구성이 아님
- **2일차 오전: 종료 장소로 바로 이동 (담당자 선택).** 에이전트가 대신 고르지 않는다 (세 가지: 후보로 일정 추가 / 자유시간 / 종료 장소로 바로)
- **평일 밤 칸: 비우기** (서문시장 야시장 월~목 운영 안 함)
- **식비 포함 · 운영 방식(단체 동행형 / 개별 이동형): 미정**
- 시범: 외국인 관광객 2명 · 1박, 평일 2027-03-10(수) · 토요일 2027-03-13(토)
- 숙박: 순위 없이 숙박 권역(반월당역)만. 예산 평일 10만 원 이하 / 주말 A 10만 원 이하 / 주말 B 10만~15만 원
