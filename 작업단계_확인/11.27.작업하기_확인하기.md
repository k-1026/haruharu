## 1. 이번에 고칠 핵심
**일본어 결과물의 일관성을 고치고, 기관 담당자가 배포를 준비할 수 있도록 일정표와 게시 전 체크리스트를 제공한다.**
앱 구현은 민지님, 앱에 넣을 3단계 코스·4단계 홍보 내용과 검수 기준은 예진님이 맡는다. 이 문서는 작업 제안과 확인 기준이며 구현 완료 보고가 아니다.

앞서 선택한 B안(언어·동선·배포 준비·치킨)은 전체 개선 방향으로 유지하되, 남은 두 작업일의 필수 범위는 아래로 줄인다. 동선 제외는 민지님 요청과 관련되므로 팀에서 합의하고 WBS에 보류 사유를 남긴다.

| 우선순위 | 이번 범위 | 담당 |
|---|---|---|
| 필수 | 일본어 고정 문구·장소명·랜딩 수정(L1·L2·L4) | 예진: 한·일 표/용어 근거, 민지: 적용 |

## 3. 언어: 내용과 구현을 나눠 고치기
| 항목 | 기존 기록의 문제 | 예진님이 준비할 것 | 민지님이 반영·확인할 것 |
|---|---|---|---|
| L1 | 표지·포스터·리플릿 안내의 한국어 고정 문구 | 문구 ID, 사용 위치, 한국어, 일본어 초안, 검수 상태 표 | 언어별 문구 적용, 모든 면 확인 |
| L2 | 포스터·리플릿 장소명이 한국어 | 용어집의 확인된 일본어 명칭과 출처 | 홍보물·랜딩에 동일 표기 사용 |
| L4 | 일본어 랜딩 제목·소개·단위·지역·종료 지점·지도 안내에 한국어 | 해당 문구를 빠짐없이 한·일 표에 포함 | 초기 표시와 언어 전환 후 모두 확인 |
| L5 | AI 번역 안내 숨김 | 검수 전 안내 문구·공개 기준 | AI 초안/원어민 검수 전 상태가 사라지지 않도록 처리 |
| L6 | 영어·중국어 선택과 랜딩 지원 범위 불일치 | MVP 지원 범위 안내 | 미지원 선택 비활성화 또는 준비 중 표시 |
| L3 | 일차·시간칸 머리글 번역 누락 | 머리글 목록 | 여유 시 적용. 일본어 말풍선 추가는 별도 범위 |
| L7 | 일본어 일부 글자 네모 표시 의심 | 문제가 보인 문구 목록 | 화면·다운로드 결과에서 재현, 글꼴 원인 확인 |

**미번역 처리 제안:** 용어집에 없는 명칭은 담당자용 자료에 ‘자료 필요’와 원래 이름을 함께 남긴다. 임의 일본어 표기는 만들지 않는다. 공개물에 한국어를 조용히 대체 삽입하거나 ‘자료 필요’ 상태를 그대로 게시하지 않는다. 확인된 공식 표기 확보 또는 담당자가 의도한 병기를 승인한 뒤 공개한다. 기존 두 안의 ‘한국어 유지’와 ‘자료 필요 표시’를 이 방식으로 통일할지 팀에서 결정한다.

완료 기준: 일본어를 선택한 대표 코스의 표지·포스터·리플릿·카드뉴스 전 면·랜딩에서 의도하지 않은 한국어가 없고, 장소명·코스 버전이 일치한다. 출처·상호의 의도적 병기는 검사 예외를 명시한다. 번역 적용 완료와 원어민 검수 완료는 별개다.

## 4. 배포 준비: 이번에는 두 파일부터
‘⑦ 배포 준비’는 사용자 흐름의 확장 제안이다. 새 AI 에이전트나 별도 화면을 반드시 추가한다는 뜻은 아니다. 이번에는 최종 파일 생성에 두 파일을 포함하는 최소 구현을 우선한다. 기존 1~5단계 에이전트와 ①~⑥ 화면 흐름의 번호도 구분한다.

### 배포 일정표 CSV
열: 날짜, 채널, 언어, 게시물, 링크, 담당자, 검수 상태, 게시 URL

- 날짜·채널·담당자·게시 URL은 담당자 입력 칸으로 둔다.
- 일본어 선택 시 언어는 일본어로 기입할 수 있다. 게시물 칸에는 실제 산출물 파일명/식별자를 연결한다.
- 검수 상태 기본값은 ‘미확인’. 빈 공개 링크를 임의 주소로 채우지 않는다.
- 예시 행은 시연용으로 표시하고 실제 배포 계획과 구분한다.
- 인스타그램·페이스북·블로그는 확정 채널이 아니다. 일본인 대상 적합성과 기관 보유 계정은 확인 필요.
- 기존 기록의 ?from=은 유입 구분용 후보다. 실제 지원·보존 여부를 민지님이 확인한다. 매개변수만 있다고 접속 수가 집계되는 것은 아니다.

### 게시 전 체크리스트
| 확인 항목 | 기본 상태 | 확인 근거/담당/확인일 |
|---|---|---|
| 일본어 원어민 검수 | 미확인 | 빈칸 |
| 사진 출처와 사용 가능 범위 | 미확인 | 빈칸 |
| 캐릭터 권리 귀속·사용 승인 | 미확인 | 빈칸 |
| 방문일 기준 영업·휴무·예약 등 운영 정보 | 미확인 | 빈칸 |
| 공개 QR 주소와 외부 휴대전화 접속 | 미확인 | 빈칸 |
| 확정 코스 버전·장소명·일정의 일치 | 미확인 | 빈칸 |
| 기관 게시 담당자 및 필요한 게시 승인 | 미확인 | 빈칸 |

예진님은 열·항목·작성 안내를 확정하고, 민지님은 추가 AI 호출 없이 파일 생성과 ZIP 포함을 구현한다. 미확인은 자동으로 완료 처리하지 않는다. 내부 시연용 ZIP 생성과 실제 공개 승인도 구분한다.

**기획자에게 주는 가치:** 홍보물과 함께 언제·어디에·누가 게시할지 채우는 양식, 게시 전에 확인할 항목을 제공한다. 게시 문구·채널·공개 URL이 미확정인 동안 ‘즉시 게시 가능한 완성 패키지’라고 설명하지 않는다. 실제 게시는 담당자가 직접 한다.

## 5. 동선과 치킨: 버리지 않고 후속으로 관리
- 동선: 담당자 화면의 지도와 홍보물·랜딩의 동선은 다른 산출물이다. 담당자 지도 구현만으로 홍보물 문제 해결이라고 표시하지 않는다.
- 여유 시 포스터에 방문 번호·일차 구분을 넣고 ‘방문 순서 안내, 실제 지도 아님’을 표시한다. 모르는 이동시간을 만들지 않는다.
- 실제 좌표와 도로 경로 재사용은 후속. 좌표 완전성·경로 자료·출처 조건을 확인한다. 순서 도식에 ‘전체 지도’라는 안내가 남는다면 실제 기능에 맞게 수정한다.
- 치킨: 민지님의 ‘어제 말한 콘텐츠’ 정의를 먼저 확인한다. 현 지침 범위에서는 담당자가 선택한 저녁 치킨 장면의 선택형 카드만 검토한다.
- 역사·가게 이야기는 스토리 검증표 판정을 따르고, 코스 전체를 치킨으로 바꾸거나 확인 안 된 정체성 주장을 추가하지 않는다. 식사는 개별 선택·결제라는 설명을 유지한다.

## 7. 발표자료에서 수정·유지할 것
- 사용 흐름: 배포 준비가 반영된 경우에만 최종 파일 뒤의 담당자 업무를 추가한다. 미구현이면 다음 과제로 표시한다.
- 실제 화면: 일본어 카드뉴스 전 면과 랜딩을 수정 후 새 캡처로 교체한다. 과거 캡처를 최신 결과로 제시하지 않는다.
- 산출물: 일정표·체크리스트가 실제 ZIP에 들어간 경우 목록에 추가하고 다운로드 시연한다.
- 시연 주소: 발표 본문의 8790과 요청 주소 8803 중 실제 실행 주소를 통일한다.
- 유지할 한계: 가상 설문 13행, 원어민 검수 전, 현장 운영 미확인, 공개 QR 없음, 인터뷰·시간 절감 가설 미검증. 해결 증거가 생긴 항목만 상태를 바꾼다.
- 기존 하네스 통과는 번역 품질·사실 정확성 보증이 아니다. 대표 시연 1회도 전체 품질 보증으로 확대하지 않는다.
- 속도 피드백은 단계별 대기·재시도 원인 확인으로 남긴다. 의존 관계가 있는 코스 확정→홍보를 무작정 병렬화하거나 모델을 일괄 교체하는 것은 이번 필수 범위에 추가하지 않는다.
