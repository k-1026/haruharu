## 2. 토큰 수 (count_tokens로 셈)

실행 요청에서 사용량(`usage_metadata`)을 받아 적으려 했으나 **Gemini 503(혼잡)으로 네 번 모두 실패**했다. 그래서 같은 모델의 토큰 세기 API(`count_tokens`)로 지난 실행의 입력 · 출력을 셌다.

| 부분 | 토큰 |
|---|---:|
| 에이전트 본문 (`.claude/agents/홍보검토.md`, 시스템 지시) | 404 |
| 공통 지침 `지침/공통/단계_넘김.md` | 4,663 |
| 입력 JSON (조건 · 근거목록 · 확정코스) | 67,414 |
| 4단계 지침 12개 + 홍보문구 스킬 (지침 본문을 넣는 방식일 때만) | 35,819 |
| 출력 — 실행 A · C · D · E (`4단계_결과.md`) | 4,480 · 4,392 · 2,906 · 3,893 |

- 요청 안내 문장(몇백 토큰)은 세지 않았다
- **생각(thinking) 토큰은 세지 못했다** [U]. 요금표상 출력 값에 포함되므로 실제 출력 비용은 아래보다 클 수 있다

## 3. 4단계 1회 비용 (계산값, 유료 등급)

| 방식 | 입력 토큰 | 출력 토큰 | 입력 비용 | 출력 비용 | 합계 |
|---|---:|---:|---:|---:|---:|
| 앱 방식 그대로 (AI가 지침을 안 읽음) | 72,481 | 2,906 ~ 4,480 | $0.0217 | $0.0073 ~ $0.0112 | **$0.029 ~ $0.033** |
| 지침 본문을 넣는 방식 (M1 안건 9-1 제안) | 108,300 | 2,906 ~ 4,480 | $0.0325 | $0.0073 ~ $0.0112 | **$0.040 ~ $0.044** |

- 계산식: 입력 토큰 × $0.30 / 1,000,000 + 출력 토큰 × $2.50 / 1,000,000
- 지침 본문을 넣으면 4단계 1회에 입력이 약 1.5배가 된다 (계산값). 대신 지침을 지키는 비율이 올라갔다 (`4단계_재실행_1124.md` 3 · 6 · 7장)
- 원화 환산은 하지 않았다 (환율을 확인하지 않음)

## 4. 아직 c_AI가 아닌 것 [U]

- **1 ~ 3단계는 재지 않았다.** 3단계는 AI가 파일을 여러 번 읽을 수 있어(자동 함수 호출) 호출마다 앞 내용이 다시 입력으로 들어간다. 1회 요청 크기만으로는 셀 수 없고 실제 `usage_metadata`가 필요하다
- **재실행 횟수:** 오늘 4단계는 같은 저장본으로 성공 5회, 503 실패 6회였다. 실제 기획안 1건에 몇 번 다시 돌리는지는 정하지 않았다
- **기획안 1건 = c_AI** 로 쓰려면 1 ~ 4단계 합계 × 평균 재실행 횟수가 필요하다
