## 0. 다른 PC에서 시작하기

1. `git fetch origin` → `git checkout 이예진` → `git pull` (처음이면 `git clone https://github.com/k-1026/haruharu.git`)
2. Claude에게: "`작업단계_확인/11.26진행사항v1.md` 읽고 이어서 하자. 답은 한국어로."
3. gh CLI는 로그인 안 됨 → PR은 브라우저에서 GitHub 로그인 후
4. **integration에 PR 올리는 방법 (이번에 바뀜):** 사람1도 3단계 지침을 고치므로 파일을 통째로 덮어쓰지 않는다. integration 기준 브랜치를 만들고, 파일마다 `git merge-file`로 3-way 병합한다 (base = 지난 PR merge 커밋의 파일, ours = integration, theirs = 이예진). Windows에서는 줄바꿈(CRLF)을 지운 뒤 병합해야 가짜 충돌이 안 난다
5. 이전 PC에만 있는 것: 없음 (모두 push). `app/3-4단계-연결` 로컬 브랜치는 이제 필요 없음 (사람1이 앱에 3 · 4 · 5단계를 직접 연결함)
