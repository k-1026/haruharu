## 시연 순서 (5~9번, 약 6분)

1. 조건 입력: 중구 · 봄 · 중국어 번체 · 1박 2일 (조건 세트 B)
2. 2단계 근거표에서 근거 ID · 경고 ID만 짚고 넘어감
3. 3단계 코스: 근대골목 겹침 표시 → "그대로 두기"를 고르면 4단계가 "연결하기" 문구를 쓰지 않음을 보여 줌
4. 담당자 결정: 저녁 자유식 · 2일차 오전 "종료 장소로 바로"
5. 4단계: 저녁-1 E5 걸림 → 고친 문구 / 2일차-낮-1 장소 스토리 문구
6. 코스 카드 + 번역 `AI 초안` 상태

- 시연 화면은 3.3 화면 설계(`정리본/3.3_화면설계_3·4단계_초안.md`)와 3.1 앱 연결이 끝난 뒤 정한다. 연결이 안 되면 미리 돌린 결과 화면 캡처로 대신한다

## 말하지 않을 것 · 조심할 것

- **시범 사용 결과는 아직 없다** (관광객 시범 2027-03, 담당 부서 문의 전). "시범에서 효과가 확인됐다"처럼 말하지 않는다. 10번은 "테스트(에이전트 실행)로 확인한 것"으로만 말한다
- 비비드 투어 실패 원인은 언론 보도 기준이다. "우리 도구가 있었으면 성공했을 것"처럼 단정하지 않고 "같은 문제를 미리 표시한다"까지만 말한다
- 조사 수치를 쓸 때는 G5 · G17 결정을 따른다 (`정리본/M1_안건_제안안_사람2.md`). 대만 응답자 비율 등은 대상 · 연도 · 표본을 같이 적는다
- 중구청 담당자 이름 · 연락처, 실존 업체 평가는 넣지 않는다
