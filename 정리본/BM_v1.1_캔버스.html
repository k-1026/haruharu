한 줄 BM. 대구 관광 담당자가 체류형 사업을 발주 · 검수 · 결재할 때, 조건 → 수요 근거 → 코스 → 홍보 초안을 출처 · 경고와 함께 묶어 판단 근거를 미리 갖추게 한다. 1~4단계 실행 확인 · 5단계 결재 파일 지침만. 건당으로 시작, 시범으로 확인되면 구독 검토 팀 결정

⑦ 핵심 파트너

  • 용역 수행 업체 · 대행사 — 파트너이자 잠재 경쟁자
  • 운영 주체 후보: 중구청 관광과 상품, 시장 상인 조직 [U], 야시장 운영 재단
  • 여행사 — 진흥원 인센티브 1박 2만 원/인 · 공항 입국 최대 2,000만 원 확인값. 누구에게나 열린 공개 제도, 예산 조기 소진 기록. 우리 매출과 연결 없음

⑧ 비용 구조

  • 지역별 구축비 (운영 정보 · 이동 · 상품 목록 · 스토리) · 건별 (AI c_AI · 검토 c_검토) · 공통 고정비 (웹 앱 개발 · 유지보수, 데이터 갱신, 영업 · 인터뷰 · 시범, 입찰 자격) · 파트너 몫 — 금액 모두 [U]
  • 건당 공헌이익 = p − (c_AI + c_검토) → 지금은 부호도 모름
  • 손익분기 틀: n × p × r ≥ 고정비 + 지역 구축비 + n × (c_AI + c_검토) (금액 미정)

⑨ 수익원

  • 기획안 건당 → 연 구독 검토 팀 결정 · 다시 볼 기준 있음 (md 5장)
  • 도구 요금 p [U] · 지불 의향 미확인. 1,500여만~5,000만 원은 사업 예산 크기 확인값, 요금 아님
  • SOM = N × n × p × r — 검증 전 식, 값 넣어 결론 내지 않음. n 0~3건 가정값
  • 확인 순서: ① 채택률(시범 1건) → ② 요금(지불 의향) → ③ 해당 발주 건수
