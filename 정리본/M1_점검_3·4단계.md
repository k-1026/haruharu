**어긋남 ② 3단계 → 5단계.** 5단계 `입력.md` 3행에는 확정 코스 · 근거 · 운영 주체 · 대체 · 겹침 · 경고만 있다. 3단계가 넘기는 **식사, 운영 방식 · 2일차 오전 구성, 장소 스토리, 담당자 결정 기록, 3단계 미확인 사항(확정 / 가정 / 미정 시각)** 이 빠졌다. 결재 파일 · 제안서에 식비 포함 여부와 가정 시각이 그대로 들어가야 하므로 필요하다. "받는 곳"의 "사람2 브랜치"도 integration 경로로 바꾼다. (사람1 파일)

**어긋남 ③ 코스 카드.** 4단계 `9_출력.md` 코스 카드에는 11/22에 "식사 안내" 줄을 더했다. 5단계 `출력.md` 47줄 코스 카드 설명은 "이런 분이라면 → 이 코스 · 코스 한눈에 · 남은 경고"만 있다. (사람1 파일, 한 줄 추가)

| 확정조건 중 거짓이 있음 | 4단계 시작 안 함, 담당자에게 되묻기 |
| 근거ID가 2단계 근거목록에 없음 | 3단계 재실행 |
| 시각.종류가 허용값이 아님, 또는 `미정`인데 값이 있음 | 재실행 |
| 자유식인데 식당이 있음, 지정식인데 식당이 없음 | 재실행 |
| 식사목록 · 미확인사항의 칸ID가 칸목록에 없음 | 재실행 |

### 3-2. 4단계 → 5단계

| 필드 | 형식 | 필수 | 비고 |
|---|---|---|---|
| 코스카드 | 객체 | ○ | 대상문장 · 코스이름(없으면 `미정`) · 한눈에 · 식사안내 · 남은경고 |
| 대응표 | 객체 목록 | ○ | 장면ID(= 칸ID) · 장소 · 홍보물 · 상태 |
| 문구목록 | 객체 목록 | ○ | 장면ID · 제목 · 본문 · 사실근거(출처ID · 근거ID 목록, 또는 `연결문장` / `가정값` / `미정`) · 경고 |
| 번역목록 | 객체 목록 | ○ | 장면ID · 언어 · 번역 · 역번역 · 상태(`AI초안` / `검토중` / `검토완료`) · 검토자 · 날짜 |
| 표현필터 | 객체 목록 | ○ | 장면ID · 표현 · 종류 · 처리(`고침` / `그대로둠` / `미처리`). 없으면 빈 목록 |
| 코스변경 | 객체 목록 | ○ | 요청장면ID · 이유 · 3단계결과 · 다시만든장면 · 재검토상태(`끝남` / `진행중`) |
| 시안 | 객체 | ○ | 톤앤매너 · 장면별(장면ID · 주연 · 배치세트 · 포즈) · 배치점검 |
