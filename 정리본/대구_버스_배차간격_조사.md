# 대구 버스 노선별 배차간격 조사

- **출처:** 대구광역시 버스정보시스템 > 버스 운행 시간표 (`businfo.daegu.go.kr:8095/dbms_web/content/businfo/schedule`)의 노선별 조회 데이터 (사이트가 호출하는 `/busInfo/schedule` 응답의 `gap` 항목) `[P]`
- **조회 기준일:** 2026.11.19 (목) / 조회 노선 142개 전부 응답 확인
- **단위:** 분. 사이트의 평균 배차간격(`avgTm`) 값을 그대로 사용 `[F]`

## 읽는 법

- 사이트는 노선을 **방면(운행 유형)별**로 나누어 배차간격을 줍니다. 한 노선에 방면이 여러 개이고 값도 제각각입니다(예: 101번 파계사방면 25분, 덕곡방면 132분).
- 아래 표의 평일·토·휴일 값은 **방면별 값을 해당 방면 운행횟수로 가중평균**한 것입니다 `[I]`. 사이트가 주는 노선 단일 평균이 아닙니다.
- **주 운행**은 운행횟수가 가장 많은 방면의 배차간격입니다 `[I]`. 사실상 그 노선의 대표 배차간격입니다.
- **범위**는 해당 노선 방면 중 최소~최대 값입니다. 사이트가 `999`로 주는 항목은 "배차간격 없음, 일 N회 운행"이라 평균과 범위에서 제외했습니다.
- `전일`은 요일 구분 없이 하나만 제공하는 노선입니다(평일·토·휴일 칸이 비어 있음).

## 한계와 주의

- **하루 한 날짜 값입니다.** 2026.11.19 기준이고, 사이트는 오늘부터 6일 뒤까지 조회를 받습니다. 다른 요일이나 계절 개편, 임시 운행에서는 값이 달라질 수 있습니다.
- **평균 배차간격은 하루 전체 평균입니다.** 첨두·비첨두 시간대별 값이 아닙니다. 시간대별 간격은 사이트의 상세 운행시간표(첫차·막차 표)에서 직접 계산해야 하고, 이번에는 하지 않았습니다.
- **101번처럼 방면이 갈리는 노선**은 평균값 하나로 보면 실제 이용과 많이 어긋납니다. 그런 노선은 `주 운행`과 `범위`를 같이 봐야 합니다.
- 사이트 드롭다운에 있는 **142개 노선**을 기준으로 했습니다. 목록에 없는 노선은 조사 대상이 아닙니다.
- 표의 `주 운행`, 가중평균, 요약 통계는 제가 사이트 값에서 계산한 `[I]`이고, 사이트가 직접 제공하는 값이 아닙니다.
