## 0. 지금 앱 구조 (integration 브랜치에서 확인한 것)

| 파일 | 하는 일 | 3 · 4단계와 관계 |
|---|---|---|
| `stages.py` | 단계 번호 → 에이전트 파일 | 3 · 4단계 줄이 **주석 처리**돼 있다 ("사람2 브랜치에 있다. main에 합쳐지면 푼다") |
| `run_stage.py` | 에이전트 md 본문을 지시문으로 넣고 Claude Agent SDK로 한 번 호출, 결과 텍스트를 돌려줌 | 3 · 4단계도 그대로 쓸 수 있다 |
| `orchestrator.py` | 터미널에서 번호로 고르게 하며 1 → 2단계를 잇고, 결과를 `runs/<시각>/n단계_결과.md`로 저장 | 2단계 뒤 "경고를 남기고 진행 (3단계는 아직 연결 전)"에서 끝난다 |

- **확인한 문제:** 오케스트레이터는 2단계 결과를 출력한 **뒤에** E3 선택을 묻지만, 그 선택을 결과 파일 · 다음 입력에 붙이지 않는다. 그래서 2단계 "3단계로 넘기는 것" 블록에는 늘 "E3: 미선택"이 남는다 (2.6 기록표 B의 B7과 같은 원인). → 3단계 입력을 만들 때 **담당자 선택을 입력 맨 앞에 붙여야** 한다 (2장 ①).

## 1. 3 · 4단계 흐름과 담당자 조작 지점

```
[2단계 결과] → (E3 선택) → ① 3단계 입력 만들기 → 3단계 실행 → ② 3단계 화면
   → 담당자: 코스 작성 조건 · 충돌 대체 · 겹침 선택 · 확정
   → 확정 조건 점검 (시작 · 종료 확정 + 노선 겹침 선택/없음)
       ├ 미충족 → 초안 보관, 빠진 것을 묻고 3단계 다시 실행
       └ 충족 → ③ 4단계 입력 만들기 → 4단계 실행 → ④ 4단계 화면
   → 담당자: 번역 언어 · 톤 · 홍보물 종류 · E5 처리 · 번역 상태 · (필요하면 E6 코스 수정 요청)
   → E6 요청 → 3단계로 돌아감 (바뀐 장소 · 시간만) → 4단계 해당 장면 "다시 확인 필요"
   → 확정 → 5단계 입력 (사람1)
```

## 2. 입력 만들기 (오케스트레이터에서 할 일)

**① 3단계 입력** — 2.6 테스트의 `3단계_시범입력.md` 형식을 그대로 쓴다.

```
담당자 선택 (E1): 알림을 남기고 진행
담당자 선택 (E3): 경고를 남기고 진행          ← 2단계 블록의 "미선택"보다 앞에 둔다
확정 체류 기간: 1박2일
코스 작성 조건:
  - 코스 시작: [일차] [장소] [시각] (확정 / 후보 제안 요청)
  - 코스 종료: [일차] [장소] [시각] (확정 / 후보 제안 요청)
  - 저녁: [대구 음식 / 치킨 옵션 / 미선택]
  - 식사 칸마다: 식사 방식 [지정식 / 자유식 / 미선택], 지정식이면 식당, 식비 포함 [포함 / 불포함 / 미정]
  - 운영 방식: [단체 동행형 / 개별 이동형 / 미정]
  - 1일차 순서: [장소 → 장소 → …] (없으면 에이전트 제안)
  - 숙박 권역: [기준점] (업체 고정 안 함)
  - 2일차 오전 구성: [확인 가능한 후보로 일정 추가 / 자유시간(시작 · 끝 · 이후 연결) / 종료 장소로 바로 이동 / 미선택]  ← 미선택이면 확정 안 됨. 에이전트가 대신 고르지 않음 (2026-11-22 사람1 수정 요청)
  - 비는 칸 처리: [비우기 / 대체안 받기]
설정 변경: [없음 / 바꾼 값]
2단계 결과: (2단계_결과.md 전체)
장소 운영 정보 · 이동 시간: research/data/ 경로 (MVP는 파일, 3.4 이후 DB)
```

- 3-b를 **3단계 실행 전에 한 번에 묻는다.** 2.6 A처럼 실행 뒤에 다시 묻는 왕복을 줄인다. 모르면 "미선택"으로 두고, 에이전트는 후보만 내고 확정하지 않는다.

**③ 4단계 입력** — 3단계 결과의 "4단계로 넘기는 것" 블록 + 1단계 언어권 + 4-a 선택. 3단계 결과 전체를 넘기지 않고 블록만 자른다 (`3단계_결과.md`에서 "## 4단계로 넘기는 것" 아래).

## 3. 3단계 화면

| 영역 | 보이는 것 | 담당자 조작 | 표시 규칙 |
|---|---|---|---|
| 맨 위 띠 | 조건 요약 · 코스 시작 / 종료 (확정 · 후보 배지) · 안 선택 탭(평일안 / 토요일안) | 시작 · 종료 확정 | 후보는 "담당자 확인 전" 배지 |
| 시간표 | `6_출력.md` 시간표. 일차로 묶음. "빈 시간 — 제안 칸"은 회색 줄 | 칸 클릭 → 장소 바꾸기 (직접 고치기) | 가정 값(머무는 시간 등) 옆에 "가정" 표시. 미확인 이동은 시각 안 이음 |
| 충돌 패널 (E4) | 충돌 문구 · 대체안 | 대체안 받기 / 직접 고치기 / 비우기 | 진행을 막지 않음 (노란 표시) |

| 제안 패널 | 해설 · 체험 제안 | (정보만) | "신청 · 협의는 담당자 몫" 문구 고정 |

| 담당자 결정 기록 | 고른 것 · 고르지 않은 후보 · 메모 | (자동 기록) | — |
| 체크리스트 | C1~C10 · 안별 결과 | (정보만) | "확인 불가"는 통과와 다른 색. C3 메뉴 미정 메모 |
| 아래 | 확정 버튼 | 확정 | ① 시작 · 종료 확정 ② 노선 겹침 선택/없음 → 둘 다 돼야 켜짐. 안 되면 무엇이 빠졌는지 표시 |

## 4. 4단계 화면

| 영역 | 보이는 것 | 담당자 조작 | 표시 규칙 |
|---|---|---|---|
| 맨 위 띠 | 번역 언어 · 톤앤매너 · 홍보물 종류 | 고르기 (톤 · 종류는 지금 `[자료 필요]`) | 미선택이면 "미선택" 배지 |
