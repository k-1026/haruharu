## 1. 1단계 기획 조건

### PP-1a. 고른 조건에 맞는 근거가 충분한지 미리 알기 어렵다 — 강도 중

| 항목 | 내용 |
|---|---|
| 상황 | 담당자가 시기 · 대상 국가 · 당일/1박을 정할 때 |
| 문제 | 조건을 좁힐수록 표본이 작아지거나 해당 표가 없는데, 이를 조건을 정한 뒤에야 알게 된다 |
| 근거 | 대구관광실태조사 2024 외국인은 1,010명인데, 6~8월 당일은 약 72명 표본 [F 1113 발표] · 외국인 불편 응답 · 정보 채널 · 입국 경로 표는 확보한 자료에 없음 [F 신민지 `inventory/데이터수집_결과.md`] · 여정지도 v0.2의 질문 "이 시기 · 이 나라로 정하면 근거가 있나?" [H] |
| 도구 대응 | 조건에 맞는 데이터만 골라 두고, 안 맞으면 알림(E1) |

## 2. 2단계 수요 근거

### PP-2a. 출처 · 기간 · 대상 · 단위가 다른 자료를 한 표로 비교하기 어렵다 — 강도 강

| 항목 | 내용 |
|---|---|
| 상황 | 기획안에 넣을 수요 수치를 고를 때 |
| 문제 | 같은 질문에도 자료마다 기준이 달라 수치를 그대로 나란히 쓸 수 없다 |
| 근거 | 외국인 출발 국가: 빅데이터(이동통신 기반 방문자 수)는 대만 중심, 실태조사(설문)는 기준이 다름 [I] · 거주지 비율 합계가 100을 넘어 절대 비율로 해석 불가 [F 신민지 `brand/persona_design_draft.md`] · "외지인 방문자" 정의(고유 방문자인지 방문 건수인지) 미확인 [F 신민지 `inventory/프로젝트_정리_v2.md` §11] · 실태조사 시기 구분(4~5월, 6~8월 …)이 계절 구분과 다름 [F] · 여정지도 v0.2 문제 가설 ① [H] |
| 도구 대응 | 수치마다 출처 · 연도 · 표본 · 한계를 붙인 근거표, 비교 불가(E2) · 근거 약함(E3) 경고 |
| 메모 | 팀이 자료를 정리하면서 직접 겪은 문제라 "자료 문제"는 강하게 확인됨. 담당자도 같은 불편을 겪는지는 [H] |

### PP-2b. 필요한 데이터가 공개 자료에 없다 — 강도 강

| 항목 | 내용 |
|---|---|
| 상황 | 숙박 위치나 기존 사업 성과를 근거로 쓰려 할 때 |
| 문제 | 기획에 꼭 필요한 값이 공개되지 않거나 집계되지 않는다 |
| 근거 | 구별 외국인 숙박 위치 데이터 없음 [F 밸류체인 v2.0 §6] · 중구 스탬프 완료자 수 · 할인 사용 실적 없음 [F 밸류체인 `onepagers/jung_stamp_tour.md`] · 근대골목 밤마실 이용 인원 집계 없음 [F `onepagers/geundae_night_walk.md`] · 비비드 투어 "실적 공개 없음" [F `onepagers/vivid_dongseongro_tour.md`] |
| 도구 대응 | 근거표에 "없음"을 빈칸이 아닌 한계로 표시하고, 기관 데이터를 올릴 자리를 둠(2단계 "기관 데이터 올리기") |
| 메모 | 기관 내부 데이터(안내소 방문자, 골목투어 이용 인원, 스탬프 실적)는 구청에 요청해야 하는 항목으로 밸류체인 v2.0 §7에 이미 적혀 있음 [F] |

## 3. 3단계 코스 검토

### PP-3a. 이미 있는 상품 · 노선과 겹치는지 확인하기 어렵다 — 강도 강

| 항목 | 내용 |
|---|---|
| 상황 | 새 코스나 투어 상품을 기획할 때 |
| 문제 | 같은 지역에 구청 · 기관 상품이 여러 개 있어, 새 상품이 기존 노선과 겹친다 |
| 근거 | 비비드 동성로 투어(중구청 관광콘텐츠팀, 1,500여만 원) 저조 원인으로 "기존 근대골목 투어(1~5코스)와 노선 중복"이 보도됨 [F 언론] · 밤마실 원페이지에도 "비비드 투어와 노선이 겹친다는 지적" [F] · 중구에는 근대골목 투어, 밤마실, 근대골목 스탬프 12곳, 약령시 스탬프 5곳이 이미 있고 장소가 일부 겹침 [F] |
| 도구 대응 | **기존 상품 겹침 표시(E7, 신설).** 코스 장소를 중구 기존 상품 13개의 경유 장소와 대조해 겹치는 곳을 표시하고, 담당자가 피하기 / 연결하기 / 그대로 두기를 고름 → `지침서/3.코스_검토/8_기존_상품_겹침.md`, 목록 `9_기존_상품_목록.md`. 유저플로우 v1 · 역할표에는 아직 없음 → 7장 팀 문서 수정 제안 |
| 메모 | 실패 사례의 원인으로 보도된 것이라 강도는 강. 다만 언론 보도 기준이고 구청 공식 실적은 [U] |

### PP-3b. 영업일 · 휴무 · 운영 시간 · 스탬프 조건을 한 번에 맞추기 어렵다 — 강도 중

| 항목 | 내용 |
|---|---|
| 상황 | 낮 · 저녁 · 숙박을 한 시간표로 이을 때 |
| 문제 | 장소마다 운영 조건이 달라, 코스를 짠 뒤에 충돌이 드러난다 |
| 근거 | 골목투어 1~5코스는 "참가 인원 10명 미만이면 일정이 취소될 수 있다" [F 06_페인포인트 E-03, 중구청 페이지 원문 단일출처] · 밤마실 B코스는 상세 페이지는 "2025년 한시운영", 신청 페이지에는 신청 항목이 있어 공식 페이지끼리 맞지 않음 [F 06_페인포인트 E-01] · 땅땅치킨랜드 월요일 · 명절 휴장 [F 여정지도 v0.2] · 밤마실은 금 · 토만, 동절기 시간 변경 [F, 구청 원문 [U]] · 약령시 스탬프는 "기념품 소진 시까지", 중구 주민 기념품 제외 [F] · 업체 운영계획은 "중구와 협의하여 최종 확정" [P 타임워프 과업요청서] · 여정지도 v0.2 문제 가설 ② [H] |
| 도구 대응 | 휴무 · 영업시간 · 이동 시간 충돌 표시와 대체안(E4) |

## 4. 4단계 홍보 검토

### PP-4a. 외국어 홍보물이 부족하고, 사업마다 따로 만든다 — 강도 강

| 항목 | 내용 |
|---|---|
| 상황 | 외국인 대상 사업의 홍보를 준비할 때 |
| 문제 | 외국어 홍보물이 없거나 한 언어뿐이고, 사업마다 업체에 따로 맡겨 언어 · 범위가 제각각이다 |
| 근거 | 비비드 투어는 "영문 팸플릿만", 구청 홈페이지에는 배너만 → 저조 원인으로 보도 [F] · 근대골목 투어 팸플릿은 4개 언어, 관광안내소에는 영문만 [F 밸류체인 v2.0 §3] · 대구트립 앱은 5개 언어 [P 과업이행요청서] · 축제 용역은 "외국인 참가자 유치를 위한 홍보방안 마련"을 업체 제안에 맡김 [P 동구 봄축제 · 어울림한마당] · 빛 축제 제안요청서에는 다국어 홍보 요구가 없음 [P] |
| 도구 대응 | 장면별 문구와 언어별 번역 초안, 원어민 검토 단계 |

| 항목 | 내용 |
|---|---|
| 상황 | 코스나 프로그램이 바뀐 뒤 |
| 문제 | 바뀐 부분을 찾아 홍보물 전체를 다시 확인해야 한다 |
| 근거 | 담당자는 홍보물 디자인을 사전 승인하고 [P 동구 봄축제 · 어울림한마당], 콘텐츠를 검수하고 수정을 요구함 [P 중구 SNS] · "업로드 전 담당자와 사전 협의 또는 확인" [P 동구 유튜브] · 여정지도 v0.2 문제 가설 ③ [H] |

## 6. 각 단계 md의 "이 단계가 필요한 이유" 문안

| 단계 | 문안 |
|---|---|
| 1 기획 조건 | 조건을 좁힐수록 쓸 수 있는 자료가 줄어듭니다. 조건을 정하는 순간 근거가 충분한지 알려 주면, 근거 없는 조건으로 기획을 시작하는 일을 막을 수 있습니다. (PP-1a) |
| 2 수요 근거 | 대구 관광 자료는 출처 · 기간 · 대상 · 단위가 서로 달라 그대로 비교할 수 없고, 꼭 필요한 값이 없는 경우도 많습니다. 수치마다 출처와 한계를 붙여야 기획안이 결재와 평가를 견딥니다. (PP-2a, PP-2b) |
| 3 코스 검토 | 같은 지역에 비슷한 상품이 이미 있고, 장소마다 운영 조건이 다릅니다. 노선이 겹치거나 휴무와 충돌한 코스는 실제 운영에서 실패합니다. (PP-3a, PP-3b) |
| 4 홍보 검토 | 외국인 대상 사업도 외국어 홍보물이 부족하거나 사업마다 따로 만들어집니다. 코스 장면과 홍보물을 짝지어 두면 언어별 초안을 한 번에 만들고, 코스가 바뀔 때 바뀐 장면만 다시 보면 됩니다. (PP-4a, PP-4b) |
