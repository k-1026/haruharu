## 0. 한 줄 BM

대구 관광 담당자가 체류형 사업을 **발주 · 검수 · 결재할 때**, 에이전트가 조건 → 수요 근거 → 코스 → 홍보 초안을 출처 · 경고와 함께 묶어 **판단 근거를 미리 갖추게** 한다. 1~4단계는 통합 시험에서 실행 확인, 5단계(결재 파일 · 제안서 · 홍보물)는 개발 중이다. **기획안 건당으로 시작하고, 시범 사용으로 쓰임이 확인되면 연 구독을 검토한다** `[팀 결정]` (5장 다시 볼 기준).

## 3. 단위 경제와 SOM — 검증 전 식

> **건당 공헌이익 = p − (c_AI + c_검토)** — p · c_AI · c_검토 모두 [U]. 지금은 공헌이익이 플러스인지조차 모른다.

> **SOM(연) = N × n × p × r** — 지금은 **값을 넣어 결론을 내지 않는다** (레드팀 I-3).

| 변수 | 지금 상태 | 확인 순서 |
|---|---|---|
| r 채택률 | 근거 0건 (민감도 1위) | **1** 시범 사용 1건 |
| p 도구 요금 | [U] — 사업 예산(1,500여만~5,000만 원)은 p가 아님 | **2** 지불 의향 확인 (담당자 · 대행사), 대체 수단 비용 |
| n 연간 해당 발주 | **0~3건** `가정값` — 중구 2026 확인 발주 중 "체류 코스 기획"에 해당하는 건수는 [U]라 하한 0 | **3** 해당 발주 건수 확인 |
| N 발주처 | 중구 1 (MVP), 대구 전체 11 `가정값` | 확장 때 |
| c_AI · c_검토 | [U] | 통합 시험 사용량 · 검토 시간 기록 |

- **손익분기 틀** (금액 미정): 연 매출 = n × p × r ≥ 공통 고정비 + 지역별 구축비 + n × (c_AI + c_검토). 위 확인 순서대로 값이 채워지면 몇 건 · 몇 년에 비용을 덮는지 본다.
- 참고: 시장검증 5-2의 계산 예(중구 연 150만~7,500만 원 `계산값`)는 p에 사업 예산을 넣은 값이라 이 문서에서는 쓰지 않는다. 시장검증 5-2도 같은 방식으로 맞출 예정 (7장).
