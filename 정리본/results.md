# 피치 5·6·7장 — 가설과 결과 (초안)

## 발표에 바로 쓸 내용 · 팀 검토 전

**5장 MVP:** “1·2단계 시험에서 직접 대조한 수치 2건이 원자료와 일치했고, 자료 선택 안내 오류 1건을 발견해 지침을 수정했습니다. 실제 담당자의 시간 절감과 구매 의향은 아직 확인하지 못했습니다.” 11/25 기준 1~3단계 앱 실행 기록이 있고 3단계의 지침 읽기 여부는 미확인이다. 4단계는 앱 밖 시험 실행만 확인했으며, 당시 앱 경로에는 지침이 전달되지 않았다. 5단계 앱 실행과 실제 담당자 사용 기록은 없다. [단계별 상태표](단계별_상태표.md)

**6장 팀:** “두 사람이 단계를 나눠 맡고, 에이전트의 초안과 시험 결과를 사람이 자료와 대조해 검토했습니다.” 당시 담당과 도구별 검토 내용은 아래 표에 정리했다. 현재 발표 역할은 팀 확인이 필요하다.

**7장 요청:** “중구 관광 담당 부서와의 시범 사용을 연결해 주시고, 실제 사업 조건에서 업무 적합성과 구매 가능성을 확인할 기회를 부탁드립니다.” 함께 필요한 자료는 장소 운영시간·휴무와 기존 상품 목록이다. 요청 대상과 문구는 팀 확정 전이다.

**3.0 가설: 신민지(사람1) 확인 필요.** '3.0'은 문서 버전이 아니라 사람1의 작업 단계 번호로 보인다(2.6 테스트 · 3.3 화면설계 · 3.7 발표 개요와 같은 번호 체계) [I]. 3.0 가설만 따로 적은 원문은 찾지 못했다. As-Is/To-Be 비교표의 11/18 초안(커밋 7c895ee)에는 "3.0 가설(사람1)" 언급이 있었으나, 11/20 v1.1(커밋 3e927db)에서 그 문장이 빠지고 지표를 [기획서 10-2(사람1) 지표](AsIs_ToBe_비교표_v1_초안.md)에 맞췄다. 따라서 아래 기획서 v0.3 가설(근거 확인 시간 · 근거 없는 표현 감소)이 3.0 가설과 같은지는 확인되지 않았다. 3.0 가설 원문과 합격 기준값은 신민지 확인 대상이다.

아래 판정은 확인된 기획서 v0.3과 시험 기록을 기준으로 한 초안이다. 실제 담당자의 시간 절감, 표현 감소, 지불 의향은 아직 검증되지 않았다.

기준: 2026-11-25까지 확인된 팀 자료. GitHub 신민지 브랜치의 [11/20 피치 근거 점검표](https://github.com/k-1026/haruharu/blob/%EC%8B%A0%EB%AF%BC%EC%A7%80/%EB%B0%9C%ED%91%9C/1120_%ED%94%BC%EC%B9%98%EA%B5%AC%EC%A1%B0_%EA%B7%BC%EA%B1%B0%EC%A0%90%EA%B2%80.html)는 11/18 파일을 11/20에 개명했다고 기록한다. **3.0 가설만 적은 원문은 아직 찾지 못했다**(위 문단 참고). 아래는 확인된 기획서 v0.3의 가설과 피치 점검표를 대조한 판정 초안이며 3.0 확정본으로 단정하지 않는다.

## 민감도 1위 후보와 요청사항 — 팀 결정 전

**후보: 채택률 r.** r의 근거는 0건이며, n은 0일 수 있고 도구 요금 p는 미확인이다. 사업 전체 예산을 도구 가격으로 쓰지 않는다. 최신 [시장검증 v1.4](시장검증_v1_초안.md) 5-2-1은 과거 민감도 배수와 매출 계산 예가 사업 예산을 p로 사용하고 n 하한을 1로 둔 결과이므로 **발표에서 쓰지 않도록 철회**했다. 따라서 1위는 시범 사용의 우선 확인 후보이며, 최종 선택은 팀 결정이 필요하다. [BM 레드팀](BM_레드팀/redteam_log.md) I-1~I-3 참고.

**발표 요청 문안 후보:** “관광 담당 부서와의 시범 사용 및 구매 가능성 확인을 연결해 주세요.” 시범 사용 1건은 활용 가능성을 탐색하는 시작점이며 채택률을 추정하기에 충분하지 않다. 팀이 1위 가정과 요청 대상·구체적 요청을 확정한다.
