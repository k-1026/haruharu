# 4단계 홍보 검토 — 입력

## 1. 3단계에서 받는 것

`../3.코스_검토/6_출력.md`의 "4단계로 넘기는 것" 블록을 그대로 받는다.

- 확정 코스 (시간표 · 장소 · 순서)
- 장소별 근거 · 운영 주체 후보
- 장소 스토리 (출처 있는 것만)
- 대체 이력
- 겹침 이력 (E7: 장소 · 겹친 기존 상품 · 담당자 선택). "연결하기"를 고른 장소는 문구에서 기존 상품(예: 스탬프 보관장소)을 언급할 수 있다. 운영 주체와 협의된 것처럼 쓰지 않는다
- 남은 경고 (2단계 경고 포함)

1단계 조건 중 **대상 국가 · 언어권**도 함께 받는다. 번역 언어를 정할 때 쓴다.

## 2. 담당자가 고르는 것

| 선택 | 선택지 | 쓰는 곳 |
|---|---|---|
| 톤앤매너 | `[자료 필요: 팀 확정]` (색상 · 분위기) | `7_시안_캐릭터.md` |
| 캐릭터 | 너구리 · 족제비 2인 (고정. 고르는 항목 아님) | `7_시안_캐릭터.md` 2장 |
| 번역 언어 | 영어 · 일본어 · 중국어 간체 · 중국어 번체 (1단계 언어권 기준) | `6_번역.md` |
| 홍보물 종류 | `[자료 필요: 팀 확정]` (예: SNS 카드, 리플릿) | `3_장면_구성.md` |
