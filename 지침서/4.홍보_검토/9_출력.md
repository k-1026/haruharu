# 4단계 홍보 검토 — 출력

## 화면에 나오는 결과

유저플로우 S4의 "장면 → 홍보물 대응표 + 문구 · 번역 초안 + 시안"이다.

## 출력 형식

```
## 장면 → 홍보물 대응표
| 장면 번호 | 장소 | 시간 칸 | 홍보물 | 상태 |

## 장면별 문구
### [장면 번호] [장소]
- 제목: ...
- 본문: ...
- 사실 근거: [출처 ID]
- 경고: ...  ← 없으면 "없음"

## 표현 필터 (E5)
- [장면 번호] 걸린 표현 · 종류  ← 없으면 "없음"

## 번역 초안
| 장면 번호 | 언어 | 번역 | 상태 |

## 시안
- 톤앤매너: ...
- 캐릭터: ...
- 장면별 시안: [장면 번호] ...

## 5단계로 넘기는 것 (이번 범위 밖)
- 확정 문구 · 번역
- 장면 → 홍보물 대응표
- 고른 톤앤매너 · 시안
```

## 5단계가 받는 것

5단계(산출물)는 이번 11일 범위에서 빠졌다. 넘기는 항목은 유저플로우 S4 → S5 기준으로만 적어 두고, 5단계를 만들 때 다시 확인한다.
