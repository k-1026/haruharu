# 3단계 코스 검토 — 입력

## 1. 2단계에서 받는 것

2단계 `출력.md`의 "3단계로 넘기는 것" 블록을 그대로 받는다 (신민지 브랜치 `지침/2_수요근거/출력.md`).

- 조건 (계절 · 체류 기간 · 대상 국가, 언어권) — 1단계 그대로
- 수요 분석 요약 (방문객 · 좋았던 점 · 음식 · 숙박, 문장마다 출처 · 연도 · 표본)
- 근거표 (항목 · 수치 · 출처 · 연도 · 표본 · 대상 · 한계 · 경고)
- 경고 목록(E3)과 담당자 선택 (조건 바꾸기 / 경고를 남기고 진행)

- 블록 항목 확정: `[자료 필요: 사람1과 합의]` — 2단계 `출력.md`에 "코스 검토 담당과 합의"로 남아 있다. 항목이 바뀌면 이 파일과 2단계 `출력.md`를 함께 고친다.

## 2. 장소 운영 정보 (사람1 수집)

| 항목 | 내용 | 없을 때 |
|---|---|---|
| 장소 이름 | 공식 명칭, "대구광역시 ○○구"까지 | 코스에 넣지 않는다 |
| 영업시간 | 요일별 시작 · 끝 시각 | "운영 정보 미확인" 표시 |
| 휴무 | 정기 휴무 요일, 명절 휴무 등 | "운영 정보 미확인" 표시 |
| 이동 시간 | 다음 장소까지 수단 · 분 | "이동 시간 미확인" 표시 |
| 출처 · 확인일 | 출처 ID, 확인한 날 | 미확인으로 본다 |

- 파일 위치: `[자료 필요: 사람1과 합의]` — 후보는 `지침/공통/` 아래 장소 운영 정보 파일 또는 이 폴더 안. 원자료 후보: `research/place_tour/중구_관광지_운영정보.md` (신민지 브랜치).
- 이동 시간을 재는 기준(도보 · 대중교통 · 차량, 어느 서비스 기준): `[자료 필요: 팀 확정]`
