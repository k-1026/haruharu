# 3단계 코스 검토 — 출력

## 화면에 나오는 결과

유저플로우 S3의 "시간표 형태의 코스 + 충돌 표시 + 대체안 + 장소별 근거"다.

## 출력 형식

```
## 조건
- 시기 · 체류 기간 · 대상 국가 (1단계 그대로)

## 코스 시간표
| 순서 | 시간 칸 | 시각 | 장소 | 머무는 시간 | 다음까지 이동 | 충돌 |

## 충돌과 대체안 (E4)
- [충돌 종류] 문구 → 대체안: [장소] / 대체안 없음   ← 없으면 "없음"

## 장소별 근거
| 장소 | 넣은 이유 | 근거 수치 | 운영 정보 | 운영 주체 후보 | 이어받은 경고 |

## 4단계로 넘기는 것
- 확정 코스 (시간표 · 장소 · 순서)
- 장소별 근거 · 운영 주체 후보
- 장소 스토리 (출처 있는 것만)
- 대체 이력
- 남은 경고
```

## 4단계가 받는 것

`4단계로 넘기는 것` 블록이 `../4.홍보_검토/2_입력.md`의 "3단계에서 받는 것"이다. 항목을 바꾸면 4단계 `2_입력.md`도 같이 고친다.

## E6로 다시 넘길 때

4단계 요청으로 코스를 고쳤으면 전체가 아니라 **바뀐 장소 · 시간과 영향받는 장면 번호**만 넘긴다.
