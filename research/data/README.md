# research/data 폴더 안내

| 위치 | 내용 | 규칙 |
|---|---|---|
| `raw/` | 원본 파일 (공공데이터 다운로드, 관광데이터랩 ZIP에서 푼 CSV 등) | 내용 수정 금지 |
| `datalab_regional/` | 관광데이터랩 지역별 현황 정리본 17개 + 계획·명세 문서 | 정리본 (영문 파일명) |
| `data_spec.md` | 데이터 명세 (공용 파일, 수정 전 팀 공지) | 공용 |
| 그 밖의 파일 | 팀원의 빅데이터 정리본(`관광데이터랩_대구광역시동구_빅데이터…` 등)과 기존 정리본 | 아직 정리 전. 팀 확인 후 폴더 정리 예정 |

## 확인 필요
- 루트의 한글 파일명(`관광데이터랩_…_빅데이터…`)은 정리본 규칙(영문)과 다름. 이름 변경은 팀 합의 후
- `datalab_bigdata_raw_ledger.csv`, `datalab_bigdata_collection_log.md`는 팀원 빅데이터 대장·로그 (루트에 그대로 둠)
- 중구·동구 ZIP 원본 대장(원래 파일명·다운로드 시각)은 아직 없음
