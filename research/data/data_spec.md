# 정리본 데이터 설명서

- 정리본은 모두 UTF-8(BOM 없음) CSV이고, 한국관광데이터랩에서 내려받은 CSV를 그대로 옮기거나 합친 것이다. PDF·KOSIS 엑셀에서 추출한 정리본은 아직 없다.
- 원본은 `raw/`에 내용을 바꾸지 않고 보관했다(CSV는 UTF-8 BOM 포함, 업로드·다운로드 파일과 바이트 단위로 같음).
- 원본 파일명은 CLAUDE.md 규칙 `<출처기관>_<지역>_<지표>_<기간>.<확장자>`로 정했다. 모르는 항목은 `지역미확인`·`기간미확인`·`출처미확인`으로 쓴다. 원래 파일명은 아래 표에 남겼다.
- 야간관광 소비 비율 CSV 5개는 사용자 컴퓨터의 데이터랩 다운로드 압축파일(`Downloads/drive-download-20261101T164226Z-1-001/`)과 sha256이 같아, 지역·기간을 원래 파일명에서 확인했다. 나머지는 원래 파일을 찾지 못해 지역·기간을 파일 내용과 기획안 기록으로 정했다.
- 원래 파일명 앞의 시각 접두(예: 20261030091802)는 데이터랩 다운로드 파일명 형식으로, 다운로드 시각으로 보인다(2026-10-30). 이번 작업의 실제 확인일은 2026-11-02다.
