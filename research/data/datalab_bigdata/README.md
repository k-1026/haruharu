# 관광데이터랩 빅데이터 정리본 (datalab_bigdata)

- 작성자: 팀원 (빅데이터 메뉴 수집·정리)
- 출처: 관광데이터랩 > 빅데이터 메뉴 (대구광역시 중구·동구)
- 형식: 열에 `source_file`, `period` 가 있는 정리 파일. 기간은 2022-2025 블록과 월간 블록이 섞여 있음
- 대장: `datalab_bigdata_collection_log.md` (수집 기록), 원본 대장 CSV(`datalab_bigdata_raw_ledger.csv`)는 현재 작업 폴더에 없음 (git 이력에는 있음)

## 파일 묶음

| 묶음 | 파일 예 | 내용 | 구분 표시 |
|---|---|---|---|
| 방문자 수 | `…빅데이터방문자수추이` | 월별 방문자 수 | 외지인(b) / 현지인(a) / 전체(a+b) |
| 외국인 방문 | `…빅데이터외국인방문자수추이`, `…외국인지역별방문자수`, `…외국인방문자거주지(국가)` | 외국인 방문자 수, 출발 국가 비율 | 외국인 |
| 방문자 출발지 | `…빅데이터방문자거주지`, `…빅데이터방문자유출지` | 거주지(시도·시군구) 비율 | 전체 |
| 검색 | `…빅데이터검색건수추이`, `…빅데이터지역별검색건수`, `…빅데이터유형별검색건수`, `…빅데이터지역별관광지검색순위_(유형 8종+전체)` | 카테고리별 검색량, 관광지 검색 순위 | 전체 |
| 소비 | `…빅데이터관광소비추이_구분미확인1·2`, `…빅데이터업종별지출액_구분미확인1·2`, `…빅데이터지역별지출액_구분미확인1·2` | 소비액, 업종 비율, 지역 비율 | **구분미확인** |
| 지역 방문 | `…빅데이터지역별방문자수` | 기초지자체 방문자 수·비율 | 전체 |

## 주의
- **구분미확인** 파일은 외지인/현지인/전체 어느 기준인지 확인되지 않음. 페르소나 근거로 쓰기 전에 기준 확인 필요
- 방문자 수 파일은 `방문자 구분`이 있어 외지인만 골라 쓸 수 있음
- 거주지 비율 합계가 100을 넘음(중구 약 593, 동구 약 598). 기준 모수가 불명확해서 시도별 비율은 상대 비교로만 씀
- 지역별관광지검색순위는 중구와 동구 각각 유형별 파일이 있음

## 지역별 현황 정리본과의 관계
- 같은 사이트의 다른 메뉴(지역별 현황)에서 받은 값과 겹치는 지표가 있음 (예: 외지인 소비, 방문 출발지). 같은 지표는 한쪽 출처만 골라서 쓸 것 (중복 합산 금지)
- 지역별 현황 정리본은 `research/data/datalab_regional/` 참고
