## 주의
- 거리 × 동반 교차표는 없음. 거리는 출발지 분포, 동반은 SNS 언급으로 따로 봐야 함
- 외지인 연령별 소비는 없음 (성/연령별 소비는 내국인 기준이라 제외)
- 2022년 상반기는 방역 완화 과정이라 영향 가능 (팀 판단)
- 입장객 수는 잠정치 가능
- 문서 파일: `관광데이터랩_지역_수집계획.md` (수집 계획), `관광데이터랩_지역통합_명세.md` (열 명세)
