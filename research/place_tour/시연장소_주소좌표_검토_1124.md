## 반영 도구와 보관

- 기존 검토표의 근거 없는 `O`는 검토 완료로 승계하지 않았다. 공식 자료를 대조한 5곳만 `자료대조완료`, 검토자는 `자료대조:Codex`다. 사람의 현장 확인으로 기록하지 않았다.
- `사용=O`만으로는 이제 반영되지 않는다. 현재 장소명·주소 일치, 검토자·검토일·근거 URL·검토근거·검토상태·위치기준, 유한한 위경도와 범위를 모두 검사한다. 하나라도 오류면 전체 반영을 중단한다.
- 기존 검토표를 새 자동검색으로 덮어쓰지 않는다. 반영 전 원본 백업 후 임시 파일을 교체한다. 새 메타 정보가 있는 자료의 미검토 좌표는 지도에 사용하지 않는다. 기존 형식의 별도 자료 파일은 호환을 유지한다.
- 수정 전 두 CSV와 자동 백업은 Git 제외 `app/runs/좌표수정전_1124/`에 보관했다. 기존 장소 18행의 주소·운영정보·출처ID 등 좌표 외 기존 필드는 모두 동일함을 대조했다. 변경은 좌표와 새 좌표 검토 메타 정보다.
- 코스 원본·선택·이동시간·기존 삭제 파일·무관한 자료는 변경하지 않았다. 실제 AI 실행·커밋·push는 이번 작업에서 하지 않았다.

아직 실제 지도에서 입구·보행 경로를 육안 대조한 결과는 아니다. 공식 마커는 시설·권역 대표점이며 길찾기 도착점 확정과 구분한다. 새 코드의 서버 반영은 서버 재시작 후 확인해야 한다.

## 후속 반영: 진입 방향 승인·좌표 수집 자동화·자유식 후보 표시

- 사용자가 추천 진입 방향 반영을 승인했다. 근대골목은 청라언덕 관광센터 기준, 시장·야시장은 서문시장역 쪽 접근으로 안내한다. 김광석길은 방천시장 쪽 접근을 권장한다. 방향 안내와 입구 좌표 확정은 구분하며, 시장 중앙이나 시설 대표점을 입구로 바꿔 기록하지 않았다.
- 진입 방향은 `research/data/시연_진입기준.json`에 별도로 기록하고 저장 코스의 시간표에 안내한다. 코스 원문과 기존 장소·주소를 덮어쓰지 않는다. 국채보상운동기념관 정문은 추가 근거가 없으므로 반영하지 않았다.
- 식당을 확정하지 않아도 추천후보 중 좌표가 검토된 식당을 별도 지도 핀으로 표시한다. 일정 장소는 원·방문 순번, 후보는 마름모·후보명으로 구분한다. 후보들은 방문 연결선에서 제외하고, 명시적으로 제외된 식당도 표시에서 뺀다. 후보에 없는 식당을 새로 추천하거나 선택을 저장하지 않는다. 후보가 없는 자유식 권역에는 임의 식당을 넣지 않는다.
- `python app/좌표받기.py --공식후보`를 추가했다. 등록된 공식 5곳의 URL에서 장소명에 연결된 마커 좌표를 추출하고 `app/runs/공식좌표_후보_<시각>.json`에 새 후보를 저장한다. AI·브라우저를 사용하지 않는다. `사용`·검토자는 빈칸이고 검토 상태는 대기다. 기존 검토표·좌표를 덮어쓰지 않는다. 자료 부족·이름 불일치·좌표 범위 오류는 수집 실패로 남긴다.
- 실제 공식 웹 요청 확인에서는 관광공사 2곳을 수집했고 대구푸드 3곳은 기대한 지도 좌표 본문을 읽지 못해 실패로 남았다. 이것을 좌표 변경이나 검토 완료로 처리하지 않았다. 앞서 공식 페이지에서 확인한 5곳의 검토 좌표는 그대로 보존했다. 신규 장소·다른 공식 사이트는 출처 등록과 추출 형식 지원이 필요하다.
- 서버 8790에서 실행 중인 기획이 없는 것을 확인한 뒤 재시작했다. 저장 코스 조회에 김광석길·향촌 좌표, 저녁 후보 3곳의 좌표와 링크, 시장·야시장·김광석길 진입 안내가 반환되는 것을 확인했다. `/plan/`·JS는 HTTP 200이며 최신 후보 표시 코드가 제공된다. 사용자가 지도 육안 확인을 맡기로 했으므로 이번에는 브라우저를 조작하지 않았다.
- 선택 Python 181개·Node 43개 통과. 후보 1곳의 좌표만 있어도 표시하고, 후보 핀이 동선에 연결되지 않는 것을 모의 검증했다. 전체 시험 완료는 아니며 실제 AI·커밋·push는 하지 않았다.

## 대표 위치·권역을 이용한 동선 보완 (2026-11-25)

- 사용자 요청에 따라 입구 확인과 지도용 대표 위치를 분리했다. 근대골목은 관광공사 청라언덕 대표점, 시장/야시장은 기존 관광공사 시장 대표점, 평화시장과 동성로는 공식 상세의 대표 마커를 사용한다. 이름과 연결된 좌표·주소/권역 설명을 대조한 근거와 검토자는 `research/data/지도_대표위치.json`에 기록했다. 청라언덕 좌표를 관광센터 입구로, 동성로 좌표를 호텔로 확정하지 않았다.
- `장소정보.대표위치()`는 등록 별칭·알려진 권역 후보 접두어·주석만 정리한다. 숙소는 코스 문장에 동성로 일대/권역이 명시됐을 때만 권역을 표시하며 중구/동구 전체를 임의 호텔로 바꾸지 않는다. 공식 대조 자료가 없는 기존 CSV를 일괄 승인하지 않았다.
- `담당자요약.py`는 별도로 작성된 식사표의 권역명이 길어도 일정의 등록 장소명으로 대표 위치를 조회한다. 자유식 방식·식당 선택·숙소 업체·저장 코스는 변경하지 않았다. 자유식 외 식사 방식 미선택도 권역 후보 화면으로 볼 수 있지만 자유식으로 확정하지 않는다.
- 지도와 시간표에 대표 위치·입구 미확인·근거 링크를 표시하고 방문 순서 연결선에 방향을 추가했다. 시장과 야시장의 동일 대표점 라벨은 분리 배치한다. WebGL 대체 도로 지도에도 연결선을 표시한다. 실제 보행 길찾기·이동시간 재검증은 아니다.
- 유휴 서버만 재시작한 뒤 현재 A안 2버전의 실제 API 응답을 JS 지도 모델에 전달해 7개 일정 중 6개 표시점·5개 연결 구간·2개 식사 권역을 확인했다. 미정인 둘째 날 오전 1개는 시간표에 유지했다. 기존에는 대표점 1개로 연결 구간이 없었다. 예전 기록 중 장소 자체가 없는 구간은 새 장소로 채우지 않는다.
- 선택 Python 188개·Node 49개, JS 구문·diff 공백 검사가 통과했다. 전체 시험 완료나 최신 화면 육안 검증은 아니다. 실제 AI 실행·커밋·push 없음. 기존 변경·삭제 파일·무관한 자료는 보존했다.
