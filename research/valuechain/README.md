# 밸류체인 리서치 — 작업 안내

이 폴더는 대구 미식 체류관광의 밸류체인(가치사슬)을 정리하는 리서치 작업 공간이다.
이 README는 폴더 구조, 작업 규칙, 파일별 담당을 정한다. 아직 담당자는 정하지 않았다.

## 1. 기본 정보

- 브랜치: `밸류체인` (이 브랜치에서만 작업한다)
- 담당: 미정 (팀 회의에서 확정 후 아래 3번 표에 기입)
- 상태: 폴더 골격만 있음. 본문 노트·사례 페이지는 아직 작성 전이다.

## 2. 폴더 구조

```
research/valuechain/
├── README.md                 이 파일 (작업 규칙 · 담당 표)
├── 00_출처_대장/             밸류체인 전용 출처 대장 (출처 ID 원장)
├── 01_분석노트.md            01 분석 노트        (주제 미정)
├── 02_분석노트.md            02 분석 노트        (주제 미정)
├── 03_분석노트.md            03 분석 노트        (주제 미정)
├── 04_분석노트.md            04 분석 노트        (주제 미정)
├── 05_분석노트.md            05 분석 노트        (주제 미정)
├── signals.md                신호(변화 징후) 모음
├── stakeholders.md           이해관계자 정리
├── pages/                    사례별 HTML 페이지 + index.html (현재 비어 있음)
├── valuechain_v2.0.md        밸류체인 본문 (마크다운)
└── valuechain_v2.0.html      밸류체인 본문 (HTML 버전)
```

- 01~05 분석 노트의 파일명·주제는 담당이 정해진 뒤 확정한다. 위 이름은 자리표시다.
- `pages/`의 사례 HTML은 `index.html`에서 목록으로 연결한다.
- 파일명은 영문 소문자·숫자·밑줄(`_`)을 기본으로 한다. 이미 있는 한글 폴더명·파일명은 바꾸지 않는다.

## 3. 파일별 담당 (미정)

| 파일 / 폴더 | 담당 | 상태 |
|---|---|---|
| 00_출처_대장/ | 미정 | 미작성 |
| 01 ~ 05 분석 노트 | 미정 | 미작성 |
| signals.md | 미정 | 미작성 |
| stakeholders.md | 미정 | 미작성 |
| pages/ (사례 HTML · index.html) | 미정 | 미작성 |
| valuechain_v2.0.md / .html | 미정 | 미작성 |

- 담당이 정해진 파일은 그 담당자만 수정한다.
- 담당자 이름은 팀이 확정한 뒤에만 적는다. AI가 임의로 이름을 채우지 않는다.

## 4. 작업 규칙

1. **브랜치**: 밸류체인 브랜치에서만 작업한다.
2. **담당 범위**: 파일별 담당자만 그 파일을 수정한다. 담당이 `미정`인 파일은 먼저 팀에 담당을 정한다.
3. **작업 전 pull**: 작업을 시작하기 전에 `git pull`로 최신 내용을 받는다. 커밋하지 않은 변경이 있으면 먼저 상태를 확인하고 보존한다.
4. **근거 표시**: 근거가 없는 내용은 아래 표시를 붙인다.
   - `[U]` (Unverified): 출처·원자료로 확인하지 못한 내용
   - `[H]` (Hypothesis): 팀의 해석·가설·제안. 사실로 쓰지 않는다.
5. **출처 연결**: 모든 사실 주장은 `00_출처_대장`의 출처 ID로 연결한다. 대장에 없는 출처는 본문에 쓰지 않는다.
6. **커밋**: 커밋 메시지는 `docs: 무엇을 바꿨는지` 형식으로 쓴다. 한 커밋에는 의미 있는 변경 하나만 담는다.
7. **main 반영**: `main`에 직접 push하지 않는다. 밸류체인 브랜치에서 PR을 만들어 합친다.
8. **검토**: PR은 팀이 정한 검토자가 확인한 뒤 merge한다.

## 5. 표시 예시

```
- 국내 관광객의 야간 소비 비중이 늘었다. [U]
- 치킨 골목의 야간 매출은 공공 통계 기준으로 높다. [H] (근거 출처: 00_출처_대장 ID 확인 후 기입)
```
