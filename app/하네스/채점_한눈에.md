# 하네스 채점 한눈에 (발표용)

## 하네스란
- 우리 에이전트를 **실제 AI로 돌리고**, 결과를 **코드로만** 채점해 점수표로 남기는 시험 장치입니다.
- 채점에는 AI를 쓰지 않습니다(토큰 0). 같은 기준으로 매번 같은 판정이 나옵니다.
- 시험 조건: 일본어권 · 중구 · 가을 · 1박2일 · 커플 (가상설문 CSV 사용).
- 점수표는 `app/하네스/결과/`에 날짜별로 남고, 이전 실행과 자동 비교합니다.

## 단계별 채점 기준

| 단계 | 무엇을 보나 | 통과 기준 (코드 판정) |
|---|---|---|
| 2 수요 근거 | AI 요약 | 30초 이내 · 3단계 전달 검사 통과 · 기관 자료(가상설문) 반영 · **근거에 없는 숫자 지어내지 않음** |
| 3 코스 | 낮~저녁~숙박 코스 | 60초 이내 · 형식 통과 · 치킨은 저녁 1번까지 · **낮 치킨 식사 없음** · 휴무·운영시간 충돌 없음 · **후보표 밖 장소 없음** · 1박2일 숙박 칸 · A/B안 모두 |
| 3 코스(치킨 선택) | 담당자가 치킨을 고른 경우 | 위 기준 + 후보표와 저녁 후보에 치킨이 실제로 보임 |
| 4 홍보 | 장면별 문구·번역 | 420초 이내 · 제품 검사 통과(첫 시도) · **공개 문구에 내부 ID·'미확인' 없음** · **과장 금지 표현 없음**(원조·최고의·치킨의 수도 등) · 번역 언어·장면 빠짐 없음 · 식비 미정 안내 없음 |
| 5 산출물 | 결재 파일·제안서·홍보물 묶음 | 오류 없음 · 세 파일 모두 생성 · 코스·경고 대조 불일치 없음 · 코스 장소가 세 파일에 모두 나옴 · 남은 경고 보존 · 공개 파일에 내부 표시 없음 |

## 최근 결과 (2026-11-27)

| 단계 | 시간 | 결과 |
|---|---|---|
| 2 수요 근거 | 15.5초 | 4/4 통과 |
| 3 코스 / 치킨 선택 | 25.8초 / 29.6초 | 모두 통과 |
| 4 홍보 | 124.1초 | 7/7 통과 |
| 5 산출물 | 0.01초 (AI 없음) | 6/6 통과 |

## 하네스로 잡아낸 것
- 치킨이 코스 이름에서 빠져 0개로 세던 문제 → 후보표 이름으로 대조해 바로잡음.
- 결재 파일·제안서는 공개 문서라 경고를 빼는 설계임을 확인 → 경고는 내부 기록에 모두 남는지로 채점.
- 4단계 AI 입력이 약 18만 자로 매우 큼 → 발표 뒤 줄일 과제로 기록.

## 코드가 보지 않는 것 (다음 과제)
- 스토리가 사실인지, 출처 등급이 맞는지 같은 **판단이 필요한 항목**은 검증 에이전트로 볼 예정입니다.
