# 단계 연결 초안 시험

기준은 사용자가 승인한 PR #10이 병합된 `integration/stage-1-5`이다. 이 문서는 담당자와 합의되지 않은 JSON을 운영 기준으로 확정하지 않는다.

## 실행 범위

```powershell
cd C:\Users\admin\Desktop\haruharu\app
python -m unittest discover -p "test_*.py" -v
python orchestrator.py
```

기본 실행은 1→2와 3단계 전달 검사까지다. 검사 통과 후 시작·종료·식사·식비·오전 구성·운영 방식을 담당자에게 묻고 `코스작성조건_선택.json`과 전달 JSON에 저장한다. 모르는 것은 Enter로 미정 유지. 실제 AI 사용에는 Claude 인증·모델 접근이 필요하다.

```powershell
python orchestrator.py --통합시험
```

이 옵션은 실제 3·4단계 AI 호출을 추가한다. 현재 개인 checkout에 3·4단계 파일이 없다면 호출 전에 대기 상태와 필요한 파일 경로를 기록한다. 최신 개인 수정과 통합 브랜치의 `지침/3_코스검토/`, `지침/4_홍보검토/`, `.claude/agents/코스검토.md`, `.claude/agents/홍보검토.md`, `.claude/skills/홍보문구/`를 함께 갖춘 환경에서 사용한다. 브랜치 전체를 덮어쓰지 않는다.

- 기본 실행의 입력·결과를 보존하고 별도 `통합시험_시각/` 폴더에 3·4단계 입력·원문·검사·담당자 선택을 기록한다.
- 3단계의 JSON·참조·확정 조건을 검사한 뒤 담당자의 실제 확인을 받아야 4단계를 호출한다. 오류·초안 선택이면 중단한다.
- 4단계는 문구·번역·배치 계획의 JSON 초안이다. 실제 이미지가 생성됐다는 뜻이 아니다. 번역 상태는 AI 초안이다.
- JSON 오류·AI 실패·없는 파일은 대기로 남긴다. 무한 재호출·자동 확정·5단계 호출은 하지 않는다.
- 원표 수치 대조, 4단계 문구·번역 검토, G5/G17 결정, 현장 운영 확인은 별도다.

## CRLF 확인

`test_코스조건`은 실제 CRLF 바이트 파일을 만들어 `에이전트_읽기`가 머리와 도구를 분리하는지 시험한다. 현재 `Path.read_text()`가 줄바꿈을 정규화해서 통과했다. CRLF를 확정 원인으로 간주한 코드 변경은 하지 않았다. 다른 문제가 생기면 BOM·파일 머리·실제 SDK 입력을 별도로 재현한다.
