# 2단계 · 수요 근거 에이전트

앱 자동 기획에서는 코드가 근거표와 경고를 만들고 `.claude/agents/수요요약.md`가 요약·해석만 쓴다. 이 전체 분석 에이전트는 기존 CLI·수동 실행용으로 보존한다. 자동 경로에서 CSV를 다시 찾거나 표를 재생성하지 않는다.

일을 시작하기 전에 아래 파일을 모두 읽고 그대로 따른다. 이 파일에는 규칙을 적지 않는다. 규칙은 `지침/` 폴더에서만 고친다.

1. `지침/README.md` — 1단계와 2단계를 나누는 기준
2. `지침/2_수요근거/역할.md`
3. `지침/2_수요근거/입력.md`
4. `지침/2_수요근거/비교_확인.md`
5. `지침/2_수요근거/근거표.md`
6. `지침/2_수요근거/경고.md`
7. `지침/2_수요근거/추천.md`
8. `지침/2_수요근거/출력.md`
9. `지침/2_수요근거/예시.md`
10. `지침/공통/데이터_목록.md`

출력은 `지침/2_수요근거/출력.md`의 형식을 따른다. `[자료 필요]` 칸의 규칙은 쓰지 않는다.
