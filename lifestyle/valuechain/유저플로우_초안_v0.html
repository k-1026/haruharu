2. 예외·수정 경로

주황색 점선입니다. 각 경로에 어디서 어디로 가는지 적었습니다.

E1 · 근거 부족

발생 위치: ② 수요 근거 확인
  1. 조건 변경 → ① S1에서 조건을 고친 뒤 다시 ②로
  2. 자료 재검토 → ② S2에서 다른 자료나 같은 자료의 기준을 다시 확인
  3. 한계 확인 후 진행 → ③ S3. 미확인 항목은 표시를 남기고 다음 단계로 이어짐
미확인 항목은 S5 기획안의 '가정·추가 확인'에 옮길지 여부를 정해야 함 설계 제안
확정 세 가지 선택지 · 설계 제안 표시 방식

E2 · 운영 조건 충돌

발생 위치: ③ 코스 검토
  1. 영업일·휴무·이동 시간이 코스와 맞지 않음
  2. 담당자가 충돌 구간을 확인하고 ③에서 수정
운영 조건을 확인해야 한다는 것까지 합의. 시스템이 자동으로 충돌을 찾는지, 진행을 막는지는 정하지 않음
확정 담당자 확인·검토 · 미정 자동 판별·진행 차단

E3 · 코스 변경 후 홍보 재검토

발생 위치: ④ 홍보 검토
  1. 홍보물을 보다가 코스를 고쳐야 함
  2. → ③ S3에서 코스 수정
  3. → ④ S4로 돌아와 홍보 내용을 다시 검토한 뒤 ⑤로
바뀐 코스에 맞는 홍보물을 어떻게 표시할지는 미정
설계 제안 수정 → 재검토 경로 · 미정 재검토 표시 방식

E4 · 당일형 선택

발생 위치: ① 상품 유형 선택
  1. 당일형을 고르면 숙박 구간을 뺀 설정을 적용
  2. 그래도 ② S2 수요 근거 확인을 거친 뒤 ③으로 진행
당일형은 계절·방문 특성에 따른 선택 옵션이며 오류 경로가 아님
확정 ②를 건너뛰지 않음 · 설계 제안 숙박 구간 제외 방식

E5 · PDF 저장 실패

발생 위치: ⑤ 기획안 저장
  1. 저장이 실패하면 실패 메시지를 보여 줌
  2. → ⑤ S5에서 다시 저장을 시도
설계 제안 실패 메시지와 재시도 · 미정 실패 원인 안내 범위

3. 자동 기능과 담당자 확인 구분

'확인해야 한다'와 '시스템이 자동으로 판별한다'는 다른 기능입니다. 아래는 합의 상태를 구분한 표입니다.

기능상태방식
운영 조건(영업일·휴무·이동 시간) 확인확정담당자가 확인하고 검토
운영 조건 충돌 자동 표시설계 제안자동 표시 또는 담당자 체크 중 선택 필요
충돌이 있으면 다음 단계 진행 차단미정합의 없음
미확인 항목을 기획안 '가정·추가 확인'에 자동 기재설계 제안담당자 확인 후 기재도 가능
코스 변경 시 홍보물에 재검토 표시설계 제안표시 방식 미정
검토 완료 표시 전 PDF 저장 제한미정제한 여부와 확인 방식 모두 미정

4. 참고: 여행객 관광 동선

담당자가 기획하는 결과물의 내용입니다. 담당자의 서비스 이용 흐름이 아닙니다.

기획 대상 동선 (기본안)

① 중구 낮 관광 (근대골목 · 스탬프 거점, 선택)

② 저녁 치킨 스토리 체험 — 치킨 스토리는 포함, 저녁 배치와 체험 여부는 고정하지 않음

③ 동구 숙박 (숙박형 기본)

중구→동구는 기본안이며 필수 동선이 아닙니다. 당일형 옵션은 계절·방문 특성에 따라 선택합니다. 스탬프를 달성하면 상품을 받을 수 있으나 기준은 미정입니다.

5. 가정과 미정

설계를 위해 둔 가정과 아직 정하지 않은 항목입니다. 확정 기능이 아닙니다.

임시 가정

  • 담당자 1명이 S1부터 S5까지 진행한다 (인터뷰 미실시)
  • 수요 자료는 출처·시점·분모가 적힌 표 형태로 준비되어 있다
  • 구분 표시(지역·소비·활동)는 자료 적용 범위 안에서만 해석한다
  • 담당자의 불편·시간 부담·서비스 이용 의향은 검증된 사실이 아니라 가설이다

미정

  • 코스 초안 생성 방식
  • 스탬프 달성 조건과 상품 수령 조건
  • 번역 언어와 범위
  • 캐릭터 활용 방식, 영상 제작·활용 범위
  • PDF 생성 방식, 운영 주체 전달 방식 (후속)
  • 당일형 선택 기준의 구체 조건
  • 예산 입력의 단위·범위

6. 논리 수정 사항 (v0 대비)

문서의 논리를 고친 부분입니다. 색과 배치 같은 디자인 변경은 여기에 넣지 않았습니다.

  1. E1 근거 부족: 진행 선택지를 세 가지로 나눔. 조건 변경 → S1, 자료 재검토 → S2, 한계 확인 후 진행 → S3.
  2. E4 당일형: S1에서 S3로 바로 가던 경로를 고침. 당일형도 S2를 거친다.
  3. 코스 변경·홍보 재검토: S3 수정 → S4 재검토 경로를 명시.
  4. 치킨 스토리: "고정 포함"을 치킨 스토리 포함으로 한정. 저녁 배치와 체험 여부는 고정하지 않음.
  5. 홍보 콘텐츠: 영상 대본 검토를 빼고 방향·문구·번역 검토를 기본으로 함. 캐릭터·영상은 미정.
  6. 자동 기능: 충돌 자동 판별, 미확인 자동 기재, 저장 제한을 설계 제안 또는 미정으로 낮춤.
  7. 화면 구성: S4 스탬프 조건을 S3 안의 설정 영역으로 합치고, 저장 완료는 별도 화면 없이 S5의 메시지로 처리. 설계 제안으로 표시.
  8. PDF 저장: '저장' 행동에 성공·실패 결과를 연결 (E5 추가).
