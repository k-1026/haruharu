# 프로젝트 정리 — 우리가 가야 할 방향 (2026-11-15)

> 상태: 팀 검토용 초안. 커밋 전. 지금까지 조사와 판단을 한 장으로 정리했다.

---

## 1. 한 줄 결론

**대구 중구를 중심으로, 외국인 관광투어 코스를 설계하는 "근거 체크형 기획 도구"를 만든다.**
고객은 **공공기관 담당자**이고, 1차 고객은 **중구청 관광과 관광콘텐츠팀**이다.

---

## 2. 고객 (누가 쓰는가)

| 순서 | 고객 | 왜 이 팀인가 | 확인 상태 |
|---|---|---|---|
| **1차** | 중구청 관광과 관광콘텐츠팀 | 중구 투어를 직접 기획·발주한 팀 (동성로 타임워프 용역, 비비드 동성로 투어) | [P] 공고·기사 확인 |
| 2차 | 대구문화예술진흥원 관광콘텐츠팀 | 상품 개발·시범 투어·판로 지원 업무 | [P] 조직도 확인 |
| 3차 | 대구문화예술진흥원 관광마케팅팀 | 외국인 유치·인센티브·해외 홍보 (근거를 쓰는 쪽) | [P] 조직도 확인 |

**주의**
- 여행사는 기획 주체가 아니다 (팀 확인). 고객은 공공기관 담당자다.
- 발주처 명칭: "대구관광재단"은 쓰지 않는다. 관광 업무는 **대구문화예술진흥원 관광본부**가 맡는다.
- 기존 고객여정지도·유저플로우(발표 전 v0)는 **전면 재작성**이 필요하다.

---

## 3. 어떤 에이전트로 갈 것인가

| 안 | 내용 | 평가 |
|---|---|---|
| A. 코스 생성기 | 조건을 넣으면 코스를 만들어 줌 | 기존 근대골목·비비드 투어와 중복 위험. 가장 약함 |
| **B. 근거 체크형 기획 도구 (추천)** | 조건 입력 → 코스 초안 → **근거 출처·시점·공백 표시** → 다국어 홍보안 | 실패 사례(근거 부족, 홍보 부족)를 직접 막음 |
| C. 판로·상품 준비 지원 | 업체 상품 등록과 상세페이지 보완 | 진흥원 판로 용역과 맞음. 기획 도구와는 다른 사업 |

**추천: B안.** 기획 도구이되, 모든 기획안에 **근거 등급과 "확인되지 않은 부분"을 자동으로 표시**한다.

## 4. 지금 근거는 얼마나 확실한가

| 주장 | 근거 | 상태 |
|---|---|---|
| 외국인은 중구 낮 관광지에 몰린다 | 서문시장 83.6%, 동성로 76.9%, 약령시 33.6%, 근대골목 30.1% (KOSIS 2024, n=1,010) | **확실** (공식 통계) |
| 외국인은 대구에서 숙박한다 | 대구 숙박 89% (KOSIS 2024) | **확실** (단, 구별 위치 없음) |
| 중구에 외국인 방문자가 많다 | 구별 외국인 방문자 2025: 중구 419,924 (관광데이터랩 빅데이터) | **부분** (연인원 정의, 공항 효과 주의) |
| 동구 숙박 수요가 많다 | 숙박 검색 상위 호텔이 동구 중심 | **약함** (외국인 구분 없음, 검색량) |
| 저녁 음식 수요가 어디인지 | 추천 음식 김밥·찜갈비 등 (장소별 자료 없음) | **약함** |
| 동구 저녁 수요 | 자료 없음 | **없음** |
| 중구 투어 수요가 있다 | 비비드 투어 참여 2명 (1회 운영) | **실패 사례** (상품 설계·홍보 문제) |

## 5. 무엇을 보완해야 하나 (우선순위)

1. **고객 확정** — 중구청 관광콘텐츠팀 기준으로 고객여정지도 재작성
2. **차별점 찾기** — 근대골목 투어(1~5코스, 다국어 있음)와 겹치지 않는 구성
   - 후보: 야간 동성로, 서문야시장(금·토·일 19~23시), 1박 구성
3. **다국어 홍보 설계** — 비비드 투어는 영어 팸플릿만 있어서 실패. 산출물에 번역과 홍보물을 포함
4. **숙박은 "옵션"으로** — 구별 외국인 숙박 자료가 없음. 숙박 근거를 주장으로 쓰지 않음
5. **동성로 해석 주의** — 방문율 76.9%는 "관광지 방문"이다. 투어 참여자는 동성로 상권을 쓰지 않았음 → "소비"로 읽으면 안 됨
6. **데이터 정의 확인** — 관광데이터랩 "외지인"은 비거주 방문자 (외국인만 아님). 방문자 수는 날짜별 중복 집계(연인원)
7. **사실 정정 반영** — 신세계 대구점은 동구, 동화사(동구)가 방문율 29.7%로 누락돼 있었음. 팔공산 케이블카·옻골마을은 동구, 이월드는 달서구

## 6. 하지 말아야 할 것

- 호텔 리뷰·패키지를 깊게 파는 것 (지금 단계에서 우선순위 낮음)
- 관광데이터랩 "지역관광진단" 증감률을 근거로 쓰는 것 (외지인 기준, 증감률만 확인)
- 구 유입·유출 지역(수성·북구·달서)을 관광 유입으로 읽는 것 (대구 내부 이동)
- 기획 수요를 "진흥원 발주"로 단정하는 것 (진흥원 발주는 판로·SNS 실행 용역 중심)
- 이벤트 용역(동성로 타임워프 페스타)을 투어 수요 근거로 쓰는 것

## 8. 다음 단계 (순서)

1. **비비드 투어 원문 확인** — 중구청 보도자료·관광 홈페이지에서 코스, 가격, 운영 조건 확인
2. **근대골목 투어 현황 확인** — 기존 1~5코스와 다국어 자료 목록화 → 중복 범위 확정
3. **차별점 후보 비교표** — 야간 동성로 / 서문야시장 / 1박 구성 중 무엇이 기존과 겹치지 않는지
4. **고객여정지도 재작성** — 중구청 관광콘텐츠팀 기준 (As-Is → 감정·불편 → 페인포인트 → To-Be 유저플로우)
5. **방향 문서 정리** — 위 결과를 반영해 `direction_basis_draft.md` 갱신
