단계 사이에 넘기는 것

넘김내용
① → ②조건(계절 · 대상 언어권 · 지역 · 체류 기간(당일 / 1박2일 / 추천받기)), 골라 둔 데이터 목록, E1 알림 여부
② → ③조건 + 확정 체류 기간, 담당자 선택(E3), 수요 분석 요약, 근거표 전체(근거 ID R), 경고 목록(경고 ID W + 적용 근거 ID), 대구 도착 · 출발 지점 참고자료(없으면 "미확보")
③ → ④확정 코스(시간표 · 장소 · 순서, 시작 · 종료 장소와 시각 포함, 가정값 표시), 식사 구성(식사시간 · 권역 · 식당 후보, 고정 메뉴 / 자유식), 장소별 근거 · 운영 주체 후보, 대체 이력, 겹침 이력(E7), 남은 경고
④ → ⑤코스 카드(홍보물 묶음 맨 앞), 확정 문구 · 번역(AI 초안 / 검토 중 / 검토 완료(검토자 · 날짜)), 장면 → 홍보물 대응표, 톤앤매너 · 시안, E5 · E6 기록
①~③ → ⑤① 조건 요약 · E1, ② 근거표 · E2 · E3, ③ 확정 코스(④와 같은 확정 시작 · 종료 포함) · 장소별 근거 · 운영 주체 후보 · E4 대체 이력 · E7 겹침 이력 (⑤는 1~4단계 결과를 모두 받음)
③ ↔ ④ (E6)바뀐 장소 · 시간, 영향받는 장면 번호

원칙과 미정 항목

에이전트는 표시와 제안만 하고, 진행할지는 담당자가 정합니다. 경고 · 충돌 자체만으로 차단하지 않지만, 이미 합의한 담당자 선택과 확정 조건(② 담당자 선택, ③ 시작 · 종료 · 노선 겹침 선택)은 충족해야 합니다. 경고는 다음 단계까지 따라갑니다.

미정 [팀 확정 전]: 기관 데이터 세부 처리(CSV · XLSX는 제안, 열 맞추기 방법 미정) · 진행 · 대기 구분 확정 · "다시 확인 필요" MVP 포함 여부 · "근거 약함" 기준값 · ② → ③ 넘김 형식과 3 · 4 → 5 JSON 필드 이름 · 시안 도구와 캐릭터 사용 범위 · 언어권과 번역 언어 범위 · 4단계 통계 사용 방식(G5 · G17) · 치킨 시식권 · 쿠폰(향후 검토) · 톤앤매너 · 홍보물 종류 선택지 · ⑤ 파일 형식 · 결재 기본 양식 · E8 번호

정리됨 (11/20 합의): R · W 전달과 ③ 진입 조건 · 코스 시작 · 종료 · 캐릭터 너구리 · 족제비 고정 · 번역 상태 3종과 담당자 검토

⑤ 산출물은 1~4단계 결과를 묶기만 합니다. 새 수치 · 장소 · 문구를 만들지 않고, E1~E7 경고와 [미확인] 표시는 세 파일에 그대로 따라갑니다.

확인 필요: E1 · E4 · E5의 예시(겨울 당일형 무박 비율, 월요일 휴장, 순위 표현)는 역할표의 예시이며 원자료로 아직 확인하지 않았습니다.
