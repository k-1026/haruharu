# 코스 초안 수동 수정

사용자 요청: 2일차 점심 포함 여부와 시작·종료 입력을 AI 재호출 없이 기존 초안에 반영한다.

- 기존 관리자 서버와 입력 폼을 확장한다. 원본 결과를 덮어쓰지 않고 같은 회차에 새 수정본을 만든다.
- 점심 선택은 포함/미포함/미정, 당일은 해당없음이다. 선택값만으로 임의의 점심 시각·권역·식당을 만들지 않는다. 포함 시 없는 식사 칸은 시각·권역 미정으로 추가한다. 미포함 시 해당 칸만 제외하고 선택 이력은 보존한다.
- 시작·종료는 지정한 값만 바꾼다. 기존 시간표를 자동 이동하거나 이동시간·영업정보를 재계산하지 않는다. 영향 구간을 재검토 대기로 표시한다. 담당자 확정·4단계 실행은 하지 않는다.
- 다른 운영 방식·1일차 식사 변경을 이 기능이 몰래 반영하지 않는다. 해당 변경이 섞이면 구체적으로 알려 저장을 중단한다. 2일차 점심 식사 조건은 함께 반영한다.
- 테스트: 원본 보존·포함/제외/미정·안별 칸ID·입력 검증·AI 미호출·HTTP 저장·화면 수정 대상 유지와 버튼 동작.
- 화면 반영 버튼과 AI 시작 버튼을 구분하고, 저장된 수정본의 시간표·변경 내용·재검토 항목을 보여준다.
- 이 작업은 기존 통합 브랜치에서 진행한다. 커밋·push·다른 담당자 지침 변경 없음.

## 후속: 일차·시간 범위 검사

사용자 요청으로 시작·종료 일차 선택과 순수 시간표 검사(`app/시간표검사.py`)를 추가한다. 이전 기록은 미정으로 유지하며, 시작 전·종료 후·머무는 시간 초과·같은 안의 겹침을 검사한다. 조건부 충돌·확인 대기는 확정 충돌과 구분한다. 시간표 자동 재배치와 이동시간 추정은 하지 않는다. 기존 수정본으로 재검사하고 사용자의 일차 선택을 대신 기록하지 않는다.
