# 장소 선택과 운영정보 우선 표시 (2026-11-23)

사용자 요청: 전체 여행 시작·종료로 명칭 변경, 후보 검색/선택과 직접 입력, 보유 운영정보 먼저 표시, 누락/충돌 중심 확인. AI 재실행 금지.

- 장소·이동 CSV를 읽기 전용으로 연결한다. 임의 검색어를 장소로 단정하지 않고 이름 일치와 명시적 지역 접두어/부가설명만 정규화한다.
- 후보 검색은 시작·종료, 지정 식당, 일정 장소에 공통 적용한다. 저장된 운영시간·휴무·출처·확인일은 참고 자료이며 사람 확인 체크를 자동 생성하지 않는다.
- 기존 기간은 요약하고 미정 구간만 먼저 펼친다. 운영정보의 누락·마감 초과를 먼저 보여 주고 모든 상세 입력은 다시 열 수 있다.
- 상시 기획/특정 출발일 시험을 구분한다. 상시 기획은 날짜 없이 저장 가능하며 운영 요일·계절 조건을 남긴다. 실제 날짜 미확정은 실제 운영 및 기존 4단계 확정 준비 검사에서 대기 상태로 보존한다. 상시 상품의 최종 확정 기준은 팀 합의로 남긴다.
- 시험: 명칭 매칭(낮/야시장 혼동 금지), 출처/확인값 보존, 누락과 시간 충돌, 저장/재조회, 날짜 없는 상시 초안, AI 호출 없음. 커밋·push 없음.

구현 및 자동시험 완료: Python 115개, Node 28개 통과. 실제 조회 API로 후보 16개와 기존 코스 7개 일정/7개 운영 대상 확인. 브라우저 육안 확인은 미실행. 원본 자료·실제 사용자 확인값 보존.
