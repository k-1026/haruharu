# 기획자 화면 간소화

사용자가 승인한 흐름: 기본 조건 → 저장된 제안 코스 → 필요한 부분만 수정. AI 미호출.

- 1·2단계의 기존 대상/지역/체류 조건은 이어받은 값으로 요약한다. 현재 연결에 없는 1·2단계 재실행 기능을 새 입력처럼 가장하지 않는다.
- 전체 여행 조건은 필요 시 펼치고, 코스 일정은 기본 화면에서 바로 보여 준다. 개별 일정 수정과 초안 저장을 주 동작으로 둔다.
- 식사 방식·식비·2일차 오전 선택은 기존 값/미정 상태를 보존한다. 다른 값으로 자동 선택하지 않는다.
- 운영시간·출처·원문·전달 검사·실행 이력·AI 시험 버튼은 관리자 상세로 이동한다. HTML form 연결과 변경 감지·저장 데이터는 유지한다.
- 지침의 확정 조건과 앱이 추가한 운영 점검을 구분한다. 지침을 화면에 맞춰 고치지 않고, 기존 앱의 엄격한 준비 검사와 지침 간 차이는 미해결로 명시한다. 이번에는 자동 확정/4단계 실행을 추가하지 않는다.
- Node에서 화면 배치/폼 연결/직렬화/수정 저장을 검증하고 기존 Python 회귀시험을 유지한다. 원본 코스·미정 값·사용자 체크를 임의 변경하지 않는다.
