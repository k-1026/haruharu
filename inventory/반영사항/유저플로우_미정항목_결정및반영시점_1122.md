실제 앱·화면 파일 경로는 작업 시작 시 확인한다. 위 표를 이유로 없는 파일을 만들거나 상대 담당자의 브랜치를 임의로 수정하지 않는다.

### 관련 작업을 할 때 따를 순서

1. 이 목록과 최신 유저플로우를 읽고, 이번 작업에 해당하는 행만 고른다.
2. 이미 합의·반영됐는지 원문과 현재 파일로 확인한다. 이 목록의 옛 상태 때문에 끝난 일을 다시 하지 않는다.
3. 합의된 내용은 사용자 요청 범위 안에서 해당 문서·지침·화면·코드에 반영하고 확인한다.
4. 아직 결정이 필요한 내용은 임의로 확정하지 않는다. 해당 기능에 결정이 꼭 필요하면 구체적인 선택만 사용자에게 묻고, 독립적인 작업은 계속한다.
5. 구현·시험을 실제 확인한 뒤 이 목록에 결정 내용, 반영 파일과 남은 일을 기록한다. 담당자 합의나 시험 완료를 대신 꾸며 적지 않는다.

저장소 AGENTS.md와 CLAUDE.md에 이 확인 절차를 연결한다. 별도 감시 프로그램이나 예약 실행은 아니다. 관련 작업 시 해당 지침을 읽는 AI가 확인하도록 하는 규칙이다.

## 1. 폴더 사용 방법

이 폴더에는 앞으로 결정하거나 다른 문서·지침·앱에 반영할 일을 모은다. 확정된 업무 규칙은 유저플로우 본문과 단계별 지침에서 관리하고, 여기는 결정·반영 상태를 확인하는 용도로 쓴다.

- 파일명은 주제 뒤에 작성일을 붙인다. 예: 유저플로우_미정항목_결정및반영시점_1122.md
- 날짜는 이 문서의 작성일이다. 모든 항목의 마감이 11월 22일이라는 뜻은 아니다.
- 결정됐다고 바로 완료가 아니다. **내용 합의 → 관련 문서·지침 반영 → 구현·시험 확인**을 구분한다.
- 예진님 확인이 필요한 항목도, 영향을 받지 않는 민지님 담당 작업까지 멈출 이유는 아니다.

## 3. 지금 다시 합의할 필요가 없는 내용

유저플로우와 보완안에 이미 합의로 기록된 내용이다. 실제 지침·앱 반영 여부는 별도로 확인한다.

- 조건은 계절·언어권·지역·체류 기간이며 지역 기본값은 없다.
- 관광·저녁·숙박 장소의 지역을 “낮 중구·숙박 동구”로 고정하지 않는다. 당일형에는 숙박을 넣지 않는다.
- 코스 시작·종료는 담당자가 지정하거나 제안을 확인한다. 미정이어도 초안은 만들 수 있고 확정 전에는 확인한다.
- 노선 겹침이 발생하면 E7 선택이 있어야 코스를 확정한다. 장소 겹침만 있는 경우의 처리는 보완안 합의에 따른다.
- R·W를 다음 단계에 전달하며 2단계의 담당자 선택과 확정 체류 기간을 확인한다.
- 캐릭터는 너구리·족제비 2인 고정이다. 배치 범위와 시안 생성 도구는 별도 미정이다.
- 번역 상태는 AI 초안 / 검토 중 / 검토 완료(검토자·날짜)다. 검토·확정은 담당자가 맡기며 역번역만으로 검토 완료로 바꾸지 않는다.
- 픽업·교통편 제공은 현재 기획에 새로 넣지 않는다. 향후 기차 등 교통 연계 가능성은 열어 둔다.
- 5단계는 앞 단계의 확정 결과를 묶는다. 새 수치·장소·문구를 만들어 채우지 않는다.

## 4. 지금 진행할 일

1. **문서 그림 갱신:** 현재 HTML·PNG가 이미 수정됐는지 먼저 확인한다. 미반영 부분이 있으면 Markdown v1.2를 기준으로 HTML의 상자·분기·전달표를 수정하고, 확인한 HTML을 PNG로 다시 캡처한다. 미정 항목은 그림에도 “팀 확정 전”으로 표시한다. 모든 미정을 해결할 때까지 기다릴 필요는 없다.
2. **1·2단계 기본 흐름:** 기관 데이터 “없음” 경로부터 오류 수정 후 재시험하고 결과 화면을 준비한다.
3. **단계 연결 전 합의:** 보내는 쪽·받는 쪽이 같은 예시로 전달 항목과 검사 기준을 확인한다.
4. **후속 단계 준비:** 4단계 선택지와 5단계 문서 양식은 해당 기능 구현 전까지 맞춘다.

### MVP 구현에 대한 권고 — 팀 확정 전

- 관리자·담당자 화면 구성은 [관리자 화면 구성안](../관리자화면_기획기록_구성안_1122.md)을 참조한다. 화면은 아직 구현하지 않았다. 고객의 코스 조건 입력과 운영팀 로그 조회를 구분한다.

- “다시 확인 필요” 표시는 오래된 결과를 최신 결과로 착각하지 않게 하므로 MVP 포함을 권한다.
- 처음에는 앞 단계 변경 시 관련 뒤 단계 전체를 재확인 대상으로 표시해도 된다. 장면별 정밀 추적은 이후로 미룰 수 있다.
- 불일치가 남은 결과를 저장한다면 초안임을 표시하는 방안을 검토한다. 현재 유저플로우의 “저장 허용”만으로 최종본 판정을 대신하지 않는다.
- 임시 선택을 쓰면 시험값·제안·예시임을 표시한다. 임시 선택이 자동으로 팀 확정 사항이 되는 것은 아니다.
