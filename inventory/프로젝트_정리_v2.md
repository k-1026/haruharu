## 1. 무엇을 만드는가

**중구 관광 기획 도구**입니다. 담당자가 조건을 넣으면 다음을 만듭니다.

1. **코스 초안:** 낮 관광, 저녁, 숙박 선택 (숙박형 / 당일형)
2. **근거표:** 각 장소와 수치의 출처, 확인되지 않은 부분 표시
3. **다국어 홍보 초안:** 코스가 바뀌면 함께 갱신
4. **체류 인증 체크포인트:** 저녁까지 머물렀음을 확인하는 스탬프 설계
5. **음식 선택지:** 선호 음식을 고르면 해당 식당을 포함 (치킨은 고른 경우에만)
6. **인센티브 참고 표시:** 진흥원 요건 충족 여부를 참고용으로 표시

**첫 납품:** 중구청 관광콘텐츠팀에 "중구 야간·1박 연계 기획안" (낮 상품과 겹치지 않는 저녁·밤 구성, 치킨 해설 요소 포함)을 도구의 첫 결과물로 제출합니다.

## 2. 지금까지 어떻게 여기까지 왔나

| 단계 | 방향 | 바뀐 이유 |
|---|---|---|
| 1 | 외국인 대상 1박2일 상품 (재단 발주 가정) | 출발점 |
| 2 | 중구 단독 vs 중구+동구 혼합 비교 | 동구 근거가 약함. 발표에서 혼합이 1점 차로 1위 |
| 3 | 치킨을 메인 콘셉트로 한 "치킨의 수도" 안 | 외국인 치킨 선호 3.8%로 근거 부족 |
| 4 | 치킨은 요소, 제목은 "낮은 대구 여행, 저녁은 골목에서" | 발표 결론 |
| 5 | 재단을 발주처로 가정 | 재단 명칭과 역할 확인 |
| 6 | 발주처를 진흥원 관광본부로 정정 | 대구관광재단은 진흥원에 속함 |
| 7 | 고객을 공공기관 담당자로 정함 | 여행사는 기획 주체가 아님 |
| 8 | 고객을 중구청 관광콘텐츠팀으로 좁힘 | 중구 기획 발주 기록 확인 |
| 9 | 치킨 스탬프, 캐릭터, 에이전트를 아이디어로 검토 | 치킨 요소를 살리려는 시도 |
| 10 | 상품 과잉 확인 후 **도구 중심**으로 정리 | 중구에 상품이 많아 상품 추가는 중복 |
| 11 | **도구 채택**, 설계는 지역 확장형, 데이터는 중구 | 근거, 데이터, 발주 가능성의 균형 |
| 12 | 로드맵 정리 (1단계 중구 외지인, 2단계 중구+동구) | 지역은 누적, 동구는 2단계 |
| 13 | 시기별 구조와 음식 선택지 추가 | 여름 당일치기 비율과 선호 음식 반영 |

**정리하면:** 상품을 만드는 쪽에서 **상품을 조합하고 홍보하는 도구** 쪽으로 옮겨 왔습니다. 치킨은 메인에서 **선택지와 해설 요소**로 자리를 잡았습니다.

## 4. 고객과 수주 대상

| 구분 | 기관 | 역할 |
|---|---|---|
| **1차 (MVP 발주처)** | 중구청 관광과 관광콘텐츠팀 | 도구 납품, 첫 기획안 |
| 2차 | 동구청 문화관광과 | 중구 실적 이후 동구 확장 |
| 협력 후보 | 대구문화예술진흥원 관광본부 | 지금은 정보 교류. 실행 용역은 자격 요건상 어려움 |
| 참고 | 대구시 관광 부서 | 정책과 예산 |

**고객의 정의:** 공공기관 담당자 (기획을 직접 하는 쪽). 여행사는 기획 주체가 아니므로 고객이 아닙니다.

## 5. 치킨의 위치

| 위치 | 단계 | 역할 |
|---|---|---|
| 음식 선택지 | MVP부터 | 선호 음식으로 고르면 식당이 코스에 들어감. 기본 추천에서는 제외 |
| 해설 요소 | MVP부터 | 노포 통닭집과 치킨 역사를 해설 지점으로 사용 |
| 볼거리 안의 요소 | 1단계 | 중구 외지인 상품에서도 선택지와 해설로 제공 |
| 동구 치킨 자산 | 2단계 | 평화시장, 효목동 역사를 동구 코스에 추가 |
| 치맥 축제 연계 | 확장 후보 | 두류공원 축제(달서구)와 평화시장 골목(동구)을 묶음 |
| 장기 메인 정체성 | 근거가 쌓인 뒤 | 보류 |

**근거 요약:** 외국인 치킨 선호는 낮고 (추천 음식 1+2순위 3.8%), 내국인은 먹으러 대구에 오지 않습니다 (맛집 탐방 목적 0.5%, 2023). 그래서 치킨은 **메인이 아니라 선택지와 해설**입니다. 치맥 축제는 외지인 중심이므로 확장 단계에서 다룹니다.

## 6. 기능 항목

### 6-1. 음식 선택지
- 선호 음식을 여러 개 고르면 해당 식당을 코스에 넣습니다.
- 치킨은 고른 경우에만 들어갑니다.
- 식당은 영업 상태와 위치를 확인한 곳만 넣습니다.

### 6-2. 인센티브 요건 (참고 기준)
- 외국인 6인 이상, 대구 1박 이상, 관광지 2곳 이상 (유료 1곳 이상 포함), 1박마다 관광지 1곳 추가
- 반경 1km 이내 두 곳은 1곳으로 계산
- 요건에 못 맞아도 코스를 막지 않고, "참고 충족 / 미충족"만 표시
- 최종 판단은 진흥원 공고 기준

### 6-3. 스탬프 체류 인증 모듈
- 기존 스탬프와 연결: 근대골목 스탬프투어 (12곳), 약령시 한방로드 스탬프 (5곳)
- 우리 역할: 저녁 체크포인트, 체류 증명 기준, 보상 구조 설계
- 운영(앱, QR, 정산)은 운영사에 분리 발주 가능

## 7. 시기별 상품 구조

- **6~8월 (여름):** 외국인 당일치기 비율 18.7%. 당일형 중심, 여름 옵션으로 치맥 축제 연계 후보
- **나머지 달:** 6~7%. 1박2일 중심
- 여름 당일 표본은 약 72명으로 작아서 **옵션으로만** 둡니다.

## 8. 확장 로드맵

| 단계 | 지역 | 방문객 | 치킨 | 발주처 |
|---|---|---|---|---|
| **MVP (지금)** | 중구 | 외국인 | 선택지와 해설 | 중구청 관광콘텐츠팀 |
| **1단계** | 중구 (유지) | 외지인 (내국인 포함) | 선택지와 볼거리 요소 | 중구청 (확대) |
| **2단계** | 중구 + 동구 추가 | 외국인·외지인 | 동구 치킨 자산 | 동구청 문화관광과 |
| **확장 후보** | 달서구 축제 + 동구 골목 | 외지인 중심 | 치맥 축제 연계 | 축제 운영 기관 (협의 필요) |

**지역은 누적됩니다.** 2단계에서 중구를 빼지 않고 동구를 더합니다.

### 8-1. 1단계 주의점
- 외지인에서 **대구 주민의 대구 내 이동은 제외**합니다. 중구로 오는 상위 출발지가 대구 내부(수성구, 북구, 달서구, 동구)입니다.
- **경북 근거리 당일 옵션**은 1단계 안의 선택 기능으로 검토합니다. 다만 경북 방문 규모는 아직 확인되지 않았습니다.

## 10. 이번 정리에서 바로잡은 것

- 발주처: 대구시 관광부서 → **중구청 관광콘텐츠팀** (MVP)
- 재단: 대구관광재단 표현 삭제 (관광 업무는 진흥원 관광본부)
- 동구 신세계: **동구 확정**
- 동화사: 누락 → 방문율 29.7%로 추가
- 황금동: 중구 치킨 근거에서 제외 (**수성구**)
- 외지인 숙박 지표: 외국인 근거에서 제외, 1단계 이후 사용
- 로드맵: 1단계는 **중구 외지인**, 2단계는 **중구 + 동구**
- 치맥 축제: 1단계 이후에서 **확장 후보**로 이동 (축제는 달서구)
- 치킨: 메인 콘셉트 → 선택지와 해설 요소
- "선택 숙박": **숙박형 / 당일형 선택**으로 명확화
