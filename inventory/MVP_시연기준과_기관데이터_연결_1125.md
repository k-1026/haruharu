# MVP 시연 기준과 기관 데이터 연결

- 최초 작성: 2026-11-25 / 현재 구현·검증 기준 갱신: 2026-11-27
- 목적: 현재 MVP의 지원 범위와 확인 증거, 미완료 범위를 구분한다.
- 상태: 사용자 요청에 따른 로컬 앱 기준이다. 팀 전체 합의·현장 운영·원어민 검수·외부 공개 완료를 뜻하지 않는다.
- 관련 문서: [현재 유저플로우](유저플로우_v2.md), [반영 목록](반영사항/유저플로우_미정항목_결정및반영시점_1122.md), [구현·검증 이력](../app/작업현황.md).
- 발표자용 진행 순서·멘트는 이번 저장·PR 추가 범위에서 제외한다.

## 1. MVP 조건과 완료 기준

| 항목 | 현재 기준 |
|---|---|
| 대표 조건 | 일본인 커플·가을·중구·1박2일. 대상·동행은 목표 문구로 입력 |
| 기존 기능 보존 | 지역 선택과 동구 자료 유지. 시연을 위해 필수 지역을 넓히지 않음 |
| 희망과 필수 조건 | AI는 필수 지역·언어권·계절·기간을 임의 변경하지 않음. 희망 조정은 이유를 설명 |
| 기관 자료 | CSV/XLSX 실제 업로드·미리보기·시트 선택·적용 후 근거에 연결 |
| 대안 | A/B의 실제 구성 차이와 이유 확인. B가 없으면 실패·대안 불가 사유를 구분 |
| 중간 수정 | 선택 일정의 변경 요청 → 실제 코스 AI → 재검증 → 새 버전. 다른 일정·과거 버전 보존 확인 |
| 확정·홍보 | 최신 안·버전을 한 번 확정하고 같은 코스로 홍보 생성. 시작·끝·오전·겹침 재질문 없음 |
| 실제 결과 | 생성 코스·문구를 디자인과 코스별 QR 랜딩에 반영. 문서 3종·ZIP 확인 |
| 식사 | 제공하지 않음. 개별 선택·개별 결제. 치킨은 저녁 선택 옵션·스토리 요소 |

이는 기능과 검증 기준이며, 특정 장소·시각·문구를 매번 동일하게 생성한다는 약속이 아니다.

## 2. 자료 업로드의 현재 지원 범위

| 항목 | 구현된 범위 |
|---|---|
| 파일 | UTF-8 CSV, XLSX. 파일 1MB 이하 |
| 표 | 시트당 데이터 100행·25열, XLSX 최대 10시트 중 하나 선택 |
| 기본 열 | `출처,기간,지역,대상,항목,값,단위,표본수` |
| 선택 열 | `세부항목` |
| 확인 | 표·행·출처·기간·지역·대상·단위를 미리 보고 **내용 확인 · 이 자료 적용** |
| 자료 없음 | 업로드 없이 기존 저장소 자료 사용. 별도 ‘없음’ 체크 없음 |
| 미지원 | PDF·HWP·이미지·구형 XLS·암호 파일·복잡한 자유 형식 보고서 자동 해석. 수식 계산 대신 저장된 값 사용 |

위 상한은 현재 로컬 MVP 구현값이며 팀 공통 운영 합의로 기록하지 않는다. 미리보기와 적용을 구분하며, 파일명만 보이는 것으로 근거 반영 완료라 하지 않는다.

[가상 자료 사용법](../app/시험자료/시연자료_사용법.md)에 동일한 13행의 CSV·XLSX가 있다. 앱의 예제 다운로드도 이용할 수 있다. **가상 설문**으로 소개하고 실제 일본인 선호 통계·공식 조사로 제시하지 않는다. 사용안내 등 비데이터 시트와 실제 적용할 데이터 시트를 구분한다.

## 3. 기관 자료가 코스까지 전달되는 기준

- 원본 파일·선택 시트·행 위치와 출처·기간·대상·지역·단위·표본을 보존한다.
- 업로드 행은 기존 저장소 근거와 구분되는 ID로 수요 요약·A/B 구성·B 보완·부분 수정에 전달한다.
- 조건에 맞지 않거나 읽을 수 없는 행은 제외·경고 사유를 남긴다. 모든 업로드 행을 채택했다고 표시하지 않는다.
- 서로 다른 조사·기간·단위의 수치를 단순 평균하지 않고 같은 조사 복사본을 독립 근거로 세지 않는다.
- 채택 근거와 코스 판단의 연결을 검토한다. 설문의 덜 매운 음식 선호는 특정 식당의 맵기·영업·예약 가능성 증명이 아니다.
- 자료 변경 후 이전 코스·홍보를 새 자료 검토 완료로 간주하지 않는다.

## 4. 실제 AI와 코드의 역할

| 주체 | 맡는 일 |
|---|---|
| 코드 | 파일 수신·파싱·자료 필터·표·근거/경고, 형식·필수 조건·시간 검사, 상태·버전 관리 |
| 수요 근거 AI | 근거와 한계의 요약 |
| 코스 AI | 근거에 따른 A/B 기획·이유 설명, 요청한 범위의 수정 |
| 총괄 AI·실행기 | 보완·대안·자료 필요 판단. 코드 실행기가 정해진 전이·시간/호출 한도를 관리 |
| 자료수집 AI | 필요한 경우 자료 보완. 매 실행에서 무조건 호출되는 단계가 아님 |
| 독립 검증 AI | 작성 결과의 별도 검토와 보완 지적 |
| 홍보 검토 AI | 확정 코스의 장면별 문구·번역·배치 계획 초안 |
| 코드 | 반영된 시안에 배치·QR/랜딩·공개 사본·최종 파일 조립·대조 |

에이전트들은 작업에 따라 순차·조건부로 실행한다. 모든 에이전트를 동시에 띄우거나 1~5단계 각각에 별도 AI 호출이 있다고 설명하지 않는다. 랜딩과 최종 파일 조립에는 추가 AI를 호출하지 않는다. 실제 실행 로그에서 호출 역할·단계·결과를 확인하며 2분 완료나 무제한 보완을 약속하지 않는다.

## 5. 화면·데이터 검증 기준

| 구간 | 확인할 결과 |
|---|---|
| 업로드 | 실제 선택 파일·데이터 시트·13행 미리보기·적용 상태, 기존 자료와의 구분 |
| 코스 비교 | 필수 조건 유지, A/B 차이·이유와 미생성 사유, 지도·일정·장소 설명 연결 |
| 부분 수정 | 지정 범위·새 체류시간·변경 이유, 다른 방문과 이전 버전 보존 |
| 최신 결과 | 수정 완료 후 **만든 코스 보기**로 최신 버전 조회. 이전 화면을 수정본으로 오인하지 않음 |
| 홍보 준비 | 최신 안·버전 확정, 제목 자동 제안·선택 수정, 읽기 전용 일정과 톤·종류 설정 |
| 서버 전달 | 확정 코스 전체 사본 일치, 미확정·구버전 차단, 옛 일정 입력 무시·원본 기록 불변 |
| 홍보 결과 | 실제 생성 문구·번역과 코스, 적용된 최신 디자인, 같은 코스의 QR |
| 공개 자료 | 내부 경고·근거 ID·미확인·검토 상태 제외, 제외 내역은 담당자에게 표시. 사진 출처·라이선스 유지 |
| 최종 파일 | 요약 확인 후 결재·제안·홍보 HTML 3종과 ZIP. 같은 코스·수정값·언어 내용 대조 |

지도는 대표 위치를 이용한 이해용 동선이다. 코드 검사 통과·독립 AI 검토·담당자 코스 선택·실제 운영 확인은 서로 다른 상태다. 코스 선택만으로 영업·숙박·번역·계약을 승인하지 않는다.

## 6. 다시 만들기와 검토

- **문구·번역 새로 생성**: 이전 디자인 설정을 유지하고 최신 확정 코스로 홍보 AI 재실행. 코스 재기획이나 매번 새 그림을 그리는 기능이 아니다.
- **변경사항으로 파일 갱신**: 저장된 결과를 코드로 다시 문서화. AI 호출이 없고 변경이 없으면 본문도 사실상 같다.
- **수정이 필요한 홍보 표현**: 근거 없는 최상급·수치·역사 단정·픽업·식사 제공 약속 등을 내부 검토한다. 미처리/수정 필요면 새 최종 파일 생성을 막는다.
- 재생성 버튼만으로 표현 수정·번역 검수·운영 확인 완료를 보장하지 않는다.
- 내부 기록은 보존하고 공개 사본에서 확인되지 않은 문장과 대응 번역·장소 등을 함께 제외한다. 제외를 확인 완료로 바꾸지 않는다.

## 7. 2026-11-27 실제 확인 증거

이날 코드 수정 검증은 Python 496개·Node 101개 통과로 기록됐다. 이번 문서 갱신은 그 시험을 다시 실행한 작업과 구분한다.

실제 새 실행은 운영 데이터와 분리한 `app/개발보관/홍보직결_1127/runs`에서 수행했다. 이 경로의 시험 결과·다운로드는 Git 제외이며, 공유 가능한 요약은 [작업현황](../app/작업현황.md)에 있다.

- 가상 XLSX 13행 업로드·적용 후 실제 수요·코스·총괄·자료수집·독립 검증 실행, A/B 비교·지도 확인.
- A안 2일차 약령시 한의약박물관 체류 60→45분으로 실제 수정·재검증. A3 생성, 종료 13:43→13:28 반영. 이전 4개 버전·다른 7개 방문 보존.
- A3 확정 후 중복 입력 없는 설정에서 실제 홍보 AI 1회 완료. A3와 홍보 전달 코스 전체 JSON 일치.
- 한국어·일본어 랜딩의 약 45분 반영, 코스 토큰 `e8d6ae415b1b14320712` 연결 확인.
- 화면에서 검토·최종 요약 확인 후 문서 3종 생성·대조, 실제 ZIP 다운로드와 SVG 26개 확인.
- 기존 운영 실행 67개 파일 해시 변경 없음.

이 수치·장소는 **해당 시험 결과**다. 다음 생성에도 같은 방문 수·파일 수·소요시간·표현 검사 결과가 나와야 한다는 고정 규칙이 아니다. 새 결과의 번역·운영 품질은 다시 검토한다.

## 8. 남은 범위와 발표 시 구분

- 현재 `http://127.0.0.1:8790/plan/`은 로컬 앱이다. QR 코스 페이지는 같은 PC의 버튼으로 확인할 수 있지만 휴대전화 외부 접속용 공개 배포는 완료되지 않았다.
- 실제 방문일 영업·휴무·예약·이동, 원어민 번역, 휴대전화 실기기 QR 판독·최종 인쇄 확인은 별도다.
- 관광객 개인 식사 선택 원칙과 직원용 후보 묶음·개인 지도 미리보기는 있으며, QR 랜딩에서의 전체 선택 흐름 연결·공개 검증은 남아 있다.
- HTML 문서는 브라우저 인쇄/PDF 저장을 사용한다. 기관 양식 업로드·네이티브 HWP 생성, 문구 직접 편집·디자인 전용 편집기는 현행 기능으로 제시하지 않는다.
- B 누락·형식 오류 시 A를 보존하고 기존 한도 안에서 B만 한 차례 보완한다. 명시적 대안 불가 사유는 무한 재요청하지 않는다. A만 있으면 두 안 비교 성공으로 표시하지 않는다.
- 11/25 최초 검토의 ‘업로드 없음·새 A/B/부분 수정 미시험’은 당시 상태다. 현재 완료·미완료는 위 2~7절을 기준으로 하며 팀 운영 정책의 최종 확정으로 확대하지 않는다.
