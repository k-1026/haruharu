# 데이터 수집 과정별 계획 (v2.1.2)

- 상태: 팀 검토용 초안. 커밋 전.
- 목적: 우리가 해야 하는 **과정 순서**대로, 각 단계에서 **정해야 할 것**과 **필요한 데이터**를 적는다. 데이터 종류별 상세는 `데이터수집_상세표_v2.1.1.md`를 참고한다.
- 기준: 기획 방향 `기획방향_기준_v2.1.md`, 설계 `에이전트_구성_v2.1.md`.
- 밸류체인 원문: **`origin/밸류체인`의 `inventory/밸류체인_v2.0.md`**와 `research/valuechain/`.
- 추가 확인: **`origin/이예진`** (`11월 9일/다시_자료/`), **`origin/신민지`** (`research/data/raw/KOSIS/`, `관광데이터랩/`). 아래 표에 브랜치 경로를 적었다.
- 마감: 2026-12-01 · 인원: 2명

## 상태 표기

| 표기 | 뜻 |
|---|---|
| **있음** | 원자료나 기록을 열어 확인함 |
| **있음 (미열람)** | 파일 위치는 확인했지만 내용은 아직 열지 않음 |
| **확인 필요** | 기록은 있으나 수치나 출처가 맞는지 불확실 |
| **부족** | 일부만 있음 |
| **없음** | 찾지 못함. 구해야 함 |
| **제외** | 우리 몫이 아니거나 1차 범위 밖 |

---

## 전체 과정 (순서)

```
1. 밸류체인 ─ 2. 페인포인트 ─ 3. 고객여정 ─ 4. 고객 페르소나
      ↓
5. 기획 입력·구조 규칙 ─ 6. 코스 자원 ─ 7. 저녁·음식
      ↓
8. 근거·출처 관리 ─ 9. 산출물 (제안서, 홍보물) ─ 10. 검증
```

앞 단계에서 정한 것이 뒤 단계의 입력이 된다. 예를 들어 **페인포인트**가 정해져야 **고객여정**의 어느 단계에서 불편이 생기는지 연결할 수 있다.

## 1단계. 밸류체인 (밸류체인 브랜치 참고)

**정할 것:** 고객이 누구인지, 여행사가 어떤 역할인지, 돈이 어디서 어디로 흐르는지, 우리가 단계별로 무엇을 맡는지.

| 필요한 데이터 | 상태 | 어디에 있나 | 부족하면 |
|---|---|---|---|
| 중구청 관광 기획 발주 기록 (비비드 투어 예산 약 1,500만 원, 타임워프 용역 등) | 있음 | 밸류체인 `01_수요_홍보.md`, 기사·공고 | — |
| 기획 용역비 규모 | 부분 있음 | 이예진 `11월 9일/다시_자료/공공예산_용역발주_조사_2026.md` (나라장터 2026.01~11). 관광 용역 추정가격 예: 야간관광 활성화 홍보 약 2.3억, 음식관광 디지털 홍보 약 2.3억 (낙찰 미확정). 대구관광재단 공고는 0건 | 우리 구청의 실제 예산은 없음. 유사 용역 추정가격을 참고값으로만 씀 |
| 공공 예산 흐름 (구청 → 우리, 진흥원 → 여행사) | 있음 | 밸류체인 §4 돈 흐름 | — |
| 여행사 판매 수수료 | 제외 | 여행사 몫 | 구하지 않음 |
| 여행사 채널 구조 (인바운드 예약 연동) | 있음 | 밸류체인 ④ 근거 (하나투어ITC 공지, 2026 공고) | — |
| 진흥원 인센티브 (1박당 2만 원/인, 여행사별 월 2,000만 원 한도) | 있음 | 밸류체인 ⑥ 근거 (진흥원 공식) | 2차 참고용 |
| 외국어 홍보 현황 (영문 팸플릿, 다국어 팸플릿) | 있음 | 밸류체인 ② 근거 (대구일보 2026.06.11) | — |
| 중간체·중번체 홍보물 | 없음 | — | "확인되지 않음"으로 표기 |
| 성과 → 다음 기획 피드백 경로 | 없음 | 밸류체인 §5 "설계 필요" | 설계로 정함 (데이터 아님) |

**다음 단계로 넘길 것:** 고객은 중구청 관광 담당, 여행사는 실행 파트너, 우리는 기획과 근거까지라는 구분 확정.

## 2단계. 페인포인트 (외국인 기준)

**정할 것:** 외국인이 대구·중구에서 겪는 불편 3~5개. 확정이 아니라 **근거 등급을 붙인 가설**로 시작한다.

| 페인포인트 후보 | 근거 | 상태 | 어디에 있나 | 부족하면 |
|---|---|---|---|---|
| 외국어 안내 부족 | 영문 팸플릿만 있는 투어, 안내소 영문 자료 | 있음 (언론) | 대구일보 2026.06.11 (워크트리 raw) | 외국인 설문 근거 없으면 "가설"로 표기 |
| 운영 정보 불명확 (요일, 시간, 요금) | 공식 상세 페이지에 "미확인" 다수 | 있음 | 워크트리 `research/place_tour/중구_투어_전체_목록.md` | — |
| 외국어 투어 이용 저조 | 신청 0건 (2026-11-21 기준) | 있음 (원인 미확인) | 워크트리 신청 달력 raw | 원인(홍보 부족인지, 예약 경로인지)은 가설 |
| 예약 경로 불편 (전화 예약, 주말 사전 예약 필요) | 중구 동성로 치킨집 리뷰 (네이버 지도, 2026.11 조회) | 있음 (국내 리뷰, 외국인 아님) | 이예진 `11월 9일/다시_자료/대구_중구·동구치킨관련_VOC_표.md` (C-15, C-17, C-20) | 외국인 근거가 아니므로 "국내 방문객 사례"로만 씀. SNS 신청 기사는 별도 재확인 |
| 숙소 선택 기준 | 외국인 숙박 선택 이유 (KOSIS 2024) | 있음 (미열람) | 신민지 `KOSIS/대구광역시_외국인숙박선택이유_2024.xlsx` | 원표 열어 상위 이유 확인 |
| 저녁 선택지 불명확 | 식당 정보 없음 | 부족 | — | 5단계 저녁·음식 데이터로 해결 |
| **외국인 본인의 직접 불편 응답** | 설문 | **없음** | 찾지 못함 | KOSIS 다른 표 확인. 없으면 "미확인" 유지 |

**다음 단계로 넘길 것:** 확정 가능한 페인포인트 (운영 정보, 외국어 안내)와 가설로 둘 페인포인트를 나눔.

## 3단계. 고객여정 (외국인 숙박형)

**정할 것:** 여정 8단계와 단계별 외국인 행동, 그리고 각 단계에서 우리가 개입할 지점.

여정 틀은 기존 근거리 자료(`lifestyle/D11`, 밸류체인 브랜치)의 8단계를 쓴다: 인지 → 계획 → 이동·도착 → 낮 관광 → 저녁 결정 → 저녁·야간 → 숙박·귀가 → 사후.

| 단계 | 필요한 데이터 | 상태 | 어디에 있나 | 부족하면 |
|---|---|---|---|---|
| ① 인지 | 외국인의 정보 채널 | **없음** | — | 가정으로 표기 |
| ② 계획 | 외국인 추천 관광지 상위 10 | 있음 (미열람) | 신민지 KOSIS | 원표 확인 |
| | 외국인 추천 음식 상위 20 | 있음 (미열람) | 신민지 KOSIS | 원표 확인 |

| | 원거리 숙박형 여정 가설 (치맥 여행러, 치킨 덕후 순례자) | 있음 (가설, 리뷰 없음) | 이예진 `11월 9일/원거리_숙박형_유형별_치킨_여정_지도.md` | 리뷰나 설문으로 검증 필요. 감정 점수는 가설 |
| | 외국인 입국 경로 (공항, 대구역 등) | **없음** | — | "공항 또는 대구역"으로 가정 |
| ④ 낮 관광 | 외국인 방문 관광지 (서문, 동성로, 약령시, 근대골목) | 있음 (미열람) | 신민지 KOSIS | 원표 확인 |

| ⑥ 저녁·야간 | 밤마실 운영 정보 | 있음 | 워크트리 밤마실 raw | 외국인 안내 여부는 미확인 |
| | 외국인 야간 소비 | 부족 | 관광데이터랩 업종별 소비 (외지인 기준) | 외국인 기준 없음. 참고만 |
| ⑦ 숙박·귀가 | 외국인 숙박 선택 이유 | 있음 (미열람) | 신민지 KOSIS | 원표 확인 |

**다음 단계로 넘길 것:** 페인포인트가 여정의 어느 단계에 생기는지 연결한 표.

## 4단계. 고객 페르소나 (외국인)

**정할 것:** 외국인 페르소나 2~3개 (출발국, 동행, 목적, 체류 기간).

**기존 자료 처리:** `brand/persona_design_draft.md` (밸류체인 또는 place-tour 브랜치)는 근거리 기준(P1·P2)이라서, 외국인 P3만 참고한다. 나머지는 옵션 메모로 둔다.

| 필요한 데이터 | 상태 | 어디에 있나 | 부족하면 |
|---|---|---|---|
| 외국인 출발국 (대만, 중국, 일본 등) | 있음 (미열람) | 밸류체인 raw `관광데이터랩중구_빅데이터외국인방문자거주지(국가).csv` | 수치를 열어 확인 |
| 외국인 동행 유형 | 있음 (미열람) | 신민지 KOSIS `외국인_동반자유형_본인제외.xlsx` | 가장 많은 유형 확인 |
| 외국인 방문 목적 | 있음 (미열람) | 신민지 KOSIS `외국인_방문주된목적.xlsx` | 상위 목적 확인 |

**다음 단계로 넘길 것:** 페르소나 2~3개 (출발국, 동행, 목적, 기간 조합).

## 5단계. 기획 입력과 구조 규칙

**정할 것:**
- **입력 단위:** 월로 할지 계절로 할지. 밸류체인은 **계절**, 기획 v2.1은 **월**을 쓴다. 팀이 하나로 정해야 한다.
- **구조 규칙:** 어느 시기에 1박형, 당일형 옵션을 넣을지.

| 필요한 데이터 | 상태 | 어디에 있나 | 부족하면 |
|---|---|---|---|
| 시기별 당일치기 비율 (여름 18.7%, 나머지 6~7%) | 있음 (미열람) | 신민지 KOSIS 체류기간, 숙박기간 2024 | 여름 표본 약 72명 표기 |
| 외국인 월별 방문 추이 | 부족 | 관광데이터랩 외국인 관심관광지 월별 (관심 지표, 방문 규모 아님) | 방문 규모는 외지인 기준 파일로 대체 가능하면 사용 |
| 계절별 방문 규모 차이 | 있음 (기존 분석) | `brand/persona_design_draft.md` (외지인 기준, 차이 1~3%) | 외국인 기준으로 재확인 |
| 2026년 10월 언어권 자료 | 없음 | — | 가을 집계 방식 정하고 "미확인" 표기 |

**다음 단계로 넘길 것:** 입력 단위 (월 또는 계절)와 시기별 구조 규칙 확정.

## 6단계. 코스 자원 (장소와 운영)

**정할 것:** 중구 장소 8~10곳, 그중 운영 정보를 확인할 장소 5곳, 투어가 있는 장소는 투어 정보를 같이 적는다.
