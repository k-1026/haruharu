# 4단계 홍보 검토 — 표현 필터 (E5)

문구 초안에서 검증되지 않은 표현을 찾아 표시한다. 걸리면 담당자가 **문구 고치기 → 다시 생성**을 한다. 필터는 문구를 대신 지우지 않고 표시만 한다.

## 1. 걸러 낼 표현

| 종류 | 예 | 왜 |
|---|---|---|
| 순위 · 최상급 | "대구 1등", "가장 맛있는", "최고의" | 순위를 매기는 근거가 없다 (역할표 예시) |
| 원조 · 최초 단정 | "원조", "최초", "유일한" | 공식 기록으로 확인 전에는 단정할 수 없다 |
| 근거 없는 스토리 | 출처 없는 유래 · 일화 | 3단계 장소 스토리에 없는 이야기 |
| 수치 과장 | 근거표와 다른 수치, 반올림한 수치 | 근거표 값과 일치해야 한다 |
| 실존 업체 · 생존 인물 | 특정 가게 · 사람을 평가하거나 사실을 덧붙임 | 공개된 공식 기록 범위 밖 (팀 CLAUDE.md 5번) |
| 운영 단정 | "언제든", "365일" | 운영 정보로 확인하지 않았다 |
| 제안을 실제처럼 | 팀이 제안한 상품 · 시설을 운영 중인 것처럼 | 사실과 제안을 나눠야 한다 (팀 CLAUDE.md 4번) |
| 범위 밖 서비스 | "공항 픽업", "픽업 포함", "역까지 모셔다 드립니다", "교통편 제공" | 현재 기획에 픽업 · 교통편 제공이 없다. 코스 시작 · 종료 안내는 3단계 확정값만 쓴다 (`4_문구.md` 2장, 사람1 `1120_유저플로우_보완안_사람1.md` 2-4 ⑥) |
| 도시 정체성 · 대표성 주장 (B9) | "치킨 도시", "치킨의 도시", "치킨의 수도", "K-치킨벨트 대표 지역", "치킨명소 선정" | 우리 말로 순위 · 정체성을 주장하지 않는다. 정부 · 공식 자료에 있는 사실만 2장의 인용 표현으로 쓴다 (사람1 B9, 기획서 6-4) |

- 원조 · 최초 표현이 공식 기록으로 확인된 경우 쓸 수 있는지, 쓴다면 출처를 어떻게 붙일지: `[자료 필요: 팀 확정]`
- 걸러 낼 단어 목록(국문 · 외국어): `[자료 필요: 팀 확정]`. 외국어 번역에서도 같은 뜻이면 걸린다 (예: "chicken capital", "city of chicken").

- 팀 내부 기획 문서 제목("치킨의 수도, 하룻밤 머무는 도시로 ver5")은 내부 이름일 뿐이다. 홍보 문구 · 시안 · 번역에는 쓰지 않는다.

### 1-1. 대신 쓸 수 있는 사실 (치킨 관련, B9)

정체성 주장 대신 아래 표현을 출처와 함께 쓴다. 원자료 표기를 바꾸지 않는다. 출처: 신민지 브랜치 `research/crosscheck.md`, `research/sources.md`. `[P]` = crosscheck에 "원자료 확인 완료"로 기록됨, `[U]` = 미확인.

| 쓸 수 있는 표현 | 쓰면 안 되는 표현 | 근거 · 확인 상태 |
|---|---|---|
| "평화시장 닭똥집골목은 K-치킨벨트 대구 치킨명소로 소개되어 있습니다" | "치킨명소로 선정", "K-치킨벨트 선정" | C29: 한식진흥원 K-치킨벨트 대구시 화면에 '치킨명소' 01로 게재 (S52 캡처, 2026-11-03). 화면 표현은 '선정'이 아니라 게재 [P] |
| "대구는 K-치킨벨트 30개 시 · 군 중 하나입니다 (2026-11-03 화면 기준)" | "전국 30대 치킨 명소", "K-치킨벨트 대표 지역" | C47 · C48: 30은 시 · 군 수, 대구는 15스팟(치킨 · 치킨축제). 2026 대표 지역(구미 · 수원 · 제주 · 춘천)에 대구는 없음 (S54) [P]. 화면 수치는 바뀔 수 있어 확인일을 붙인다 |
| 문체부 음식관광 33선 지도의 대구 '치킨' 표기 | — | 기획서 6-4가 ver6에서 인용. 원문을 팀 자료로 대조한 기록이 없어 **원문 확인 전에는 쓰지 않는다** [U] |

- 위 표에 없는 치킨 관련 사실은 3단계 장소별 근거 · 장소 스토리에 있는 것만 쓴다 (`4_문구.md` 2장).

## 2. 표시 문구

"[장면 번호] '[걸린 표현]'은 [종류]에 해당합니다. 근거: [없음 / 출처]. 고친 뒤 다시 생성해 주세요."

- 도시 정체성 · 대표성 주장에 걸리면 1-1 표의 "쓸 수 있는 표현"을 함께 보여 준다. 대신 고르지는 않는다.

## 3. 번역문에도 적용

- 번역 초안에도 같은 필터를 적용한다. 원문에 없던 최상급이 번역에서 생기지 않았는지 본다 (`6_번역.md`).
