# 4단계 홍보 검토 — 문구

## 1. 장면별 문구 구성

| 칸 | 내용 |
|---|---|
| 제목 | 장면을 한 줄로 |
| 본문 | 2 ~ 3문장. 장소 · 시간 칸 · 경험 |
| 사실 근거 | 본문의 사실이 어느 근거(출처 ID)에서 왔는지 |
| 경고 표시 | 3단계에서 넘어온 경고 |

- 글자 수 · 문장 수 기준: `[자료 필요: 홍보물 종류별 팀 확정]`

## 2. 쓰는 법

- 사실(장소 · 역사 · 수치)은 3단계 장소별 근거와 장소 스토리에 있는 것만 쓴다. 장소 스토리는 `11_스토리_검증.md`의 판정(사용 / 조건부 / 제외)을 따른다. 근거 칸에 출처 ID를 남긴다.
- 분위기 · 감각 표현(예: 따뜻한, 고소한)은 사실 주장이 아니므로 쓸 수 있다. 단 `5_표현_필터.md`를 거친다.
- 수치를 쓸 때는 원래 값 그대로 쓰고 출처 · 연도를 근거 칸에 남긴다. 반올림하거나 키우지 않는다.
- 경고가 있는 근거를 쓰면 문구 옆에 경고를 그대로 보여 준다. 예: "간접 근거: 향촌문화관 1곳 기준".
- 영업시간 · 휴무가 미확인인 장소는 시각을 문구에 넣지 않는다.
- **코스 시작 · 종료 안내:** 3단계가 확정한 코스 시작 · 종료 장소와 시각만 쓴다 (`2_입력.md` 1장). 픽업, 픽업 포함, 역 · 공항까지 복귀, 교통편 제공 같은 내용은 새로 만들지 않는다. 시작 장소가 역 · 공항이어도 "그곳에서 코스를 시작한다"고만 쓴다 (사람1 `1120_유저플로우_보완안_사람1.md` 2-4 ⑥, 2026-11-20)

## 2-1. 식사 문구 (2026-11-23 추가, 사람1 수정 요청)

3단계에서 받은 식사 방식(지정식 / 자유식)을 문구에서 그대로 지킨다.

| 식사 방식 | 쓸 수 있는 것 | 쓰지 않는 것 |
|---|---|---|
| 지정식 | 정해진 식당 · 메뉴를 코스 일정으로 안내 | 순위 · 평가 표현 (`5_표현_필터.md`) |
| 자유식 | 식사 시간 · 권역, "추천 후보" 몇 곳, **"추천 후보 외에 다른 음식 · 식당도 자유롭게 고를 수 있습니다"** 같은 안내 | 추천 식당 · 메뉴를 필수 방문 · 필수 식사처럼 쓰는 표현 ("꼭 먹어야 할", "반드시 들러야 할", "코스의 하이라이트는 ○○ 식당") |
| 미선택 | 식사 시간 · 권역만 | 식당 이름을 코스 일정처럼 쓰는 것 |

- **식비:** 3단계에서 식비 포함 여부가 "미정"이면 문구에 "식사 포함" · "식비 별도"를 쓰지 않는다. 정해진 경우에만 쓴다.
- **이동 시간:** 추천 후보 한 곳 기준 이동 시간은 "○○ 이용 시"를 붙여 쓰거나 쓰지 않는다. 모든 식당에 같은 시간이 걸리는 것처럼 쓰지 않는다.
- **연결 안내:** 단체 동행형이면 재집결 장소 · 시각, 개별 이동형이면 다음 일정 도착 장소 · 시각만 쓴다 (3단계 값 그대로).
- **결과 보장 금지:** "음식 중복 없는 코스"처럼 실제 식사 결과를 보장하는 표현을 쓰지 않는다. 3단계 C3는 지정식 메뉴와 추천 후보 다양성만 본 것이다.
- **테스트 값을 고정으로 쓰지 않는다:** 찜갈비 등 2.6 테스트에서 고른 값을 모든 상품의 고정 구성처럼 쓰지 않는다. 3단계가 넘긴 그 코스의 값만 쓴다.

## 3. 낮 → 밤 흐름

- 장면 문구는 3단계 확정 코스의 칸 순서대로 이어지게 쓴다: 낮 → 점심 → 낮(오후) → 저녁 → 밤 → 숙박 (1박2일은 2일차까지) (`../3_코스검토/3_코스_짜기.md` 1장, 기획서 6-3). 팀 주제 "대구, 낮부터 밤까지"는 이 시간 흐름을 말한다.
- 치킨은 3단계 치킨 비중 단계(`../3_코스검토/2_입력.md` 5-1)를 따른다. 지금(1단계)은 담당자가 저녁에 치킨을 골랐을 때만 그 장면에 나오고, 코스 전체의 주제로 쓰지 않는다. 치킨 관련 사실은 `5_표현_필터.md` 1-1 표현만 쓴다.
- 이전의 "낮 커피 · 베이커리 → 저녁 치킨" 구성은 쓰지 않는다 (2026-11-19, 3단계 틀 변경에 맞춤).
- 흐름을 잇는 연결 문장은 해석이므로 사실 근거 칸을 비우고 "연결 문장"이라고 표시한다.
