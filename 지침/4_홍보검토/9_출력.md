# 4단계 홍보 검토 — 출력

## 화면에 나오는 결과

유저플로우 S4의 "장면 → 홍보물 대응표 + 문구 · 번역 초안 + 시안"에 코스 카드(B6)를 더한 것이다.

## 출력 형식

```
## 코스 카드 (B6)
- 이런 분이라면 → 이 코스: "[1단계 조건 · 담당자 선택에서 온 대상]이라면 → [코스 이름]"
- 코스 한눈에: [시작 장소 · 시각] → [칸] [장소] → … → [종료 장소 · 예정 시각]   (3단계 확정 코스 순서 그대로. 자유식 칸은 "[칸] 자유식 · [권역]", 지정식 칸은 "[칸] [식당]")
- 식사 안내: 칸마다 지정식 / 자유식 · 식비 포함 여부(미정이면 쓰지 않음) · 자유식이면 "추천 후보 외 선택 가능"   (2026-11-22 추가)
- 남은 경고: ...  ← 없으면 "없음"

## 장면 → 홍보물 대응표
| 장면 번호 | 장소 | 시간 칸 | 홍보물 | 상태 |

## 장면별 문구
### [장면 번호] [장소]
- 제목: ...
- 본문: ...
- 사실 근거: [출처 ID]
- 경고: ...  ← 없으면 "없음"

## 표현 필터 (E5)
| 장면 번호 | 걸린 표현 | 종류 | 담당자 처리 (고침 / 그대로 둠 / 미처리) |   ← 없으면 "없음"

## 번역 초안
| 장면 번호 | 언어 | 번역 | 역번역 (참고) | 번역 상태 (AI 초안 / 검토 중 / 검토 완료) |

## 코스 변경 (E6)
| 요청한 장면 번호 | 장소 · 시간 | 바꾸려는 이유 | 3단계 결과 (바뀐 장소 · 시간) | 다시 만든 장면 | 재검토 상태 (끝남 / 진행 중) |   ← 없으면 "없음"

## 시안
- 톤앤매너: ...
- 캐릭터: 너구리 · 족제비 (2인 1조). 기준 시트: 너구리 · 족제비 v1.1 (`7_시안_캐릭터.md` 2장)
- 장면별 시안: [장면 번호] 주연 [너구리 / 족제비 / 동등] · 배치 세트 [발견 / 설명 / 먹거리 / 이동 · 지도 / 엔딩 · 숙박] · 표정 · 포즈 [시트 이름 또는 "새 포즈 필요"] · ...
- 캐릭터 배치 점검: [장면 번호] [어긴 항목]  ← 없으면 "없음" (`7_시안_캐릭터.md` 3장)

## 5단계로 넘기는 것
- 코스 카드
- 확정 문구 · 번역 (장면 · 언어마다 번역 상태 포함)
- 장면 → 홍보물 대응표
- 고른 톤앤매너 · 시안
- 표현 필터 기록 (E5): 걸린 표현 · 종류 · 담당자 처리
- 코스 변경 기록 (E6): 요청 · 3단계 결과 · 재검토 상태
```

## 1. 코스 카드 쓰는 법 (B6)

- 카드 맨 위 한 줄은 "이런 분이라면 → 이 코스" 형식이다 (사람1 B6, 기획서 "가져올 것 (ver6 6장)" 문단). 춘천 K-치킨벨트 상품의 코스 선택 가이드 형식을 참고했다 (`research/음식관련 사례.md`, S58 블로그 단일출처 — 형식만 참고, 내용은 가져오지 않음).
- "이런 분"은 **1단계 조건(언어권 · 계절 · 체류 기간 · 지역)과 담당자가 고른 것(저녁 선택, 동반자 조건이 있으면 그것)에서만** 만든다. 조건에 없는 성향 · 취향을 지어내지 않는다. **저녁이 자유식이면 "이런 분"에 특정 음식 · 식당을 넣지 않는다** (예: "저녁은 찜갈비를 먹고 싶은"은 지정식일 때만, 2026-11-22). 예 형식: `10_예시.md` 코스 카드
- 코스 이름은 담당자가 정한다. 정하지 않았으면 "[코스 이름 미정]"으로 둔다.
- "코스 한눈에"는 3단계 확정 코스의 칸 · 장소 순서를 그대로 옮긴다. 순서를 바꾸거나 장소를 빼지 않는다.
- 카드 문구도 `5_표현_필터.md`를 거친다. 번역할 때는 다른 문구와 같이 `6_번역.md`를 따른다.
- 3단계에서 넘어온 경고가 있으면 카드에도 붙인다 (`1_역할.md` "하지 않는 일": 경고를 감추지 않음).

## 2. 기록 쓰는 법

- E5 "담당자 처리"는 담당자가 고르기 전까지 "미처리"로 둔다. "그대로 둠"을 고른 표현은 지우지 않고 기록에 남긴다.
- 번역 상태는 `6_번역.md` 3장의 세 가지만 쓴다. 에이전트는 `AI 초안`까지만 표시한다. 역번역은 참고 칸이며 검토를 대신하지 않는다 (3-1).
- E6 재검토가 "진행 중"이면 5단계는 기다린다 (`지침/5_산출물/입력.md` "받을 때 규칙"). 4단계는 "진행 중"을 "끝남"으로 미리 바꾸지 않는다.

## 3. 5단계가 받는 것

- `5단계로 넘기는 것` 블록이 5단계 `입력.md` 1장 표의 "4 홍보 검토" 행이다 (`지침/5_산출물/입력.md`). 항목을 바꾸면 사람1에게 알린다.
- 3단계 결과(확정 코스 · 근거 · 운영 주체 후보 · 대체 · 겹침 이력)는 4단계를 거치지 않고 5단계가 `../3_코스검토/6_출력.md`에서 직접 받는다. 그래서 이 블록에 다시 적지 않는다.
- 2026-11-19: 5단계 `입력.md`의 요청(E5 기록 · E6 변경 기록 · 번역 상태)을 반영했다. 코스 카드는 4단계에서 더한 항목이다 → **5단계 홍보물 묶음의 맨 앞 칸으로 넣는다** (사람1 1120 보완안 2-4 ③ 제안, 2026-11-20 사람2 동의). 5단계 `입력.md` · `출력.md` 반영은 사람1.

## 4. JSON으로 낼 때 (`지침/공통/단계_넘김.md` 6-2)

통합시험 · 앱 실행은 위 출력 형식 대신 단계_넘김 6-2의 JSON 객체 하나를 받는다. 필드 이름은 6-2를 따르고, **내용 규칙은 이 폴더의 지침을 그대로 적용한다.** JSON이라고 규칙을 줄이지 않는다. (2026-11-23 추가. 4단계 AI 첫 실행 `4단계시험_171352`에서 아래 칸이 지침과 다르게 나옴)

| JSON 칸 | 채우는 법 | 지침 |
|---|---|---|
| 장면ID (대응표 · 문구목록 · 번역목록 · 표현필터) | **3단계 칸목록의 칸ID를 그대로 쓴다** (예: `낮-1`, `2일-오전-1`). 앱이 칸ID에 없는 장면ID를 형식 오류로 막는다. `3_장면_구성.md` 1장의 `2일차-낮-1` 같은 번호는 마크다운 출력에서만 쓴다 | `3_장면_구성.md` 1장 |
| 대응표 장소 | 3단계 확정값 그대로. **3단계 운영 확인에서 `처리 = 제외`된 추천 후보는 넣지 않는다** (문구 · 시안에도 쓰지 않음) | `3_장면_구성.md` 3장 |
| 코스카드 한눈에 | 시작 장소 → 칸 순서 → **종료 장소 · 예정 시각까지** 쓴다. 종료 지점이 칸이 아니면 장면을 따로 만들지 않고, 코스카드 한눈에와 마지막 장면 본문에 넣는다 | 1장 |
| 문구목록 사실근거 | `출처ID`는 3단계 근거의 **원래 출처 표기**(S번호가 있으면 S번호, 없으면 근거 행의 `출처` 값 그대로)와 `근거ID목록`. 근거가 없으면 `가정값` / `연결문장` / `미정` 중 하나를 쓰고, **경고 칸에 "근거 없음"을 남긴다** (빈 목록 금지) | `3_장면_구성.md` 3장, `4_문구.md` |
| 표현필터 | 문구 · 번역 · 코스카드를 `5_표현_필터.md` 1장 표로 모두 확인하고, 걸린 것마다 한 행(장면ID · 표현 · 종류 · 처리 `미처리`). 근거보다 넓은 수요 · 인기 주장(예: 근거는 "방문 비율"인데 문구는 "인기 있는 코스")도 "근거 없는 스토리"로 적는다. 정말 없을 때만 빈 목록 | `5_표현_필터.md` |
| 번역목록 번역 | 장소 이름은 **`12_번역_용어집.md` 2장 표기를 글자 그대로** 쓴다 (예: 일본어 근대골목 `大邱近代通り`, 김광석길 `金光石の路`). 공식 표기가 `미확인`인 장소는 2-1 · 2-2의 제안표기만 쓴다 (예: 반월당역 `半月堂駅（Banwoldang）`). **번역문에 한글을 섞지 않는다** | `12_번역_용어집.md`, `6_번역.md` |
| 시안 장면별 주연 | **`너구리` / `족제비` / `동등` 중 하나만** 쓴다. 풍경 · 음식 · 관광객은 주연이 아니라 배치세트 · 포즈 설명에 쓴다. 두 캐릭터는 모든 장면에 함께 나온다 | `7_시안_캐릭터.md` 2장, `3_장면_구성.md` 2장 |

| 시안 배치점검 | `7_시안_캐릭터.md` 3장 항목을 어긴 장면만 적는다. 없으면 `없음`. **"확인 완료"라고 쓰지 않는다** (확인은 담당자가 한다) | `7_시안_캐릭터.md` 3장, `1_역할.md` |

## 5. 내기 전에 스스로 점검 (JSON · 마크다운 공통)

- [ ] 장면ID가 모두 3단계 칸ID와 같다 (JSON)
- [ ] 후보 제외된 식당이 대응표 · 문구 · 시안에 없다
- [ ] 코스카드 한눈에가 종료 장소 · 시각으로 끝난다
- [ ] 근거 없는 장면의 경고 칸에 "근거 없음"이 있다
- [ ] 표현필터를 실제로 돌렸다 (빈 목록이면 문구 · 번역 · 코스카드를 모두 봤다는 뜻)
- [ ] 번역의 장소 이름이 용어집 글자와 같고, 번역문에 한글이 없다
- [ ] 시안 주연이 너구리 / 족제비 / 동등뿐이다
- [ ] "확인 완료" · "검토 완료"처럼 사람 확인을 대신한 말이 없다
