# 4단계 홍보 검토 — 코스 변경 (E6)

홍보를 검토하다 코스를 바꿔야 할 때의 흐름이다. 4단계는 코스를 직접 고치지 않는다.

## 1. 흐름

1. 담당자가 바꿀 장면을 고른다.
2. 4단계가 3단계로 넘긴다: 바꿀 장소 · 시간, 이유, 영향받는 장면 번호.
3. 3단계에서 고친다 (충돌 대조 · 대체안 · 근거를 다시 거침).
4. 3단계가 바뀐 장소 · 시간과 장면 번호를 돌려준다.
5. 4단계는 **바뀐 장면만** "코스 변경으로 재검토 필요"로 표시하고 문구 · 번역 · 시안을 다시 만든다.
6. 바뀌지 않은 장면은 그대로 둔다.

## 2. 3단계로 넘기는 형식

```
## 코스 수정 요청 (E6)
- 장면 번호: ...
- 장소 · 시간: ...
- 바꾸려는 이유: ...
```

## 3. 기록

- 장면 → 홍보물 대응표의 상태를 "코스 변경으로 재검토 필요"로 바꾼다.
- 이미 검토가 끝난 번역이라도, 장면이 바뀌면 번역 상태를 `AI 초안`으로 되돌린다.
- 요청 · 3단계 결과 · 재검토 상태는 `9_출력.md`의 "코스 변경 (E6)" 표에 남기고 5단계로 넘긴다.

## 4. 4단계가 시작하지 않은 변경 (E6 밖)

사람1 `1120_유저플로우_보완안_사람1.md` 3-1 · 2-4 ④ 반영 (2026-11-20). 4단계에서 요청하지 않았는데 앞 단계가 바뀐 경우도 E6와 같은 방식으로 표시한다.

| 바뀐 곳 | "다시 확인 필요"로 표시하는 장면 |
|---|---|
| 3단계에서 담당자가 코스를 직접 고침 (장소 · 시간) | 바뀐 장소 · 시간에 연결된 장면 |
| 3단계 코스 시작 · 종료 장소나 시각이 바뀜 | 시작 · 종료 안내가 들어간 장면 · 문구 · 번역, 코스 카드 "코스 한눈에" |
| 2단계 근거가 바뀜 (새 근거 ID · 경고 ID) | 바뀐 근거 ID를 사실 근거로 쓴 장면 |
| 1단계 조건이 바뀜 | 모든 장면 |

- 영향 범위를 판별할 수 없으면 관련 장면 전체를 "다시 확인 필요"로 표시한다.
- 표시 방법은 E6와 같다: 대응표 상태를 "코스 변경으로 재검토 필요"로 바꾸고, 검토가 끝난 번역도 `AI 초안`으로 되돌린다.
- 확인하기 전 장면은 5단계가 "미확정"으로 취급한다 (보완안 3-3 (c)). 4단계는 확인 전 장면을 "끝남"으로 바꾸지 않는다.
- 에이전트는 표시만 한다. 고칠지 · 그대로 둘지는 담당자가 정한다.
- 결과 버전 · "다시 확인 필요" 표시를 앱이 언제 지원할지는 팀 결정 (보완안 6장). 지침은 규칙만 둔다.
