# 외국어 표기 — 공식 표기를 못 찾은 칸 처리

코스·홍보물·산출물에 들어가는 장소명·용어의 외국어(영어·일본어·중국어 간체/번체) 표기 규칙이다. 단계와 상관없이 같이 쓴다.

- 기준: CLAUDE.md 5절 출처 등급. 출처 없는 AI 번역은 'AI 생성' 등급이라 공식 명칭의 근거가 될 수 없다.
- 원칙: 에이전트가 번역해서 채워도 된다. 단, **번역한 값을 공식 표기 칸에 섞지 않는다.**

## 1. 고유명사 — 공식 출처를 먼저 다시 찾는다

대상 예: 향촌문화관(일본어), 국채보상운동기념관, 대구국제공항·동대구역(번체)

다음 출처를 확인했는지 본다. 운영 기관이 직접 낸 다국어 표기가 있을 가능성이 높다.

- 대구관광 다국어 사이트(일본어·번체 페이지)
- 한국관광공사 VisitKorea 다국어판
- 코레일, 한국공항공사 대구공항 다국어 안내
- 국립국어원 공공용어 번역 자료

찾으면 `research/sources.md`에 출처 ID를 붙여 공식으로 기록한다. 그래도 없으면 2번으로 채운다.

## 2. 못 찾은 칸 — 에이전트 번역 + 상태 표시

| 열 | 넣는 값 |
|---|---|
| `공식표기` | 공식 출처에서 확인한 값만. 없으면 `미확인` |
| `제안표기(AI번역)` | 에이전트 번역 |
| `상태` | `AI번역·미검수` → 검수 후 `검수완료(검수자)` |

- 검수자 이름은 사람이 적는다. AI가 대신 적지 않는다.
- 고유명사는 한글과 로마자를 같이 적는다(예: Hyangchon). 현장 표지판과 달라도 관광객이 찾아갈 수 있게 한다.

## 3. 일반어 — 공식 표기가 원래 없다

대상 예: 치맥, 골목투어·해설사, 스탬프 투어

- 고유명사가 아니라 상품·서비스 용어이므로 '공식 표기 없음'이 정상이다.
- 우리 상품 안에서 쓸 **팀 표준 번역**을 하나 정해 용어집에 두고, 모든 산출물에서 같은 표기를 쓴다.
- 고유한 말은 음역과 설명을 같이 쓴다. 예: `Chimaek (chicken & beer)`

## 4. 최종 산출물 전 검수

- `AI번역·미검수` 행만 모아 일본어·중국어 원어민(유학생 등)에게 검수를 받는다.
- 검수하지 못했으면 산출물에 "일부 외국어 표기는 AI 번역 초안, 검수 필요"라고 적는다.
