# 지침 — 단계별 에이전트 지침

2026-11-24 앱의 자율 이용 초안에는 [공통/자율이용_기획.md](공통/자율이용_기획.md)를 적용한다. 자료 선택·표·경고는 코드, 요약·코스 작성은 AI, 최초부터의 상태·검사·중단 관리는 총괄 실행기가 맡는다. 기획자 화면과 서비스 제공자용 읽기 전용 운영 로그를 구분한다. 아래의 기존 판매 확정 절차를 초안 입력의 필수 조건으로 해석하지 않는다.

담당자 · 에이전트 역할표의 단계마다 에이전트가 따를 지침을 모아 둔 폴더다. 사람이 읽고 고치는 곳이며, Claude Code는 `.claude/agents/`의 짧은 안내 파일을 통해 이 폴더를 읽는다.

- 기준: 담당자 · 에이전트 역할표 (1~5단계), 전체 흐름은 `inventory/유저플로우_v1.md`
- 역할표나 유저플로우가 바뀌면 해당 단계 폴더를 같이 고치고, 각 폴더 `역할.md`의 변경 기록에 남긴다.
- `[자료 필요]`는 아직 채우지 못한 칸이다. 채우기 전에는 그 규칙을 쓰지 않는다.

## 폴더

| 폴더 | 단계 | 담당 |
|---|---|---|
| `공통/` | 여러 단계가 같이 쓰는 자료 (단계 넘김 · 데이터 목록 · 외국어 표기) | 사람1 |
| `1_기획조건/` | 1단계 기획 조건 | 사람1 |
| `2_수요근거/` | 2단계 수요 근거 | 사람1 |
| `3_코스검토/` | 3단계 코스 검토 | 사람2 (각자 브랜치에서 만든다) |
| `4_홍보검토/` | 4단계 홍보 검토 | 사람2 (각자 브랜치에서 만든다) |
| `5_산출물/` | 5단계 산출물 (결재 파일 · 제안서 · 홍보물 묶음) | 사람1 |

폴더 이름은 `번호_단계이름` 형식으로 맞춘다. 담당이 다른 단계 폴더는 다른 사람 브랜치에서 만들지 않는다.

## 단계 폴더 안 파일 구성

| 파일 | 내용 |
|---|---|
| `역할.md` | 하는 일 · 하지 않는 일, 변경 기록 |
| `입력.md` | 담당자가 고르거나 올리는 것, 앞 단계에서 받는 것 |
| 단계별 규칙 파일 | 1단계 `자료_고르기.md` · `알림.md` / 2단계 `비교_확인.md` · `근거표.md` · `경고.md` / 5단계는 규칙을 `역할.md` · `출력.md`에 둠 |
| `출력.md` | 화면에 나오는 결과, 다음 단계로 넘기는 것 |
| `예시.md` | 출력 예시 |

## 1단계와 2단계 나누는 기준

| | 1단계 기획 조건 | 2단계 수요 근거 |
|---|---|---|
| 묻는 것 | 이 조건으로 볼 수 있는 자료가 **있나** | 그 자료의 수치가 무엇을 말하나 |
| 수치 | 쓰지 않는다 | 출처 · 연도 · 표본과 함께 쓴다 |
| 판단 | 하지 않는다 | 수요가 많은지 적은지, 근거가 강한지 약한지 |
