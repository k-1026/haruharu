# 2단계 수요 근거 — 출력

## 화면에 나오는 결과

역할표 2단계의 "수요 분석 요약 + 근거표 + 경고"다.

## 출력 형식

```
## 수요 분석 요약
- 방문객: ...
- 좋았던 점: ...
- 음식: ...
- 숙박: ...
(문장마다 출처 · 연도 · 표본)

## 근거표
| 항목 | 수치 | 출처 | 연도 | 표본 · 대상 | 한계 | 경고 |

## 경고 (E3)
- [경고 종류] 문구  ← 없으면 "없음"

## 3단계로 넘기는 것
- 조건 (1단계 그대로)
- 수요 분석 요약
- 근거표
- 경고 목록과 담당자 선택
```

## 3단계가 받는 것

`3단계로 넘기는 것` 블록은 코스 검토 담당이 받아 쓴다. 항목을 바꾸면 코스 검토 담당에게 알린다. 항목 확정: `[자료 필요: 코스 검토 담당과 합의]`
