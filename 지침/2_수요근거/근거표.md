# 2단계 수요 근거 — 근거표

## 1. 근거표 열

역할표의 근거표 항목은 방문객 · 좋았던 점 · 음식 · 숙박이다.

| 열 | 내용 |
|---|---|
| 항목 | 방문객 / 좋았던 점 / 음식 / 숙박 |
| 수치 | 원본 값 그대로 |
| 출처 | 기관 · 조사 이름 |
| 연도 | 자료 기준 시점 |
| 표본 · 대상 | n 또는 대상 범위 (예: 향촌문화관 1곳) |
| 한계 | 조건과 맞지 않는 점 |
| 경고 | `경고.md`에서 붙인 경고 |

### 항목별로 쓰는 자료

파일 경로는 `research/data/` 기준이다. KOSIS 2024 외국인 파일은 1단계가 고른 `category` · `subgroup` 행만 쓴다.

| 항목 | 쓰는 자료 | 비고 |
|---|---|---|
| 방문객 | 관심 관광지 월별 (`외국인/관광데이터랩_…_월별통합_202201-202609.csv`), 입장객 (`datalab_jung_paid_attraction_…`), 중구 거주 국가 (`datalab_jung_origin_country_…`), KOSIS 방문 관광지 · 추천 관광지 | 관심 관광지는 "방문 수"가 아니라 "관심 목록"이라고 적는다 |
| 방문객 (보조) | KOSIS 방문 목적, 동반자 (`kosis_foreign_purpose_2024.csv`, `kosis_foreign_companion_2024.csv`) | 수요 요약의 보조 문장으로만. 패키지 · 개별 여행 비율, 대구 첫 방문 비율은 KOSIS `여행형태` · `대구 방문 경험` 구분 행이 있는 파일에서 찾되, 해당 표를 아직 정리하지 않았으면 `[자료 필요]` |
| 좋았던 점 | `외국인/대구_외국인가장좋았던점_2024.csv` | |
| 음식 | `외국인/대구_외국인추천음식상위20_2024.csv` | `band` = `1 + 2순위`를 기본으로 쓴다 |
| 숙박 | `외국인/대구_외국인숙박기간_2024.csv`, `외국인/대구_외국인숙박유형_2024.csv`, `외국인/대구_외국인숙박선택이유_2024.csv` | 숙박 유형 · 선택 이유는 1박2일 · 추천받기일 때만 |

## 2. 수치 쓰는 법

- 원본 값 그대로 쓰고, 바로 뒤에 **출처 · 기준 연도 · 표본(또는 대상)**을 붙인다. 예: "1박 59.5% (KOSIS 대구관광실태조사 2024, 외국인, n=1,010)".
- 직접 계산한 값은 "계산값"이라고 쓰고 계산 방법을 한 줄로 남긴다.
- 해석은 사실과 나눠 "해석:"으로 시작한다.
- 한 문장에는 한 자료만 쓴다. 기간 · 대상이 다른 자료를 한 문장에서 비교하지 않는다.
- 여러 해 자료는 한 해 값만 골라 대표값처럼 쓰지 않고 연도별로 모두 보여 준다.
- **산정 기준이 다른 수치는 한쪽만 고르지 않는다.** 같은 대상(예: 축제 방문객)을 기관마다 다른 방식으로 셌으면 출처별로 함께 적고, 기준이 어떻게 다른지 한 줄로 남긴다. 예: "[대상] [값 A] ([기관 A], [산정 방식]) / [값 B] ([기관 B], [산정 방식])".
- `경고.md` "쓰지 않는 수치"에 있는 값은 넣지 않는다.

### KOSIS 2024 외국인 자료

- 조건마다 따로 나뉜 값이다. 조사시기 행과 거주국가 행을 섞어 "여름 일본인 값"처럼 만들지 않는다. 각각 따로 한 줄씩 쓴다.
- 언어권을 거주국가로 대신 잰 값에는 "간접 근거" 경고를 단다 (예: 영어권 → 미주).

### 관심 관광지 (월별)

- 1단계가 고른 행(계절 달 · 언어권 · 구)에서 관광지별로 **몇 번 나왔는지** 센다. 해마다 따로 센다.
- 문장 형식: "[해] [계절] [언어권] 관심 관광지에 [관광지]가 [n]번 나왔습니다 (계산값: [월] 목록 등장 횟수 합, 관광데이터랩)."
- 같은 장소가 언어마다 다른 이름으로 나오면 묶지 않고 원래 이름 그대로 둔다. 묶어야 하면 `[자료 필요: 장소 이름 대응표]`.

## 3. 계절 합계 규칙 (입장객 같은 수치 자료)

- 계절: 봄 3~5월, 여름 6~8월, 가을 9~11월, 겨울은 **같은 해**의 1 · 2 · 12월 (`지침/1_기획조건/입력.md` 기준).
- 해마다 따로 합한다. 여러 해를 합치거나 평균 내지 않는다.
- 세 달 값이 다 있을 때만 합계를 쓴다. 한두 달만 있으면 "[해] [계절] 일부 월만 있음 ([월]: [값]명)"이라고 쓴다.
- 합계 옆에 각 월 값을 함께 적어 검산할 수 있게 한다. 예: "2024 가을 2,514명 (9월 877 + 10월 1,021 + 11월 616, 계산값)".
- `지침/공통/데이터_목록.md`에 계절 합계표가 생기면 직접 더하지 말고 그 표를 읽는다.
