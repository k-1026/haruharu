# 2단계 수요 근거 — 경고 (E3)

수치를 읽은 뒤 근거가 약하거나 수요가 적은 조합이면 경고를 단다. 경고는 진행을 막지 않는다. 담당자는 **조건 바꾸기(1단계로)** 또는 **경고를 남기고 진행**을 고른다. 경고는 3단계 코스의 장소 근거와 4단계 홍보 검토 화면까지 따라간다.

| 경고 | 언제 | 문구 형식 |
|---|---|---|
| 표본 작음 | 표본 수가 기준보다 작다 | 기준값 `[자료 필요: 팀 확정]` |
| 간접 근거 (대리 지표) | 조건을 직접 재지 않고 일부만 보여 주는 자료다. **시기 조건은 지금 늘 해당** (향촌문화관 1곳) | "[조건]은 [자료 범위]로만 볼 수 있습니다. [전체 대상]의 수요가 아닙니다." |
| 기간 다름 | 기관 데이터와 우리 자료의 기간이 다르다 | "[자료 A]는 [기간], [자료 B]는 [기간] 기준입니다." |
| 변동 큼 | 같은 조건의 값이 해마다 크게 다르다 (예: 국가 비율) | "[대상] 값은 [연도] [값] ~ [연도] [값]으로 해마다 다릅니다 ([출처])." 판단 기준 `[자료 필요: 팀 확정]` |
| 수요 적은 조합 | 고른 조건의 비율 · 수치가 기준보다 낮다 | 기준값 `[자료 필요: 팀 확정]`. 정해지기 전에는 이 경고를 쓰지 않고 값만 보여 준다 |

## 확인 필요

- 역할표 1단계 예시 "겨울 당일형은 무박 6.2%로 수요가 적음"은 수치로 수요를 판단하는 문장이라 이 파일의 "수요 적은 조합"에 해당한다. 역할표 예시 위치를 2단계로 옮길지 팀 확인이 필요하다.
- 6.2%는 지금 정리본에서 찾지 못했다. `kosis_foreign_stay_2024.csv`의 무박 11.1%는 계절 구분 없는 2024년 값이라 같은 수치가 아니다. 원출처 확인 전에는 쓰지 않는다.
