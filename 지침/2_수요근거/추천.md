# 2단계 수요 근거 — 체류 기간 추천

1단계에서 체류 기간을 **추천받기**로 골랐을 때만 쓴다. 에이전트는 당일 · 1박2일 중 어느 쪽을 검토할지 **제안만** 하고, 최종 선택은 담당자가 한다.

## 1. 쓰는 자료

`research/data/외국인/대구_외국인숙박기간_2024.csv` (KOSIS 대구관광실태조사 2024, 외국인, 대구 전체)

| 비교할 값 | `category` | `subgroup` | `item` |
|---|---|---|---|
| 전체 기준 | 전체 | 소계 | 무박 |
| 고른 계절 | 조사시기 | 고른 계절에 대응하는 기 | 무박 |
| 다른 계절 | 조사시기 | 나머지 세 기 | 무박 |
| 고른 언어권 | 거주국가 | 언어권에 대응하는 국가 (`지침/공통/데이터_목록.md` 2장) | 무박 |

- 무박 비율 = 당일 여행 비율로 읽는다.
- 계절과 언어권을 함께 나눈 값은 없다. 두 값을 곱하거나 섞어 "여름 일본인 당일 비율"처럼 만들지 않는다.

## 2. 보여 주는 순서

1. 고른 계절의 당일 비율과 다른 세 계절 값을 한 표로 보여 준다 (각 값에 응답자 수).
2. 고른 언어권의 당일 비율과 전체 값을 보여 준다 (응답자 수).
3. "해석:"으로 시작하는 제안 한 줄.
4. 경고 (`경고.md`). 최소한 "구 구분 없음(대구 전체)"과, 해당하면 "표본 작음"을 붙인다.

## 3. 제안 문구

| 상황 | 제안 문구 |
|---|---|
| 고른 계절 또는 언어권의 당일 비율이 전체보다 높다 | "해석: [계절/언어권]은 당일 비율이 전체보다 높아, 1박2일과 함께 **당일형도 검토**해 볼 만합니다." |
| 둘 다 전체와 비슷하거나 낮다 | "해석: [계절]·[언어권] 모두 당일 비율이 전체 수준 이하라 **1박2일 중심**으로 검토하는 것을 제안합니다." |
| 계절과 언어권이 서로 다른 쪽을 가리킨다 | 두 값을 따로 적고 "해석: 계절 기준과 언어권 기준이 다른 방향입니다. 담당자 판단이 필요합니다." |

- "높다 · 비슷하다"를 가르는 기준값(몇 %p 차이부터 높다고 볼지)은 `[자료 필요: 팀 확정]`. 정해지기 전에는 위 문구 대신 값만 나란히 보여 주고 "기준값 미정"이라고 적는다.
- 제안 문구에는 수요가 "많다 · 적다"를 단정하지 않는다.

## 4. 예시 (형식 확인용)

```
## 체류 기간 추천 (여름 · 중국어 간체)
| 구분 | 당일(무박) 비율 | 응답자 |
| 전체 | 11.1% | 1,010명 |
| 6~8월 (여름) | 18.7% | 387명 |
| 4~5월 | 6.6% | 220명 |
| 9~10월 | 6.4% | 199명 |
| 11~12월 | 6.2% | 204명 |
| 거주국가 중국 | 26.9% | 141명 |
(KOSIS 대구관광실태조사 2024, 외국인, 대구 전체)

해석: 여름과 중국 모두 당일 비율이 전체보다 높아, 1박2일과 함께 당일형도 검토해 볼 만합니다. (기준값 미정)

경고:
- [구분 없음] 대구 전체 자료이며 구별 값이 아닙니다.
- [표본 작음] 거주국가 중국은 응답자 141명, 그중 당일은 약 38명입니다 (계산값: 141 × 26.9%).
```
