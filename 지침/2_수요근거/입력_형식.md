# 2단계 수요 근거 — 기관 데이터 입력 형식

상태: 제안 (2026-11-20). 팀 확정 전. 담당자가 올리는 기관 데이터를 어떤 형식으로 받고 어떻게 읽는지 정한다.

## 1. 받는 형식

| 형식 | 받음 | 이유 |
|---|---|---|
| CSV (UTF-8, 쉼표) | 받음 | 에이전트가 그대로 읽는다 |
| XLSX | 받음 | 앱이 시트별 CSV로 바꿔서 에이전트에 준다 (에이전트 Read 도구는 XLSX를 읽지 못한다). 첫 시트만 쓰지 않고 시트마다 한 파일로 바꾼다 |
| PDF · HWP | 받지 않음 (MVP) | 표를 뽑는 과정에서 값이 틀려도 검증하기 어렵다. 담당자가 표를 엑셀로 옮겨 올린다 |

- PDF 표 읽기는 확장 과제다. 넣게 되면 모든 값에 "추출값, 원표 확인 필요"를 붙이고, CLAUDE.md 5번대로 원본이 아닌 "추출·정리본"으로 표시한다.
- HWP는 지원하지 않는다.
- 파일 하나에 표 하나. 한 시트에 표가 여러 개 섞여 있으면 담당자에게 나눠 올려 달라고 알린다.

## 2. 두 가지 방식

| 방식 | 설명 | 에이전트가 하는 일 |
|---|---|---|
| 템플릿 (권장) | `기관데이터_템플릿.csv` 열을 그대로 채운다 | 열 이름이 정해져 있어 바로 읽는다 |
| 자유 형식 | 기관이 낸 표를 그대로 올린다 | 열 이름으로 값의 뜻을 읽고, 해석한 내용을 담당자에게 보여 확인받는다 |

자유 형식에서 열 이름만으로 뜻이 불분명하면 추정하지 않고 담당자에게 묻는다. 담당자가 확인하기 전에는 근거표에 넣지 않는다.

## 3. 템플릿 열

| 열 | 뜻 | 예 | 비어 있으면 |
|---|---|---|---|
| 출처 | 기관 · 조사 이름 | ○○관광재단 외국인 방문 조사 | 미확인 |
| 기간 | 값이 설명하는 때 | 2025 / 202509 | 미확인 |
| 지역 | 대구 / 중구 / 시설 이름 | 대구광역시 중구 | 미확인 |
| 대상 | 외국인 전체 / 국가 / 시설 이용객 | 외국인 | 미확인 |
| 항목 | 방문객 · 좋았던 점 · 음식 · 숙박 중 어디에 쓰는 값인지 | 방문객 | 미확인 |
| 값 | 숫자 | 3393 | 비교 불가 (행 제외) |
| 단위 | 명 / % / 건 / 박 | 명 | 비교 불가 |
| 표본수 | 응답자 수 (조사 값일 때) | 1010 | 표본 미확인 |

- 열 이름(헤더)은 한글로 쓰고 띄어쓰기를 넣지 않는다 (CLAUDE.md 2번).
- 값은 기관 표의 숫자를 그대로 옮긴다. 합계 · 비율 같은 계산은 담당자가 하지 않고, 필요하면 에이전트가 계산하고 "계산값"이라고 적는다.
- 적지 않은 칸은 "미확인"으로 두고 추정해 채우지 않는다.

## 4. 올릴 때 담당자가 같이 적는 것

파일에 열이 없으면 올리면서 따로 적는다: 출처 · 기간 · 대상 · 지역 · 단위. `비교_확인.md`의 확인 순서와 같다.

## 5. 읽은 뒤 확인

에이전트는 읽은 결과를 담당자에게 먼저 보여 준다.

```
올린 파일: ○○.csv (N행)
읽은 내용: 출처 ..., 기간 ..., 지역 ..., 대상 ..., 단위 ...
확인 못 한 항목: ...
```

담당자가 맞다고 하면 `비교_확인.md`로 넘어간다. 틀리면 파일을 고쳐 다시 올린다.

## 6. 앱이 하는 일 (app/)

- 확장자를 확인한다. PDF · HWP는 "엑셀이나 CSV로 옮겨 올려 주세요"라고 알리고 받지 않는다.
- XLSX는 시트별 CSV로 변환해 실행 폴더에 두고 경로를 에이전트에 준다. 병합 셀 · 수식은 값만 가져온다.
- 원본 파일은 수정하지 않고 `runs/` 실행 폴더에 복사해 보관한다.
