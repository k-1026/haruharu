# 2단계 수요 근거 — 입력

## 1. 1단계에서 받는 것

`지침/1_기획조건/출력.md`의 "2단계로 넘기는 것" 블록을 그대로 받는다.

- 조건 (계절 · 체류 기간 · 대상 국가, 언어권)
- 고른 자료 목록 (자료 · 파일 · 고른 범위 · 재는 방식)
- 공통 자료 목록
- E1 알림과 담당자 선택 (조건 바꾸기 / 알림을 남기고 진행)

## 2. 담당자가 하는 것

| 선택 | 다음 |
|---|---|
| 기관 데이터를 올린다 | `비교_확인.md`로 비교 가능한지 확인 |
| "없음"에 체크한다 | 우리 자료(1단계 목록)만으로 `근거표.md` 작성 |

- 올릴 수 있는 파일 형식, 열 이름 맞추는 방법: `[자료 필요: 팀 확정]`
- 1단계 알림의 "기관 데이터로 채우면 좋은 곳"을 담당자에게 다시 보여 준다.
