# 2단계 수요 근거 — 입력

## 1. 1단계에서 받는 것

`지침/1_기획조건/출력.md`의 "2단계로 넘기는 것" 블록을 그대로 받는다.

- 조건 (방문객 · 계절 · 대상 언어권 · 지역 · 체류 기간)
- 고른 자료 목록 (자료 · 파일 · 고른 행 · 재는 방식)
- 공통 자료 목록
- 체류 기간 추천 요청 여부 (1단계에서 "추천받기"를 골랐을 때 있음. 규칙은 `추천.md`)
- E1 알림과 담당자 선택 (조건 바꾸기 / 알림을 남기고 진행)

## 2. 담당자가 하는 것

| 선택 | 다음 |
|---|---|
| 기관 데이터를 올린다 | `비교_확인.md`로 비교 가능한지 확인 |
| "없음"에 체크한다 | 우리 자료(1단계 목록)만으로 `근거표.md` 작성 |

- 올릴 수 있는 파일 형식 (제안, 팀 확정 전): CSV · XLSX. PDF · HWP는 받지 않는다. 템플릿 또는 자유 형식. 읽는 방법과 확인 절차는 `입력_형식.md`, 템플릿은 `기관데이터_템플릿.csv`.
- 올릴 때 담당자가 함께 적는 것 (제안): 출처(기관 · 조사 이름) · 기간 · 대상 · 지역 · 단위. `비교_확인.md`의 확인 항목과 같다. 적지 않은 항목은 "미확인"으로 두고 추정하지 않는다.
- 1단계 알림의 "기관 데이터로 채우면 좋은 곳"을 담당자에게 다시 보여 준다.
- "없음"을 고르면 기관 데이터 없이 진행하며, 넘김 블록의 확인 전 표시에 "기관 데이터 없음"이라고 적는다.
