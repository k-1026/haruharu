# 2단계 수요 근거 — 비교 확인 (E2)

담당자가 올린 기관 데이터를 우리 자료와 함께 쓸 수 있는지 확인한다.

올린 파일을 읽는 방법과 읽은 내용의 담당자 확인은 `입력_형식.md`를 먼저 따른다. 담당자가 읽은 내용을 맞다고 한 뒤에 아래 순서로 비교한다. 템플릿의 "미확인" 칸은 해당 확인 항목에서 "미확인"으로 두고 추정하지 않는다.

## 확인 순서

| 순서 | 확인 | 우리 자료와 다르면 |
|---|---|---|
| 1 | 출처 (기관 · 조사 이름) | 출처를 적고 계속 |
| 2 | 기간 (연도 · 월) | 기간 다름 → 함께 쓰되 `경고.md`의 "기간 다름" |
| 3 | 대상 (외국인 전체 / 특정 국가 / 특정 시설 등) | 대상 다름 → 비교 불가 |
| 4 | 지역 (대구 / 중구 / 시설) | 지역 다름 → 비교 불가 |
| 5 | 단위 (명 / % / 건) | 단위 다름 → 비교 불가 (단위를 바꿔 계산하지 않는다) |

## 비교 불가일 때 (E2)

문구: "올린 [자료 이름]은 우리 자료와 [다른 항목]이 달라 바로 비교할 수 없습니다."

담당자 선택: **다시 올리기** / **경고를 달고 함께 쓰기** / **기관 데이터 빼기**

- 판정 기준의 세부(예: 기간이 몇 년 차이까지 함께 쓸지): `[자료 필요: 팀 확정]`
