# 3단계 코스 검토 — 장소별 근거

코스에 넣은 장소마다 **왜 넣었는지**를 근거와 함께 붙인다. 이 근거가 4단계 장면 문구의 사실 근거가 된다.

## 1. 장소별 근거 열

| 열 | 내용 |
|---|---|
| 장소 | 공식 명칭, "대구광역시 ○○구" |
| 넣은 이유 | 2단계 수요 요약 · 근거표의 어느 항목과 연결되는지. **근거 ID로 가리킨다** (예: "R07 · R08: 외국인 방문 관광지") |
| 근거 수치 | 2단계 근거표 값 그대로 (근거 ID · 출처 · 연도 · 표본) |
| 운영 정보 | 영업시간 · 휴무 확인 상태와 출처 |
| 운영 주체 후보 | `11_운영주체_후보.md` 2장의 후보와 표시를 그대로 옮긴다 (후보임을 표시) |
| 이어받은 경고 | 이 장소가 쓴 근거 ID에 달린 2단계 경고를 **경고 ID째** 모은다 (예: "W2 표본 작음 (R08)") |
| 장소 스토리 | 4단계에서 쓸 수 있는 확인된 이야기와 출처 |

## 2. 쓰는 법

- 수치는 2단계 근거표에서 근거 ID로 가져오고 새로 계산하거나 해석을 바꾸지 않는다. 근거표에 없는 근거 ID를 쓰지 않는다.
- 사실과 팀 해석을 나눈다. 해석은 "해석:"으로 시작한다.
- 출처는 공통 출처 ID(`research/sources.md`)로 쓴다. ID가 없으면 "출처 ID 미등록"으로 표시한다.
- 실존 업체 · 생존 인물은 공개된 공식 기록 범위에서만 쓴다 (팀 CLAUDE.md 5번).
- 장소 스토리는 출처가 있는 것만 쓴다. 출처 없는 이야기는 "스토리 미확인"으로 두고 4단계에 넘기지 않는다.

## 3. 경고 이어받기

- 2단계 경고는 지우지 않고 해당 장소 근거에 경고 ID · 문구 그대로 붙여 4단계까지 넘긴다 (유저플로우 52행). 경고 목록의 "적용 근거 ID"와 장소가 쓴 근거 ID가 겹치는 경고를 모은다. 경고를 합치거나 문구를 고치지 않는다.
- 근거가 없는 장소는 "근거 없음"으로 표시한다. 넣을지는 담당자가 정한다.
