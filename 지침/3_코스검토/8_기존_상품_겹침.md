# 3단계 코스 검토 — 기존 상품 겹침 표시 (E7)

- 상태: v0.1 (2026-11-18). 팀 검토 전.
- 왜 필요한가: 중구청이 발주한 비비드 동성로 투어는 운영 1회, 참여 2명에 그쳤고, 원인 중 하나로 "기존 근대골목 투어와 노선 중복"이 보도됐다 (언론 기준). 같은 지역에 구청 상품이 이미 여럿 있어 새 코스가 기존 노선을 그대로 따라가기 쉽다. → `painpoint_def.md` PP-3a
- 대조 목록: `9_기존_상품_목록.md`

코스 시간표의 장소를 기존 상품의 경유 장소와 대조해, 겹치는 곳에 표시를 단다. **E4(운영 충돌)와 다르다.** E4는 "이 코스가 실제로 돌아가는가"를 보고, E7은 "이미 있는 상품과 똑같지 않은가"를 본다. 겹침은 진행을 막지 않고, 나쁜 것으로 단정하지도 않는다. 담당자가 **피하기** 또는 **연결하기**를 고른다.

## 1. 대조 순서

| 순서 | 확인 | 결과 |
|---|---|---|
| 1 | 코스의 각 장소가 `9_기존_상품_목록.md` 2장의 경유 장소에 있는가 (3장 "같은 장소로 보는 이름" 포함) | 장소 겹침 |
| 2 | 코스에서 이어지는 장소 3곳 이상이 같은 상품 하나에 모두 들어 있는가 | 노선 겹침 |
| 3 | 겹친 상품이 같은 시간대(낮 / 저녁)에 운영되는가 | 시간대 겹침 여부 |
| 4 | 겹친 상품의 운영 상태가 미확인인가 | "운영 여부 미확인" 덧붙임 |

- 노선 겹침 기준(연속 3곳): `[자료 필요: 팀 확정]`. 정하기 전까지 3곳으로 본다.
- 동구 장소는 대조할 목록이 아직 없다. "대조 목록 없음(동구)"으로 표시한다.

## 2. 표시 문구

| 결과 | 문구 형식 |
|---|---|
| 장소 겹침 | "[장소]는 [상품 이름]에도 들어 있는 장소입니다 ([상품 ID], [운영 상태])." |
| 노선 겹침 | "[장소 A] → [장소 B] → [장소 C]는 [상품 이름]과 같은 노선입니다 ([시간대])." |
| 운영 여부 미확인 | 위 문구 뒤에 "이 상품의 현재 운영 여부는 확인하지 못했습니다."를 붙인다 |
| 대조 목록 없음 | "[장소]는 대조할 기존 상품 목록이 없습니다." |

- 한 장소가 여러 상품에 겹치면 상품을 모두 적되, 노선 겹침이 있는 상품을 먼저 적는다.

## 3. 담당자 선택지와 에이전트가 내는 제안

| 선택 | 뜻 | 에이전트가 내는 것 |
|---|---|---|
| 피하기 | 기존 상품과 다른 코스로 바꾼다 | 같은 시간 칸 · 같은 지역에서 **기존 상품 목록에 없는** 장소 후보. 후보에도 `4_충돌_대체.md`의 E4 대조와 `5_장소_근거.md`의 근거를 붙인다. 후보가 없으면 "대체 후보 없음". 시간 칸별 후보는 `10_대체_규칙.md` 7장 |
| 연결하기 | 겹침을 살려 기존 상품과 묶는다 | 어떤 방식으로 묶을 수 있는지 사실만 적는다. 예: "이 장소는 S1 근대골목 스탬프 보관장소입니다." 운영 주체와 협의가 필요하다는 점을 함께 적는다. 협의 대상 후보는 `11_운영주체_후보.md` 3장 |
| 그대로 두기 | 표시만 남기고 진행한다 | 표시를 지우지 않고 4단계까지 넘긴다 |

- 에이전트는 셋 중 하나를 고르지 않는다. 고르는 것은 담당자다.
- **"미선택"으로 코스를 확정하려 할 때** (2026-11-20 사람2 결정, 사람1 1120 보완안 2-3 ③):
  - **노선 겹침**(연속 3곳 이상): 선택 필수. 담당자가 셋 중 하나를 고르기 전에는 코스를 확정하지 않고 초안으로 보관한다. 비비드 동성로 투어 저조 원인으로 보도된 경우라서다 (PP-3a).
  - **장소 겹침**: 미선택이어도 확정할 수 있다. 확정 때 "미선택 → 그대로 두기로 처리"로 겹침 이력에 남기고, 4단계는 이 장소에 "연결하기" 문구(기존 상품 언급)를 쓰지 않는다.
- "연결하기"는 기존 상품을 운영하는 곳(대부분 중구청 관광과)과의 협의가 전제다. 협의된 것처럼 쓰지 않는다.

## 4. 기록

- 겹침 표시와 담당자 선택은 "겹침 이력"에 남긴다: 장소 · 겹친 상품 ID · 결과 종류 · 담당자 선택.
- "피하기"로 장소를 바꾸면 `4_충돌_대체.md`의 "대체 이력"에도 같이 남긴다 (충돌 종류: 기존 상품 겹침).
- 겹침 이력은 4단계로 넘긴다. 4단계는 "연결하기"를 고른 장소의 홍보 문구에서 기존 상품을 언급할 수 있다.

## 5. 하지 않는 것

- 기존 상품의 품질이나 성과를 평가하는 일. 실적 수치가 없으므로 "인기 없음" 같은 판단을 쓰지 않는다.
- 비비드 투어 사례를 표시 문구에 넣는 일. 사례는 이 파일의 "왜 필요한가"에만 둔다.
- 목록에 없는 상품을 추측해 겹친다고 표시하는 일.
