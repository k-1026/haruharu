# 3단계 코스 검토 — 출력

## 화면에 나오는 결과

유저플로우 S3의 "시간표 형태의 코스 + 충돌 표시 + 대체안 + 장소별 근거"에 기존 상품 겹침 표시(E7)를 더한 것이다.

## 출력 형식

```
## 조건
- 시기 · 체류 기간 · 대상 국가 (1단계 그대로)
- 코스 시작: [일차] [장소] [시각] / 코스 종료: [일차] [장소] [예정 시각] — 확정 / 후보 (담당자 확인 전)   (`2_입력.md` 5-2)

## 코스 시간표
| 순서 | 시간 칸 | 시각 | 장소 | 머무는 시간 | 다음까지 이동 | 충돌 |

## 충돌과 대체안 (E4)
- [충돌 종류] 문구 → 대체안: [장소] / 대체안 없음   ← 없으면 "없음"

## 기존 상품 겹침 (E7)
- [장소 겹침 / 노선 겹침] 문구 → 담당자 선택: 피하기 / 연결하기 / 그대로 두기 (미선택)   ← 없으면 "없음"

## 장소별 근거
| 장소 | 넣은 이유 (근거 ID) | 근거 수치 | 운영 정보 | 운영 주체 후보 | 이어받은 경고 (경고 ID) |

## 체크리스트 (12_코스_체크리스트.md)
| # | 항목 | 결과 (통과 / 통과 못 함 / 확인 불가) | 이유 · 없는 자료 |

## 4단계로 넘기는 것   ← 코스 시작 · 종료가 확정됐을 때만 만든다
- 확정 코스 (시간표 · 장소 · 순서)
- 코스 시작 · 종료 장소와 시각 (확정값)
- 장소별 근거 · 운영 주체 후보
- 장소 스토리 (출처 있는 것만)
- 대체 이력
- 겹침 이력 (장소 · 겹친 상품 ID · 담당자 선택)
- 남은 경고 (경고 ID · 적용 근거 ID 포함)
```

## 4단계가 받는 것

`4단계로 넘기는 것` 블록이 `../4_홍보검토/2_입력.md`의 "3단계에서 받는 것"이다. 항목을 바꾸면 4단계 `2_입력.md`도 같이 고친다.

## E6로 다시 넘길 때

4단계 요청으로 코스를 고쳤으면 전체가 아니라 **바뀐 장소 · 시간과 영향받는 장면 번호**만 넘긴다.

## 4단계 요청 없이 코스를 고쳤을 때 (E6 밖)

담당자가 3단계에서 직접 장소 · 시간이나 코스 시작 · 종료를 바꾸면, 바뀐 항목을 4단계로 넘겨 영향받는 장면을 "다시 확인 필요"로 표시하게 한다 (`../4_홍보검토/8_코스_변경.md` 4장). 장면 번호를 모르면 바뀐 장소 · 시간 · 시작 · 종료만 넘긴다.
