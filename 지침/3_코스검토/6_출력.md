# 3단계 코스 검토 — 출력

## 화면에 나오는 결과

유저플로우 S3의 "시간표 형태의 코스 + 충돌 표시 + 대체안 + 장소별 근거"에 기존 상품 겹침 표시(E7)를 더한 것이다.

## 출력 형식

```
## 조건
- 시기 · 체류 기간 · 대상 국가 (1단계 그대로)
- 코스 시작: [일차] [장소] [시각] / 코스 종료: [일차] [장소] [예정 시각] — 확정 / 후보 (담당자 확인 전)   (`2_입력.md` 5-2)

## 코스 시간표
| 순서 | 시간 칸 | 시각 | 장소 | 머무는 시간 | 다음까지 이동 | 충돌 |
   ← 식사 칸의 "장소"에는 지정식이면 식당, 자유식이면 "자유식 · [식사 권역]"을 쓴다. 자유시간은 "자유시간 (담당자 선택)", 미정 시간은 "빈 시간 — 제안 칸"으로 구분한다

## 식사 (3_코스_짜기.md 1-2)   ← 식사 칸마다 한 줄
| 일차 · 칸 | 식사 방식 (지정식 / 자유식 / 미선택) | 시간 | 권역 | 식당 (지정식) / 추천 후보 (자유식) | 식비 포함 (포함 / 불포함 / 미정) | 이동 시간 · 적용 조건 (예: "산호찜갈비 이용 시 참고값") | 이후 연결 (재집결 / 다음 일정 도착 장소 · 시각) |

## 충돌과 대체안 (E4)
- [충돌 종류] 문구 → 대체안: [장소] / 대체안 없음   ← 없으면 "없음"

## 기존 상품 겹침 (E7)
- [장소 겹침 / 노선 겹침] 문구 → 담당자 선택: 피하기 / 연결하기 / 그대로 두기 (미선택)   ← 없으면 "없음"

## 해설 · 체험 제안 (3_코스_짜기.md 5장)   ← 없으면 "없음"
- 제안: [칸]에 [해설 · 체험] ([요일 · 시간], 운영 주체 후보) / 요일 맞지 않음 / 운영 여부 미확인

## 장소별 근거
| 장소 | 넣은 이유 (근거 ID) | 근거 수치 | 운영 정보 | 운영 주체 후보 | 이어받은 경고 (경고 ID) |

## 담당자 결정 기록 (4_충돌_대체.md 4장)   ← 없으면 "없음"
| 항목 | 고른 것 | 고르지 않은 후보 · 메모 | 누가 · 언제 |

## 체크리스트 (12_코스_체크리스트.md)
| # | 항목 | 결과 (통과 / 통과 못 함 / 확인 불가) | 이유 · 없는 자료 |

## 4단계로 넘기는 것   ← `2_입력.md` 3장 확정 조건 ①②③을 모두 채웠을 때만 만든다 (① 시작 · 종료 확정 ② 노선 겹침 선택 또는 없음 ③ 1박2일이면 2일차 오전 구성 선택)
- 확정 코스 (시간표 · 장소 · 순서)
- 코스 시작 · 종료 장소와 시각 (확정값)
- 식사 (식사 칸마다: 지정식 · 자유식 여부, 시간, 권역, 식당 또는 추천 후보, 식비 포함 여부, 이동 시간과 그 적용 조건, 이후 연결). 식비 포함 "미정"은 미정으로 넘긴다
- 운영 방식 (단체 동행형 / 개별 이동형 / 미정) · 2일차 오전 구성 (담당자 선택)
- 장소별 근거 · 운영 주체 후보
- 장소 스토리 (출처 있는 것만)
- 대체 이력
- 담당자 결정 기록
- 겹침 이력 (장소 · 겹친 상품 ID · 담당자 선택)
- 남은 경고 (경고 ID · 적용 근거 ID 포함)
- 3단계 미확인 사항 (운영 정보 미확인 · 이동 시간 미확인 · 미정 시각 · 가정 값). 시각마다 **확정 / 가정 / 미정**을 구분해 넘긴다 — 4단계는 가정 시각을 "약 ○○:○○"로만 쓰고, 미정 시각과 미확인 운영 정보는 쓰지 않는다 (`../4_홍보검토/4_문구.md` 2-2)
```

- **안이 둘 이상일 때** (예: 평일안 · 토요일안, 2026-11-22 추가): 공통 부분은 한 번만 쓰고, 다른 줄만 안별로 따로 적는다. 각 표 · 이력에는 "안" 열 또는 "(토요일안만)" 표시를 붙인다. 체크리스트는 안별로 결과를 적는다.

## 4단계가 받는 것

`4단계로 넘기는 것` 블록이 `../4_홍보검토/2_입력.md`의 "3단계에서 받는 것"이다. 항목을 바꾸면 4단계 `2_입력.md`도 같이 고친다.

## E6로 다시 넘길 때

4단계 요청으로 코스를 고쳤으면 전체가 아니라 **바뀐 장소 · 시간과 영향받는 장면 번호**만 넘긴다.

## 4단계 요청 없이 코스를 고쳤을 때 (E6 밖)

담당자가 3단계에서 직접 장소 · 시간이나 코스 시작 · 종료를 바꾸면, 바뀐 항목을 4단계로 넘겨 영향받는 장면을 "다시 확인 필요"로 표시하게 한다 (`../4_홍보검토/8_코스_변경.md` 4장). 장면 번호를 모르면 바뀐 장소 · 시간 · 시작 · 종료만 넘긴다.
