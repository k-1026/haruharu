# 3단계 코스 검토 — 충돌 표시 · 대체안 (E4)

코스 시간표를 장소 운영 정보와 대조해 맞지 않는 곳을 표시하고 대체안을 낸다. 충돌은 진행을 막지 않는다. 담당자는 **대체안 받기** 또는 **직접 고치기**를 고른다.

## 1. 대조 순서

| 순서 | 확인 | 충돌 종류 |
|---|---|---|
| 1 | 방문 요일이 정기 휴무인가 | 휴무 |
| 2 | 방문 시각이 영업시간 안인가 (도착 ~ 떠나는 시각 모두) | 영업시간 |
| 3 | 앞 장소에서 떠나 다음 장소 도착까지 이동 시간이 충분한가 | 이동 시간 |
| 4 | 운영 정보가 있는가 | 운영 정보 미확인 |

- 이동 시간 판정 (순서 3, 2026-11-19 사람1 정리 · 사람2 확인). 상한 · 도보 기준은 `2_입력.md` 5장 설정값(지금 30분 · 20분, 가정)이다.
- **자유식 · 자유시간 칸의 이동 (2026-11-22 추가, 사람1 수정 요청):**
  - 식당 한 곳이 정해지지 않았으므로 **식사 권역(또는 자유시간 권역) → 다음 일정 장소 · 시각**의 이동 여유를 본다. 권역에서 다음 장소까지 기록된 구간이 없으면 "이동 시간 미확인"이다.
  - 추천 후보 한 곳 기준으로 잰 이동 시간은 **"○○ 이용 시 참고값"**으로 적는다. 다른 식당을 골라도 같은 시간이 걸리는 것처럼 쓰지 않는다.
  - 운영 방식이 단체 동행형이면 **재집결 장소 · 시각**, 개별 이동형이면 **다음 일정의 도착 장소 · 시각**을 적는다 (`3_코스_짜기.md` 1-2). 운영 방식이 미정이면 둘 다 "미정"으로 적는다.

| 판정 | 조건 (대중교통 기준) | 표시 |
|---|---|---|
| 통과 | 상한보다 4분 이상 짧고 환승 없음 (상한 30분이면 26분 이하) | 충돌 아님 |
| 경고 | 상한까지 3분 이내 (상한 30분이면 27~30분) 또는 환승 1회 | 충돌 문구에 "경고"를 붙이고 진행 |
| 대체 검토 | 상한 초과 또는 환승 2회 이상 | 충돌로 표시하고 `10_대체_규칙.md` 5장 대체안을 낸다 |

- 도보: 도보 분이 도보 기준 이하면 도보도 함께 안내한다. 넘으면 대중교통 값으로만 판정한다.
- 3분의 근거: 네이버 지도 조회값의 요일 · 시각 차이(1~3분, 사람1 조회)와 대구 버스정보시스템 시간표상 일요일 배차가 평일보다 약 3분 김 [F `정리본/대구_버스_시간대별_배차간격_주말.md` 2장 "일요일은 평일보다 약 3분 길어 18~19분대", 2026-11-21 · 22 시간표 기준. 원자료는 대구광역시 버스정보시스템 [P]].
- 환승 기준의 근거: KOSIS 외국인 개선사항의 언어 · 안내 불편 응답(S79). 항목 비율이 작아 방향 근거로만 쓴다.

## 2. 충돌 문구

| 충돌 | 문구 형식 |
|---|---|
| 휴무 | "[장소]는 [요일] 휴무입니다 ([출처], [확인일])." |
| 영업시간 | "[장소]는 [시작]~[끝] 운영이라 [방문 시각]에 이용할 수 없습니다 ([출처])." |
| 이동 시간 | "[장소 A] → [장소 B] 이동은 [분]분인데 시간표 간격은 [분]분입니다." |
| 운영 정보 미확인 | "[장소]의 [영업시간 / 휴무 / 이동 시간]을 아직 확인하지 못했습니다." |

## 3. 대체안 규칙

이 장은 대체안을 고르는 **순서**만 정한다. 상황(휴장 · 마감 · 이동 시간 초과 · 가족 부적합 · E7 피하기)별로 어떤 후보가 있고 어떤 조건에서 쓸 수 있는지는 `10_대체_규칙.md`를 본다.

1. 같은 시간 칸 · 같은 종류(관광지 / 시장 / 같은 저녁 묶음, `3_코스_짜기.md` 1 · 4장)의 다른 장소를 먼저 찾는다.
2. 없으면 같은 지역의 관광지로 바꾼다 (역할표 예시: 월요일 체험 시설 휴장 → 관광지로 대체. 땅땅치킨랜드 월요일 휴장은 팀 자료 기재 [F], `10_대체_규칙.md` 3-2). 운영시트의 실내 대체 후보 4곳은 모두 월요일 휴관이다 → `10_대체_규칙.md` 3-1.
3. 대체 장소도 1장 대조 순서를 다시 거친다. 대체 장소에도 `5_장소_근거.md`의 근거를 붙인다.
4. 대체안이 없으면 "대체안 없음"이라고 쓰고 담당자가 고치게 한다. 근거 없는 장소를 채워 넣지 않는다.

## 4. 기록

- 바꾼 내용은 "대체 이력"에 남긴다: 원래 장소 · 충돌 종류 · 바꾼 장소 · 누가 골랐는지(대체안 / 직접).
- 대체 이력은 4단계로 넘긴다.
- **충돌 때문이 아닌 담당자 결정은 "담당자 결정 기록"에 따로 남긴다** (2026-11-22 추가). 예: 저녁 묶음에서 식당 고르기, 비운 칸을 그대로 두기, 2일차 오전 장소를 두지 않기, 설정값 바꾸기. 열: 항목 · 고른 것 · 고르지 않은 후보와 그 메모(예: "근거가 더 강한 후보") · 누가 · 언제. 충돌로 장소를 바꾼 경우는 대체 이력에만 적는다 (2.6 테스트 A에서 에이전트가 담당자 결정을 대체 이력에 "충돌로 인한 대체 아님"으로 섞어 적었음).
