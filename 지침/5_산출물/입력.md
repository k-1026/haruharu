# 5단계 산출물 — 입력

## 1. 앞 단계에서 받는 것

5단계는 4단계만이 아니라 **1~4단계 결과를 모두** 받는다. 결재 파일에 조건 · 근거 · 코스가 함께 들어가기 때문이다.

| 단계 | 받는 것 | 받는 곳 |
|---|---|---|
| 1 기획 조건 | 조건 요약(방문객 · 시기 · 언어권 · 지역 · 체류 기간), E1 알림과 담당자 선택 | `지침/1_기획조건/출력.md` "조건 요약" · "알림 (E1)" |
| 2 수요 근거 | 수요 분석 요약, 근거표(출처 · 연도 · 표본 · 한계), 경고 목록(E2 · E3)과 담당자 선택, 고른 체류 기간 | `지침/2_수요근거/출력.md` "3단계로 넘기는 것" |
| 3 코스 검토 | 확정 코스(시간표 · 장소 · 순서, 코스 시작 장소 · 시각 / 종료 장소 · 예정 시각), 장소별 근거 · 운영 주체 후보, 대체 이력(E4), 겹침 이력(E7)과 담당자 선택, 남은 경고 | 사람2 브랜치 `지침/3_코스검토/6_출력.md` "4단계로 넘기는 것" |
| 4 홍보 검토 | 코스 카드(B6), 확정 문구 · 번역(상태: AI 초안 / 검토 중 / 검토 완료(검토자 · 날짜)), 장면 → 홍보물 대응표, 고른 톤앤매너 · 시안, 표현 필터 기록(E5), 코스 변경 기록(E6) | 사람2 브랜치 `지침/4_홍보검토/9_출력.md` "5단계로 넘기는 것" |

- 4단계 `9_출력.md`의 "5단계로 넘기는 것"은 코스 카드 · 확정 문구 · 번역(번역 상태 포함) · 대응표 · 톤앤매너 · 시안 · E5 기록 · E6 변경 기록이다 (2026-11-20 사람2 반영 확인).
- 3단계 결과는 4단계를 거쳐 오지 않고 5단계가 직접 받는다. 4단계에서 코스가 바뀌었으면(E6) 바뀐 뒤의 코스를 받는다.

## 2. 담당자가 고르는 것

| 선택 | 선택지 | 비고 |
|---|---|---|
| 만들 파일 | 결재 파일 · 제안서 · 홍보물 묶음 (여러 개 고를 수 있음) | 기본값 세 가지 모두 |
| 결재 파일 양식 | 기관 양식 올리기 / 기본 양식 | 기본 양식의 목차는 `출력.md`. 기관 양식(HWP 등)을 올리면 그 목차 순서에 맞춰 같은 내용을 옮긴 **초안**을 만든다. 받을 수 있는 양식 파일 종류는 `[팀 확정 전]` |
| 제안서 받는 쪽 | 여행사 · 운영 주체 후보 등 | 3단계 "운영 주체 후보"에서만 고른다. 새 업체를 넣지 않는다 |
| 파일 형식 | 고르지 않는다. 파일마다 아래 형태 후보로 정해져 있다 `[팀 확정 전]` | 결재 파일 = 기관 양식(HWP 등)에 옮겨 쓰는 초안, MVP는 복사해 붙이기 쉬운 문서 · 표 / 제안서 = PDF / 홍보물 묶음 = 언어별 문구표 + 시안 이미지 (유저플로우 v1.1 7장) |

## 받을 때 규칙

- **1~4단계 중 확정되지 않은 단계가 있으면 만들지 않는다.** 어느 단계의 어떤 항목이 비었는지 알리고, 담당자가 그 단계로 돌아간다.
- E6로 코스를 고치는 중이면(4단계 재검토가 끝나지 않았으면) 기다린다. 고치기 전 코스로 파일을 만들지 않는다.
- 앞 단계 결과의 경고 · `[미확인]` · `[자료 필요]` 표시는 받은 형태 그대로 보관한다. 받는 단계에서 정리하거나 빼지 않는다.
- 담당자가 조건(1단계)을 바꿨으면 이전 산출물을 고쳐 쓰지 않고, 바뀐 조건으로 1~4단계를 다시 거친 결과로 새로 만든다.
- 담당자가 5단계에서 수치나 문구를 직접 고치려 하면, 해당 단계(수치 → 2단계, 장소 · 시간 → 3단계, 문구 → 4단계)에서 고치도록 안내한다. 세 파일이 서로 달라지는 것을 막기 위해서다.
