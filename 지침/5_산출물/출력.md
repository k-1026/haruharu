# 5단계 산출물 — 출력

## 화면에 나오는 결과

유저플로우 S5의 "결재 파일 · 제안서 · 홍보물 3종 + 수치 대조"다. 담당자는 세 파일과 대조 결과를 보고 저장한다.

## 파일별 구성

세 파일은 받는 사람이 다를 뿐 **같은 기획 내용**이다. 칸마다 어느 단계 결과를 옮기는지 적었다. 이 표에 없는 내용은 넣지 않는다.

| 파일 | 받는 쪽 | 형태 후보 `[팀 확정 전]` |
|---|---|---|
| 결재 파일 | 기관 내부 보고 | 기관 양식(HWP 등)에 옮겨 쓰는 초안. MVP는 복사해 붙이기 쉬운 문서 · 표 형태. 담당자가 "기관 양식 올리기 / 기본 양식"을 고른다 |
| 제안서 | 여행사 · 운영 주체 후보 | PDF. 가격 · 수수료 칸은 두지 않는다 |
| 홍보물 묶음 | (홍보 담당 · 대행사) | 언어별 문구표 + 시안 이미지. 홍보물 종류는 4단계와 같이 팀 확정 |

### 1. 결재 파일 (기관 내부 보고용)

| 칸 | 옮겨 오는 것 |
|---|---|
| 기획 개요 | 1단계 조건 요약 |
| 근거 요약 | 2단계 수요 분석 요약 + 근거표 (출처 · 연도 · 표본 · 한계 열 그대로, E2 · E3 경고 열 포함) |
| 코스 | 3단계 확정 코스 시간표, 대체 이력(E4), 겹침 이력(E7)과 담당자 선택 |
| 운영 주체 후보 | 3단계 장소별 운영 주체 후보 ("후보"로 표시) |
| 홍보 계획 | 4단계 장면 → 홍보물 대응표, 번역 언어와 번역 상태 |
| 담당자 결정 기록 | E1~E7에서 담당자가 고른 것 (진행 / 대체안 / 피하기 · 연결하기 등) |
| 남은 경고 · 미확인 | 1~4단계에서 넘어온 경고와 `[미확인]` · `[자료 필요]` 표시 전체 |
| 변경 기록 | E6 코스 변경 이력 |

### 2. 제안서 (여행사 · 운영 주체 후보에게 보내는 것)

| 칸 | 옮겨 오는 것 |
|---|---|
| 대상 관광객 | 1단계 조건 (방문객 · 언어권 · 체류 기간) |
| 왜 이 코스인가 | 2단계 수요 분석 요약 (근거 수치에는 출처 ID와 E3 경고를 함께) |
| 코스 | 3단계 확정 코스 시간표, 장소별 근거 · 장소 스토리(출처 있는 것만) |
| 함께할 곳 | 3단계 운영 주체 후보 중 담당자가 고른 받는 쪽 |
| 홍보 시안 | 4단계 시안 · 대표 장면 문구 (장면 번호 표시) |
| 남은 경고 · 미확인 | 결재 파일과 같은 목록 |

- 제안서에 가격 · 수수료 · 보상 금액 칸을 두지 않는다. 필요하면 `[담당자 기입]`으로 비워 둔다.

### 3. 홍보물 묶음

| 칸 | 옮겨 오는 것 |
|---|---|
| 장면 → 홍보물 대응표 | 4단계 그대로 |
| 언어별 문구표 | 4단계 확정 문구와 번역을 장면 × 언어 표로 (사실 근거 출처 ID, 장면 경고, 번역 상태: 초안 / 원어민 검토 완료) |
| 시안 이미지 | 4단계 톤앤매너 · 캐릭터 · 장면별 시안 |
| 표현 필터 기록 | 4단계 E5에서 걸리고 고친 기록 |

## 대조

세 파일을 만든 뒤 아래 항목이 모두 같은지 확인한다.

| 대조 항목 | 확인 방법 |
|---|---|
| 코스 | 장소 이름 · 순서 · 시간 칸이 세 파일에서 같다. 홍보물 묶음은 대응표의 장소 · 시간 칸으로 본다 |
| 수치 | 같은 수치가 나오는 곳마다 값 · 단위 · 기준시점 · 출처 ID가 같다 |
| 경고 | 같은 수치 · 장소에 붙은 경고가 모든 파일에 있다 (한 파일에만 있으면 "경고 누락") |
| 미확인 표시 | `[미확인]` · `[자료 필요]`가 붙은 값이 다른 파일에서 표시 없이 나오지 않는다 |
| 코스 변경 | E6 이후의 코스가 세 파일 모두에 들어갔다 |

- 다른 곳이 있으면 **대조 불일치(E8 후보)** 알림을 낸다. 어느 쪽이 맞는지는 정하지 않는다. E8 번호는 `[팀 확정 전]`.
- 대조 불일치가 남아 있어도 저장은 막지 않는다. 대신 세 파일의 "남은 경고"에 불일치 내용을 적는다.

## 출력 형식

```
## 만든 파일
| 파일 | 받는 쪽 | 형식 | 상태 |
| 결재 파일 | (기관 내부) | 기관 양식 초안 / 기본 양식 문서 · 표 [팀 확정 전] | 완료 / 앞 단계 결과 없음 |
| 제안서 | (3단계 운영 주체 후보 중 선택) | PDF [팀 확정 전] | ... |
| 홍보물 묶음 | — | 언어별 문구표 + 시안 이미지 [팀 확정 전] | ... |

## 대조 결과
| 항목 | 결과 | 다른 곳 |
| 코스 | 같음 / 다름 | (파일 · 칸) |
| 수치 | ... | ... |
| 경고 | ... | ... |
| 미확인 표시 | ... | ... |
| 코스 변경 | ... | ... |

## 대조 불일치 (E8 후보)  ← 없으면 "없음"
- [항목] [파일 A 칸]과 [파일 B 칸]이 다릅니다 → 고칠 단계: n단계

## 남은 경고 · 미확인 (세 파일 공통)
| 경고 | 단계 | 대상 (수치 · 장소 · 장면) | 담당자 선택 |

## 담당자 선택
- 저장 / 해당 단계로 돌아가 고치기 (1 · 2 · 3 · 4단계)
```

## 다음 단계

5단계는 에이전트의 마지막 단계다. 결재 · 발주 · 판매 · 현장 운영(밸류체인 ④ · ⑤)은 담당자와 여행사 · 운영 주체가 한다.
