# 5단계 산출물 — 역할

- 상태: 초안 v0.1 (2026-11-18). 팀 검토 전.
- 기준: 담당자 · 에이전트 역할표 5단계, `inventory/유저플로우_v1.md` S5
- 담당: 사람1

## 한 줄 요약

1~4단계에서 담당자가 확정한 결과를 **결재 파일 · 제안서 · 홍보물 묶음** 세 가지로 묶고, 세 파일의 코스 · 수치 · 출처가 서로 같은지 대조한다. 새 내용은 만들지 않는다.

## 하는 일

1. 1~4단계 결과를 받는다. 빠진 단계가 있으면 알린다. → `입력.md`
2. 받은 결과를 세 파일의 칸에 옮긴다. 옮기는 위치는 `출력.md` "파일별 구성"을 따른다.
3. 세 파일에 같은 코스 · 수치 · 출처가 들어갔는지 대조하고, 다르면 알린다. → `출력.md` "대조"
4. 앞 단계 경고와 미확인 표시를 모은 "남은 경고" 칸을 세 파일에 모두 붙인다.

## 지켜야 할 규칙

### 묶기만 한다

- **새 수치 · 장소 · 출처를 만들지 않는다.** 수치는 2단계 근거표, 장소와 시간은 3단계 확정 코스, 문구와 번역은 4단계 확정본에 있는 것만 쓴다.
- 앞 단계에 없는 칸은 비워 두고 `[앞 단계 결과 없음: n단계 항목명]`으로 적는다. 그럴듯한 값으로 채우지 않는다.
- 문구를 다시 쓰거나 줄이지 않는다. 결재 파일처럼 짧게 써야 하는 칸은 4단계 확정 문구 중 해당 장면을 그대로 고르고, 장면 번호를 적는다.
- 번역을 새로 하지 않는다. 4단계 번역의 상태(초안 / 원어민 검토 완료)를 그대로 적는다.
- 수치의 단위 · 기준시점 · 표본 · 출처 ID는 2단계 근거표와 같은 형태로 옮긴다. 반올림하거나 합치지 않는다.

### 경고와 미확인 표시는 그대로 따라온다

- **E1~E7 경고는 지우지도, 약하게 바꾸지도 않는다.** 담당자가 "경고를 남기고 진행"을 고른 경고는 그 선택과 함께 적는다.

  | 경고 | 앞 단계 | 5단계에서 적는 곳 |
  |---|---|---|
  | E1 조건에 맞는 자료 적음 · 없음 | 1단계 | 결재 파일 "남은 경고" |
  | E2 기관 데이터 비교 불가 | 2단계 | 결재 파일 "근거 요약" 해당 행 + "남은 경고" |
  | E3 근거 약함 (표본 작음 · 간접 근거 · 기간 다름) | 2단계 | 근거 수치가 나오는 모든 파일의 해당 행 + "남은 경고" |
  | E4 휴무 · 영업시간 · 이동 시간 충돌과 대체 | 3단계 | 결재 파일 · 제안서 "코스" (대체 이력 포함) |
  | E5 검증 안 된 표현 | 4단계 | 홍보물 묶음 해당 장면 (고친 기록) |
  | E6 홍보 중 코스 변경 | 3 ↔ 4단계 | 세 파일 "변경 기록" |
  | E7 기존 상품 겹침과 담당자 선택 | 3단계 | 결재 파일 · 제안서 "코스" 해당 장소 |

- 앞 단계의 `[미확인]` · `[자료 필요]` · `[U]` · "확인 전 수치" 표시는 그 값이 들어가는 모든 파일에 그대로 붙인다.
- 한 파일에만 경고가 붙고 다른 파일에는 빠지면 대조에서 "경고 누락"으로 알린다.

## 하지 않는 일

- 수치 · 장소 · 운영 정보 · 출처를 새로 찾거나 만드는 일 (1~3단계).
- 문구를 새로 쓰거나 번역하는 일, 표현을 고치는 일 (4단계). 걸린 표현이 보이면 4단계로 돌려보낸다.
- 예산 · 가격 · 보상 금액을 정하는 일. 사용자(담당자)의 몫이다.
- 운영 주체와 협의 · 계약된 것처럼 쓰는 일. 운영 주체는 "후보"로만 적는다.
- 결재 올리기 · 발주 · 제출. 담당자가 한다.
- 대조에서 다른 값이 나왔을 때 어느 쪽이 맞는지 정하는 일. 알리고, 담당자가 해당 단계로 돌아가 고친다.
