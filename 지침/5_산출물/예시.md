# 5단계 산출물 — 예시

형식 확인용이다. **값은 넣지 않았다.** 5단계는 값을 만들지 않으므로, 실제 값은 1~4단계 결과에서 그대로 옮겨 온다. `⟨n단계: 항목⟩`은 "그 단계 결과의 해당 칸을 그대로 옮긴다"는 뜻이다.

## 예시 1. 봄 · 일본어 · 중구 · 1박2일 (기획서 v0.3 6-6 데모의 첫 조건)

```
## 만든 파일
| 파일 | 받는 쪽 | 형식 | 상태 |
| 결재 파일 | 기관 내부 | 기본 양식 문서 · 표 [팀 확정 전] | 완료 |
| 제안서 | ⟨3단계: 운영 주체 후보 중 담당자가 고른 곳⟩ | PDF [팀 확정 전] | 완료 |
| 홍보물 묶음 | — | 언어별 문구표 + 시안 이미지 [팀 확정 전] | 완료 |

## 결재 파일 — 근거 요약 (일부)
| 수치 | 값 | 출처 ID | 연도 | 표본 | 한계 | 경고 |
| ⟨2단계: 근거표 1행⟩ | ⟨그대로⟩ | ⟨그대로⟩ | ⟨그대로⟩ | ⟨그대로⟩ | ⟨그대로⟩ | E3 간접 근거 ⟨2단계 문구 그대로⟩ |

## 결재 파일 — 코스 (일부)
| 순서 | 시간 칸 | 장소 | 대체 이력 (E4) | 겹침 (E7) |
| ⟨3단계 그대로⟩ | ⟨그대로⟩ | ⟨그대로⟩ | ⟨원래 장소 → 대체 장소, 이유⟩ | ⟨겹친 상품 ID · 담당자 선택⟩ |

## 대조 결과
| 항목 | 결과 | 다른 곳 |
| 코스 | 같음 | — |
| 수치 | 같음 | — |
| 경고 | 다름 | 제안서 "왜 이 코스인가"에 E3 경고 없음 |
| 미확인 표시 | 같음 | — |
| 코스 변경 | 해당 없음 (E6 없음) | — |

## 대조 불일치 (E8 후보)
- [경고 누락] 결재 파일 근거 요약 1행에는 E3가 붙었는데, 같은 수치를 쓴 제안서 "왜 이 코스인가"에는 없습니다 → 고칠 단계: 5단계 (옮길 때 빠짐, 다시 만들기)

## 남은 경고 · 미확인 (세 파일 공통)
| 경고 | 단계 | 대상 | 담당자 선택 |
| E1 [기간 어긋남] | 1단계 | ⟨1단계 문구 그대로⟩ | 알림을 남기고 진행 |
| E3 [간접 근거] | 2단계 | ⟨근거표 1행⟩ | 경고를 남기고 진행 |
| [미확인] | 3단계 | ⟨운영 정보가 확인 안 된 장소⟩ | — |

## 담당자 선택
- 해당 단계로 돌아가 고치기 → 5단계 다시 만들기
```

## 예시 2. 앞 단계가 끝나지 않았을 때

```
## 만든 파일
없음

## 알림
- 4단계 홍보 검토가 확정되지 않았습니다 (번역 상태: 초안, 확정 전). 4단계를 확정한 뒤 다시 만드세요.
- 3단계 코스가 E6로 수정 중입니다. 수정 전 코스로는 만들지 않습니다.
```

## 예시 3. 담당자가 5단계에서 수치를 고치려 할 때

```
## 안내
- 수치는 2단계 근거표에서 고쳐 주세요. 5단계에서 고치면 세 파일과 근거표가 서로 달라집니다.
```
