# 1단계 기획 조건 — 출력

## 화면에 나오는 결과

역할표 1단계의 "조건 요약 + 조건별 참고 문구"다. 참고 문구는 수치가 아니라 **볼 수 있는 자료와 빈 곳**을 알려 주는 문장이다.

## 출력 형식

```
## 조건 요약
| 항목 | 선택 |
| 방문객 | 외국인 |
| 시기 | ... (해당 월) |
| 대상 언어권 | ... (해당 국가) |
| 지역 | ... (기본값이면 "기본값") |
| 체류 기간 | 당일 / 1박2일 / 추천받기 |

## 볼 수 있는 자료
| 조건 | 자료 | 지역 | 이 조건을 재는 방식 |
| ... | ... | 중구 / 동구 / 대구 전체 | 직접 / 직접, 단 구분 없음 / 일부만 (빠진 것) / 없음 |

## 알림 (E1)
- [자료 없음 / 구분 없음 / 따로만 나뉨 / 기간 어긋남] 문구  ← 없으면 "없음"
- 기관 데이터로 채우면 좋은 곳: ...

## 2단계로 넘기는 것
| 자료 | 파일 | 고른 행 | 재는 방식 |
- 공통 자료: (자료_고르기.md 3장 목록)
- 체류 기간 추천 요청: 있음 / 없음  ← 추천받기를 골랐을 때 "있음"
- E1 알림 여부: 있음 (n건) / 없음
- 담당자 선택: 조건 바꾸기 / 알림을 남기고 진행  ← 알림이 있을 때만
```

- "고른 행"은 2단계가 그대로 다시 고를 수 있게 열 이름과 값으로 적는다. 예: "`언어명`=일본어, `지역`=중구, 3 · 4 · 5월".

## 2단계가 받는 것

`2단계로 넘기는 것` 블록이 2단계 `입력.md`의 "1단계에서 받는 것"이다. 항목을 바꾸면 2단계 `입력.md`도 같이 고친다.
