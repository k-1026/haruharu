# 1단계 기획 조건 — 출력

## 화면에 나오는 결과

역할표 1단계의 "조건 요약 + 조건별 참고 문구"다. 참고 문구는 수치가 아니라 **볼 수 있는 자료와 빈 곳**을 알려 주는 문장이다.

## 출력 형식

```
## 조건 요약
| 항목 | 선택 |
| 시기 | ... (임시 기준 월) |
| 체류 기간 | ... |
| 대상 국가 | ... (언어권: ...) |

## 볼 수 있는 자료
| 조건 | 자료 | 이 조건을 재는 방식 |
| ... | ... | 직접 / 직접, 단 구분 없음 / 일부만 / 없음 |

## 알림 (E1)
- [자료 없음 / 구분 없음] 문구  ← 없으면 "없음"
- 기관 데이터로 채우면 좋은 곳: ...

## 2단계로 넘기는 것
| 자료 | 파일 | 고른 범위 | 재는 방식 |
- 공통 자료: (자료_고르기.md 3장 목록)
- E1 알림 여부: 있음 / 없음
- 담당자 선택: 조건 바꾸기 / 알림을 남기고 진행  ← 알림이 있을 때만
```

## 2단계가 받는 것

`2단계로 넘기는 것` 블록이 2단계 `입력.md`의 "1단계에서 받는 것"이다. 항목을 바꾸면 2단계 `입력.md`도 같이 고친다.
