# 1단계 기획 조건 — 자료 고르기

자료 목록은 `지침/공통/데이터_목록.md`를 기준으로 한다. 이 파일은 조건마다 그 목록에서 **어떤 자료의 어떤 행을 고르는지**만 정한다. 고를 때 자료 안의 수치는 읽지 않는다.

## 1. 조건별로 고르는 자료

| 조건 | 자료 (`research/data/`) | 고르는 범위 | 이 조건을 재는 방식 |
|---|---|---|---|
| 시기 | `datalab_jung_paid_attraction_foreign_monthly_2022_2026.csv` | `year_month`의 월이 고른 계절에 드는 행. `status`가 `값`이 아닌 행은 뺀다 | 일부만 (향촌문화관 1곳) |
| 체류 기간 | `kosis_foreign_stay_2024.csv` | `measure`가 `숙박 기간`인 행 (당일 → `무박`, 1박2일 → `1박`) | 직접, 단 계절 · 국가 구분 없음 |
| 대상 국가 | `datalab_jung_origin_country_2022_2026.csv` | `country`가 고른 국가인 행 전부 (연도별 행과 `2022-2025 합계` 행) | 직접 |
| 대상 국가 | `datalab_jung_interest_spots_2022_2025.csv` | `language_group`이 고른 국가의 언어권인 행 (2장) | 직접 (관심 집계) |

- "이 조건을 재는 방식"은 `직접` · `직접, 단 구분 없음` · `일부만` · `없음` 넷 중 하나로 쓴다. 자료의 설명 정보(무엇으로 나뉘어 있는지, 어떤 대상인지)만 보고 정한다.
- `체류 기간` 측정 행(1일 · 2일)은 같은 응답을 일 단위로 센 것이라 고르지 않는다.

## 2. 국가 → 언어권

| 국가 | 언어권 (`language_group`) |
|---|---|
| 대만 · 홍콩 | 중번체 (두 나라가 같은 목록을 쓴다는 점을 출력에 적는다) |
| 중국 | 중간체 |
| 일본 | 일본어 |
| 미국 | 영어권 |
| 베트남 · 기타 | 해당 언어권 자료 없음 → `알림.md`의 "자료 없음" |
