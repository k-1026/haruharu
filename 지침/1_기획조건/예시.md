# 1단계 기획 조건 — 예시

형식 확인용이다. 수치가 없는 것이 맞다.

## 예시 1. 가을 · 1박2일 · 대만

```
## 조건 요약
| 시기 | 가을 (임시 기준 9~11월) |
| 체류 기간 | 1박2일 |
| 대상 국가 | 대만 (언어권: 중번체, 홍콩과 같은 목록) |

## 볼 수 있는 자료
| 시기 | 중구 유료 관광지 외국인 월별 입장객 | 일부만 (향촌문화관 1곳) |
| 체류 기간 | KOSIS 2024 외국인 숙박 기간 | 직접, 단 계절 · 국가 구분 없음 |
| 대상 국가 | 중구 외국인 방문자 거주 국가 | 직접 |
| 대상 국가 | 중구 외국인 관심 관광지 (중번체) | 직접 (관심 집계) |

## 알림 (E1)
- [구분 없음] KOSIS 숙박 기간 자료는 계절 · 국가로 나뉘어 있지 않은 2024년 외국인 전체 자료입니다.
- 기관 데이터로 채우면 좋은 곳: 계절별 외국인 방문객 수, 국가별 숙박 기간

## 2단계로 넘기는 것
| 계절 입장객 | datalab_jung_paid_attraction_foreign_monthly_2022_2026.csv | 9~11월, status=값 | 일부만 |
| 숙박 기간 | kosis_foreign_stay_2024.csv | 숙박 기간 / 1박 | 직접, 단 구분 없음 |
| 거주 국가 | datalab_jung_origin_country_2022_2026.csv | country=대만 | 직접 |
| 관심 관광지 | datalab_jung_interest_spots_2022_2025.csv | language_group=중번체 | 직접 |
- 공통 자료: 방문 관광지 · 방문 목적 · 동반자 · 추천 음식 · 숙박 유형(1박2일)
- E1 알림 여부: 있음 (1건)
```

## 예시 2. 겨울 · 당일 · 베트남

```
## 조건 요약
| 시기 | 겨울 (임시 기준 같은 해 1 · 2 · 12월) |
| 체류 기간 | 당일 |
| 대상 국가 | 베트남 (언어권 자료 없음) |

## 볼 수 있는 자료
| 시기 | 중구 유료 관광지 외국인 월별 입장객 | 일부만 (향촌문화관 1곳) |
| 체류 기간 | KOSIS 2024 외국인 숙박 기간 | 직접, 단 계절 · 국가 구분 없음 |
| 대상 국가 | 중구 외국인 방문자 거주 국가 | 직접 |
| 대상 국가 | 중구 외국인 관심 관광지 | 없음 |

## 알림 (E1)
- [자료 없음] 베트남에 해당하는 언어권 관심 관광지 자료가 없습니다.
- [구분 없음] KOSIS 숙박 기간 자료는 계절 · 국가로 나뉘어 있지 않은 2024년 외국인 전체 자료입니다.
- 기관 데이터로 채우면 좋은 곳: 베트남 방문객 관심 장소, 계절별 당일 방문 비율
```
