# 1단계 기획 조건 — 예시

형식 확인용이다. 수치가 없는 것이 맞다.

## 예시 1. 여름 · 일본어 · 중구 · 추천받기

```
## 조건 요약
| 방문객 | 외국인 |
| 시기 | 여름 (6 · 7 · 8월) |
| 대상 언어권 | 일본어 (일본) |
| 지역 | 중구 |
| 체류 기간 | 추천받기 |

## 볼 수 있는 자료
| 시기 · 언어권 | 외국인 관심 관광지 (월별) | 중구 | 직접 (관심 집계) |
| 시기 | 유료 관광지 외국인 입장객 | 중구 | 일부만 (향촌문화관 1곳) |
| 언어권 | 중구 외국인 거주 국가 (일본) | 중구 | 직접 |
| 시기 | KOSIS 2024 외국인 자료 7종 (조사시기 6~8월) | 대구 전체 | 직접, 단 구 구분 없음 |
| 언어권 | KOSIS 2024 외국인 자료 7종 (거주국가 일본) | 대구 전체 | 일부만 (국가로 대신 잼) |
| 체류 기간 | KOSIS 2024 외국인 숙박 기간 (조사시기 네 기 + 당일여행 · 숙박여행) | 대구 전체 | 직접 |

## 알림 (E1)
- [구분 없음] KOSIS 2024 외국인 자료 7종은 구로 나뉘어 있지 않은 대구 전체 자료입니다.
- [따로만 나뉨] KOSIS 2024 외국인 자료는 조사시기별 · 거주국가별 값이 따로 있고, 두 조건을 함께 나눈 값은 없습니다.
- 기관 데이터로 채우면 좋은 곳: 중구 외국인 숙박 기간, 계절별 일본인 방문객 수

## 2단계로 넘기는 것
| 관심 관광지 | 외국인/관광데이터랩_…_월별통합_202201-202609.csv | 언어명=일본어, 지역=중구, 6 · 7 · 8월 | 직접 |
| 입장객 | datalab_jung_paid_attraction_foreign_monthly_2022_2026.csv | 6 · 7 · 8월, status=값 | 일부만 |
| 거주 국가 | datalab_jung_origin_country_2022_2026.csv | country=일본 | 직접 |
| 숙박 기간 | 외국인/대구_외국인숙박기간_2024.csv | 전체 · 조사시기 네 기 · 거주국가=일본 · 대구 체류 여부 둘 다 | 직접 / 일부만 |
| 좋았던 점 외 6종 | 외국인/대구_외국인…_2024.csv | 전체 · 조사시기=6~8월(2기) · 거주국가=일본 (+ 체류 여부 둘 다) | 직접 / 일부만 |
- 공통 자료: 방문 목적 · 동반자
- 체류 기간 추천 요청: 있음
- E1 알림 여부: 있음 (2건)
```

## 예시 2. 겨울 · 중국어 번체 · 동구 · 1박2일

```
## 조건 요약
| 방문객 | 외국인 |
| 시기 | 겨울 (같은 해 1 · 2 · 12월) |
| 대상 언어권 | 중국어 번체 (대만 · 홍콩) |
| 지역 | 동구 |
| 체류 기간 | 1박2일 |

## 볼 수 있는 자료
| 시기 · 언어권 | 외국인 관심 관광지 (월별) | 동구 | 직접 (관심 집계) |
| 시기 | 유료 관광지 외국인 입장객 | 동구 | 없음 |
| 언어권 | 외국인 거주 국가 | 동구 | 없음 |
| 시기 | KOSIS 2024 외국인 자료 7종 (조사시기 11~12월) | 대구 전체 | 일부만 (1 · 2월 없음, 11월 포함) |
| 언어권 | KOSIS 2024 외국인 자료 7종 (거주국가 대만) | 대구 전체 | 일부만 (홍콩 따로 없음) |
| 체류 기간 | KOSIS 2024 외국인 자료 (대구 체류 여부 숙박여행) | 대구 전체 | 직접 |

## 알림 (E1)
- [자료 없음] 동구에 해당하는 유료 관광지 입장객 · 외국인 거주 국가 자료가 없습니다.
- [기간 어긋남] KOSIS 2024 외국인 자료의 겨울은 11~12월입니다. 1 · 2월이 빠지고 11월이 들어갑니다.
- [구분 없음] KOSIS 2024 외국인 자료 7종은 구로 나뉘어 있지 않은 대구 전체 자료입니다.
- [따로만 나뉨] KOSIS 2024 외국인 자료는 조사시기별 · 거주국가별 값이 따로 있고, 두 조건을 함께 나눈 값은 없습니다.
- 기관 데이터로 채우면 좋은 곳: 동구 외국인 방문객 수, 겨울(1 · 2월) 외국인 숙박 기간
```

## 예시 3. 국가로 요청했을 때 — "베트남 관광객으로 봄 당일 코스"

```
## 조건 요약
| 대상 언어권 | 맞는 언어권 없음 (요청: 베트남) |

## 알림 (E1)
- [자료 없음] 베트남에 해당하는 언어권 관심 관광지 자료가 없습니다. 선택지는 영어권 · 일본어 · 중국어 간체 · 중국어 번체입니다.
- 기관 데이터로 채우면 좋은 곳: 베트남 방문객 관심 장소
- 담당자 선택: 조건 바꾸기 / 알림을 남기고 진행
```
