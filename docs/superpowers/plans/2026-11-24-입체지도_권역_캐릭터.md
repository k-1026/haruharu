# Three.js 입체 지도·자유식 권역

사용자 승인: Leaflet 대신 Three.js. 관광지·식사 권역을 따라 캐릭터가 이동하고 권역 클릭으로 후보 미리보기. 후보 선택·확정 저장 없음. 좌표 없는 일정 유지, 실제 AI 호출 없음.

- 기존 Leaflet 다운로드 파일은 보존하되 화면에 연결하지 않는다. Three.js 0.180.0 공식 모듈과 MIT 라이선스를 로컬에 둔다.
- 강사 예시의 OSM 지리 자료(map.json, 출처·ODbL 표시 포함)를 로컬에서 읽고 자체 화면 코드를 작성한다. 예시 앱 소스는 복사하지 않는다.
- 너구리·족제비의 간단한 입체 시연 모델을 기본 도형으로 구성한다. 최종 캐릭터 시트의 정식 모델·걷기 애니메이션과 구분한다.
- 지도는 OSM 도로·공원·물길과 지명을 보여 준다. 캐릭터의 장소 간 선은 코스 소개용이며 실제 도로 경로라고 주장하지 않는다.
- 자유식은 후보들의 위치 분포 또는 확인된 권역 대표점으로 표시한다. 후보는 클릭 때만 펼치며 후보 미리보기는 저장·방문 순서·확정 상태를 바꾸지 않는다.
- 좌표 없는 일정은 목록에 남긴다. 누락 구간을 실제로 걸은 것처럼 애니메이션하지 않고 건너뛰었음을 알린다. 숙소 미정·자유시간과 자료 부족을 구분한다.
- 공식 좌표 후보·주소 기반 누락 후보 수집은 AI 없이 별도 검토 파일로 저장한다. 검토자·근거·정밀도·장소 일치 검사를 통과하기 전 자동 반영하지 않는다.
- 모델·경로 상태를 순수 함수로 분리해 검증하고 정적 모듈·API 응답을 확인한 뒤 유휴 서버를 재시작한다. 화면 육안 검증은 사용자가 맡는다.

## 후속 구현

- 사용자가 지정한 예진 브랜치의 `캐릭터디자인_예시/캐릭터_걷기_모션` GIF 6개를 원본 그대로 연결했다. 확인한 폴더에는 GLB/GLTF/FBX 모델이 없어 실제 리깅 모델로 설명하지 않는다. 카메라·동선에 따른 정면/측면/후면 선택은 순수 함수로 검사한다.
- 지도 모듈을 404로 반환한 이전 서버를 종료하고 새 서버로 교체했다. Windows의 같은 포트 중복 바인딩도 차단한다.
- WebGL 생성 실패 시 같은 OSM 자료의 2D 도로 지도와 권역 후보를 제공한다. 일정 원본이나 식당 확정 상태는 바꾸지 않는다.
