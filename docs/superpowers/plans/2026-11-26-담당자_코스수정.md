# 담당자 코스 수정 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 특정 장소 예외처리 없이 생성된 코스의 개별 방문·하루·전체를 담당자 요청으로 수정하고 점심 후보를 연결한다.
**Architecture:** 기존 부분수정 API·버전 보존을 유지한다. 새 수정 범위를 칸ID와 일차로 검증한 뒤 AI 입력과 코드 조립에서 동일하게 사용한다. 변경 결과를 이전 코스와 비교하고 선택하지 않은 방문을 보존한다. 자료 보강은 출처와 미확인을 보존한다.
**Tech Stack:** Python 표준 라이브러리, 기존 AI 실행기, vanilla JS/CSS, unittest, node:test.
**Spec:** 현재 대화의 2026-11-26 사용자 구현 요청과 inventory/반영사항/유저플로우_미정항목_결정및반영시점_1122.md의 같은 날짜 후속 요구.

## Global Constraints

- 기존 사용자 변경·저장 코스·이전 버전 보존. 커밋·push·다른 브랜치 수정 없음.
- 시간·운영·이동정보를 지어내지 않는다. 부족하면 미확인과 사유를 보여준다.
- 계절·언어권·지역·체류기간은 이 수정에서 변경하지 않는다.
- 현재 개인 브랜치와 실행 중인 localhost를 대상으로 작업한다. 별도 작업트리·의존성 설치는 하지 않는다.
- 사용자가 앞선 개선 방향의 구현을 명시했으므로 재승인을 요구하지 않고 직접 실행한다.

## Review Focus

- 같은 시간칸을 가진 다른 날짜·장소는 개별 수정에 휘말리지 않는다.
- 오래된 화면에서 요청하면 최신 버전 덮어쓰기 대신 재조회 안내.
- 제외·추가·순서 변경과 식사 기록이 일치하며 유지 방문은 사라지지 않는다.
- 유지 방문이 후보표 밖이거나 정보가 불완전해도 조용히 유실하지 않는다.
- AI가 변경하지 않았거나 요청을 수행하지 못하면 성공으로 표시하지 않는다.
