# 도로 경로와 간결한 위치 정보

사용자 요청: 대표 위치 표시는 유지하면서 실제 길을 따르는 선과 캐릭터 이동을 적용한다. 위치 근거·입구 안내·외부 지도 링크는 접힌 상세로 옮긴다. 저장 코스·기존 변경 보존, 실제 AI·커밋 없음.

- FOSSGIS OSRM의 foot 서버에서 대표점 사이 도보 geometry를 한 번 수집한다. 출처 표시·정상 User-Agent·최대 초당 1회·기존 캐시 재사용을 지킨다. 서버 문서: https://routing.openstreetmap.de/about.html
- 좌표 순서는 OSRM의 lon,lat을 내부 lat,lon으로 변환한다. 응답 코드·geometry·유효 좌표·도로 보정 거리·양 끝 위치를 검증하고 로컬 road-routes.json에 저장한다. 실패를 직선으로 대체하지 않는다.
- 이것은 대표점 주변 도로 사이의 도보 미리보기다. 원래 일정의 교통수단·이동시간을 바꾸거나 입구·현재 현장 통행 가능 여부를 검증한 것으로 취급하지 않는다.
- 지도와 WebGL 대체 지도는 같은 경로를 그리며, 캐릭터는 선의 누적 거리를 따라 이동한다. 꺾이는 지점에서 다음 경로 방향을 본다. 화면 열기·후보 미리보기는 AI나 길찾기 외부 요청을 하지 않는다.
- 기본 시간표에는 짧은 대표 위치 표시만 남기고, 입구 안내·근거·지도 링크는 닫힌 '위치 정보'에 둔다.
- 수집·검증·구간 대응·꺾인 경로 보간을 시험하고 실제 현재 5구간과 정적 파일 응답을 확인한다. 육안 검증 미완료는 구분한다.
