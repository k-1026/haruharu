# 홍보물·QR 랜딩·최종 파일 정리 구현 계획

> 실행: superpowers:executing-plans. 사용자가 첨부 개선 검토 문서의 반영을 요청했다. 기존 미커밋 작업을 포함한 현재 작업 폴더에서 연속 수정하며 커밋·push는 하지 않는다.

목표: 실제 코스·에이전트 문구·QR 연결을 보존하면서 내부 검토와 공개 자료를 구분한다.

기준: `C:/Users/admin/Desktop/md파일/1125/홍보물 qr 최종 산출물 개선 검토.md`의 추천안. 추가 제안인 자유 문구 편집·별도 디자인 편집기는 이번에 새로 만들지 않는다. 기존 재생성 기능의 역할·설정 보존을 개선한다.

- [x] 이름 선택 입력 및 조건 기반 기본 제목, 재생성 설정 보존을 회귀시험 후 연결한다.
- [x] 공개 자료 변환을 한 곳에서 처리한다. 내부 JSON·경고·검토 상태는 보존하고 미확인 안내는 제외한다. 홍보물·랜딩·ZIP에 같은 변환을 적용하고 ZIP의 JSON에도 내부 내용을 넣지 않는다.
- [x] 제출 문서의 경고·필터·검토 로그를 제거하고 필요한 출처는 참고자료로 정리한다. 식비 항목은 제거하고 개별 결제 원칙을 적용한다.
- [x] 담당자에게 검토 사항·공개 제외 안내를 표시하고 최종 요약 확인을 연결한다. 표현 미처리는 최종 파일 생성 전에 처리하도록 한다. 공개 완료·원어민 검토 완료를 자동 기록하지 않는다.
- [x] 관련 Python·Node 시험, 실제 저장 결과를 사용한 HTTP·다운로드·화면 확인 후 기존 현황·반영 목록에 결과와 남은 일을 기록한다.

검증 초점: 기존 기록 무변경, 선택 코스/버전과 QR 일치, 공개 HTML/JSON/SVG에 내부 경고 미노출, 이름 공란, 재생성 설정 유지, 필터 미처리 차단, 식비 포함 표현 제거.

완료 검증: Python484개·Node100개 통과. IAB 실제 다운로드와 공개/담당자 화면 확인, SVG22개·QR32개 행렬 대조. 원본 코스·AI JSON 보존. 실제 파일 갱신으로 해당 홍보의 최종 파일/메타데이터만 갱신했다. 세부 결과·남은 범위는 app/작업현황.md 최신 절에 기록했다.
