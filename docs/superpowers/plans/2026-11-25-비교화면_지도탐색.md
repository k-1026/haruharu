# 비교 화면과 큰 지도 탐색 분리

사용자가 앞서 제시한 두 화면 구성을 승인했다. 실제 AI·커밋 없이 저장 코스로 구현한다.

- 기본 비교 화면: A/B 카드, 선택 안의 방문지 요약과 짧은 보완 설명, '지도 크게 보기'. 요청 반영·자율 이용·수정·팀 기록은 닫힌 상세로 제공한다. 없는 B는 생성된 것처럼 꾸미지 않는다.
- 지도 탐색: 화면을 가득 쓰는 별도 보기. 왼쪽은 간단한 순서/권장 시각 버튼, 가운데는 도로 지도·캐릭터, 오른쪽은 선택한 장소 설명/이용 참고/식당 후보. 작은 화면에서는 장소 설명을 아래 패널로 제공한다.
- 왼쪽·지도 핀 선택을 하나의 선택 상태로 연결한다. 좌표가 있는 장소는 카메라 이동, 없는 일정은 원위치 유지+미정 안내. 식당 후보 클릭은 읽기 전용 미리보기다.
- 대표 위치 안내는 지도 아래 공통으로 한 번만 표시한다. 장소별 배지·핀 이름의 반복 표시는 제거한다. 위치 근거와 입구 상세는 접힌 위치 정보에 유지한다.
- 설명은 기존 운영 자료/코스 이유 및 출처가 있는 장소 소개를 사용한다. 없는 사실·영업일 확정·AI 결과를 만들지 않는다.
- 돌아가기·Escape·키보드 선택·초점 복귀 및 지도 리소스 정리를 지원한다. 선택 시험·실제 API/파일 응답을 확인하고 유휴 서버를 재시작한다. 육안 검증 미완료는 구분한다.

## 실제 화면 점검 후 보완

- 사용자는 좌우 고정 열의 공간 낭비와 과도한 토글을 지적했다. 실제 브라우저에서 지도 로딩과 현재 배치를 확인했다. 지도 전체를 배경으로 쓰고 목록/장소 패널은 내용만큼의 부유 카드로 바꾼다. 장소를 선택해도 지도 크기는 줄이지 않는다.
- 비교 화면의 요청 반영·이용 방식은 읽을 수 있는 카드로 되돌리고 근거·수정 도구·팀 기록만 필요할 때 연다. 비교 카드·여백·색상과 지도 레이블의 대비를 정리한다.
