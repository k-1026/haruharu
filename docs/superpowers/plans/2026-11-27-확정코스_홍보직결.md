# 확정 코스의 홍보 직결 구현 계획

> 실행: superpowers:executing-plans. 사용자 요청: 홍보 단계의 시작·종료/둘째 날 오전/기존 상품 겹침 재입력 제거, 화면·서버 동시 수정, 기존 변경 보존, 업로드·중간 수정 포함 시연 흐름 확인.

목표: 코스 확정은 안·최신 버전 선택으로 한 번만 수행하고 홍보는 저장된 코스를 그대로 사용한다.

- [x] 회귀시험: 중복 입력 없이 생성, 저장 코스/미정/확정조건/기존 결정의 완전 보존, 클라이언트의 옛 일정값 무시, 미확정·구버전·다른 안 차단.
- [x] 서버: 선택·확정된 최신 버전 확인 후 코스 사본 그대로 저장/전달. 시작·종료·오전·겹침 값을 자동 확정하거나 사람 결정으로 추가하지 않는다. 홍보 설정만 검증한다.
- [x] 화면: 확정 코스 요약 읽기 전용 + 톤/홍보물 선택 + 언어 안내. 기존 확정이면 확정 창도 반복하지 않는다. 수정으로 새 버전이 생기면 최신 버전을 다시 확인·확정한다.
- [x] 시연: 자료 업로드 → 실제 에이전트 생성 → 코스 비교/지도 → 한 일정 체류시간 수정·재검증 → 최신 버전 확정 → 홍보 생성 → QR/최종 파일 순서. 코드 도구와 실제 AI 호출을 구분한다.
- [x] 관련/전체 시험·화면/서버 연결 확인, 작업현황·반영 목록 기록. 기존 실행 자료 및 사용자 파일은 보존, 커밋·push 없음.

검증 완료: Python496개·Node101개, 코드 검토 중요 지적 없음. 실제 화면 업로드·중간 수정·홍보·ZIP·최종3파일 확인. A3 전체 사본/이전4버전·다른7방문/운영67파일 보존 확인. 실제 운영·원어민 승인과 구분하며 자세한 순서·한계는 app/작업현황.md 최신 절에 기록했다.
