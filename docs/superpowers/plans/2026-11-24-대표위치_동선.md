# 대표 위치를 이용한 현재 코스 지도 보완

사용자 승인 범위: 현재 코스 장소·권역의 대표 좌표를 연결하고 입구와 구분한다. 기존 변경·저장 코스·식당 선택은 보존하며 AI·커밋은 하지 않는다.

1. 공식 페이지에 이름과 연결된 좌표를 확인하고 별도 대표 위치 JSON에 주소·유형·근거·검토자를 기록한다. 확인되지 않은 기존 CSV 좌표를 일괄 승인하지 않는다.
2. 이름의 행정구역·괄호 설명·알려진 권역 후보 접두어를 정리해 등록된 별칭만 찾는다. 숙소는 문장에 명시된 권역만 사용하고 중구/동구 전체를 임의의 호텔로 바꾸지 않는다.
3. 요약 API와 지도/시간표에서 대표 위치·권역·입구 미확인을 표시한다. 시장과 야시장은 같은 권역 대표점을 공유하되 같은 입구라고 설명하지 않는다.
4. 순서·일차 경계를 유지한 연결선과 캐릭터에 대표 좌표를 전달한다. 미정 장소를 날조하거나 기존 이동시간을 다시 계산하지 않는다. GPU 대체 지도에도 동선을 표시한다.
5. 회귀 시험 및 실제 저장 코스의 표시점/연결 구간 수를 대조한 뒤 유휴 서버를 재시작한다. 육안 검증과 자동 검사 범위는 구분한다.
