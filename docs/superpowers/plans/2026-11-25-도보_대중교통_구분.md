# 도보·대중교통 지도 표시

- 사용자 요청: 도보/대중교통과 이동시간 구분, 대중교통 구간의 걷기 금지, 발자국/방향 꺾쇠 제거, 도로와 구분되는 동선. 기존 변경 보존·실제 AI 실행/커밋 금지.
- 자료: 기존 이동 CSV의 방향이 같은 정확한 장소 쌍만 조회한다. 등록된 권역 접두어/괄호/주석만 정리하고 시장/야시장·호텔/역을 임의로 합치지 않는다. 출처·기준요일/시각·확인일을 전달한다.
- 표시 가정: 기존 지침의 도보 20분 기준을 사용한다. 자료에서 도보 20분 이하면 도보 표시, 초과하고 대중교통 시간이 있으면 대중교통 표시. 저장 코스·교통수단 확정 상태는 바꾸지 않는다. 미보유 대중교통 값을 만들어내지 않는다.
- 도보는 실제 도보 캐시의 청록색 선/크림 테두리와 캐릭터를 사용한다. 대중교통 geometry는 없으므로 도보 선을 버스 노선으로 표시하거나 가짜 직선 경로를 만들지 않는다. 대중교통은 보라색 시간/노선 정보와 '도착지로 넘어가기'로 안내한다. 캐릭터는 숨기고 자동으로 걷지 않는다.
- 전체 재생은 대중교통 안내에서 기다렸다가 명시적 다음 장소 버튼으로 이어 간다. 교통 구간의 가짜 진행률·실제 차량 이동은 보여 주지 않는다. 시간은 보유 자료 기준이며 예약/실시간 검증이 아니다.
- 범위: 장소정보.py→담당자요약.py→map-model.js→plan.js/three-map.js/CSS. Python의 정확한 구간/누락 시험, Node의 수단 선택·대중교통 대기/걷기 금지·재개 시험, 실제 UI와 관련 회귀 검사 후 상태 기록.


## 도보·대중교통 구분 (2026-11-25)

- 사용자 요청으로 도보는 청록 실선·크림 테두리, 대중교통은 보라색 시간·노선 안내로 구분했다. 방향 꺾쇠·발자국은 표시하지 않는다. 원본 코스·좌표·식당 미확정 상태·기존 변경은 보존했다.
- 기존 CSV에서 같은 방향의 정확한 장소 쌍만 연결하고 출처·기준요일/시각·확인일을 전달한다. 역방향이나 숙소 권역과 역을 임의로 합치지 않는다. 기존 도보 20분 가정 기준은 지도 표시 용도이며 교통수단 확정이나 팀 합의가 아니다.
- 도보는 실제 도보 캐시를 따라 재생한다. 대중교통에는 실제 노선 경로 좌표가 없으므로 가짜 선·걷기·진행률을 만들지 않는다. 전체 재생은 교통 안내에서 기다리고 ‘도착지로 넘어가기’를 누르면 이어 간다. 시간·버스 번호는 보유 자료 기준이며 실시간 운행 정보가 아니다.
- Chrome에서 현재 저장 A안의 도보 2구간·대중교통 3구간, 청록 경로·시간, 교통 구간의 캐릭터 숨김·도착지 전환·오른쪽 설명, 도보 재생 복귀를 확인했다. 전체 재생의 교통 대기/재개는 Node 상태 전이 시험으로 확인했다. SVG 대체 모드 육안 점검은 남아 있다.
- 관련 Python 27개·Node 69개 통과. 유휴 상태와 명령 확인 후 해당 8790 서버만 재시작하고 실제 코스 응답의 이동 메타데이터를 확인했다. 실제 AI 실행·커밋·push 없음. 남은 범위는 실제 대중교통 경로 연결과 최신 운행 정보 확인이다.


### 경로가 지면에서 떠 보이는 문제 보완 (2026-11-25)

- 사용자 후속 요청으로 Three.js의 도로·경로 높이를 확인했다. 기존 바닥 윗면은 -1, 도로는 0.2~0.71, 경로는 1.2~1.22인 장면 좌표라 가까운 시점에서 서로 분리돼 보일 수 있었다. 이 수치는 실제 미터가 아니라 축척된 장면 단위다.
- 바닥 윗면을 0, 면적 영역을 0.01, 도로·경로를 공통 0.02에 배치했다. 경로/테두리/도로의 겹침은 기존 renderOrder와 depthWrite:false로 구분한다. 실제 경로 좌표·캐릭터 경로·수단 구분은 보존했다.
- 저장된 강사님 참고 app.js는 주석과 QuadraticBezierCurve3 생성 코드상 실제 길찾기가 아닌 장소 사이의 순서 곡선이다. 표현 원리를 참고하되 예제 코드·자산을 복사하거나 실제 도보 경로를 곡선으로 대체하지 않았다.
- Node 69개·지도 JS 구문·diff 공백 검사 통과. 최신 수정의 실제 화면 재확인은 Chrome 점검 창이 최소화돼 도구가 복원하지 못한 상태로 남는다. 코드 검증과 육안 확인을 구분한다. 실제 AI 실행·커밋·push 없음.


### 잔꺾임을 줄인 표시 동선 (2026-11-25)

- 사용자 승인에 따라 map-model.js에서 도보 경로의 표시용 좌표만 최대 12m 편차로 단순화한다. 출발·도착점과 편차가 큰 회전·우회는 유지하며 작은 인도/횡단 꺾임을 줄인다. 도로 의미를 판독해 모든 횡단보도를 지우는 기능은 아니다.
- Three.js와 SVG의 선·진행 표시·캐릭터는 routesFor의 같은 정리 좌표를 사용한다. 원본 road-routes.json·이동시간·원본 거리·대중교통 구분·좌표 없는 일정은 보존한다. 표시 경로는 실제 보행 안내와 다를 수 있다는 공통 안내를 추가했다.
- 기존 도보 캐시 5구간의 표시점은 각각 16→6, 94→24, 123→30, 116→23, 34→14로 줄었다. 경로 자료와 시간은 다시 수집하거나 생성하지 않았다.
- 작은 꺾임 제거·큰 회전/순환·끝점 보존·원본 비변경·시간/거리 보존·재생 경로 연결 시험을 추가했다. Node 전체 71개·JS 구문·공백 검사를 확인한다. 이번 변경의 육안 재확인은 하지 않았으며 이전 최소화 창 제한과 구분해 기록한다. 실제 AI 실행·커밋·push 없음.


### 커밋 전 최종 지도 상태와 협업 범위 (2026-11-25)

- 후속 요청으로 단순화 허용 폭을 12m에서 2m로 줄였다. 이전 12m/표시점 수 기록은 중간 상태다. 도로 굽이를 살리고 거의 일직선인 잔점만 정리한다. 현재 표시점 수는 16→11, 94→43, 123→66, 116→51, 34→20이다.
- 바닥 벡터에 생략된 보행 연결은 보유 OSRM 도보 좌표를 바닥 보행길로도 표시해 보완했다. 새 현장 측량·통행 가능 검증·실시간 길찾기·새 도로 수집은 아니다. 바닥 보완·선·캐릭터가 같은 정리 좌표를 공유하고 시간/원본 거리는 유지한다.
- 원본 정면 모션은 두 캐릭터의 사선 시선이 반대여서 족제비 표시만 좌우 반전했다. 원본 GIF/APNG는 변경하지 않았다. 완전 정면 모션을 새로 생성한 것은 아니다. Chrome에서 같은 방향 시선을 확인했고, 마지막 바닥 보행길 보완 후 재확인은 사용자의 Esc 중단으로 마치지 못했다. SVG 육안 점검도 남아 있다.
- 커밋 전 Node 전체 74개와 관련 Python 27개, JS 구문/공백 검사 통과. Python 전체 discover는 15개 진행 후 추가 출력 없이 정체되어 중단했다. 전체 Python 통과로 기록하지 않으며, 이번 범위 밖 원인 진단은 남긴다. 실제 AI 호출은 수행하지 않았다.
- 이번 사용자 요청으로 개인 브랜치의 관련 커밋·push가 허용됐다. 무관한 원본 조사자료 3개와 .claude/launch.json은 제외한다. 예진 브랜치·통합 브랜치는 이력만 fetch했고 merge/PR/상대 브랜치 수정은 하지 않는다. 협업 순서와 남은 연결은 docs/협업_인계_20261125.md 참고.
