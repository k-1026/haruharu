## 실제 시험에서 고친 전달·표시 문제

- `처리기.검증입력`: 기존에는 설문 근거의 ID·빈 등급만 전달했다. 사용한 근거의 원자료 문항·수치·출처·파일/행·표본·한계·경고를 전달하도록 보완했다. 명시되지 않은 등급을 만들어 넣지 않는다.
- 장소 CSV의 정확한 운영 출처ID·URL·등급·확인일·운영시간·휴무를 방문별로 전달한다. 새 점심의 S123(한국관광공사 공식 상세)이 재검증 입력에 연결됨을 확인했다. 담당자 승인·실제 방문일 영업 확인으로 바꾸지 않는다.
- 검증 입력의 코드검사는 같은 안의 최신 버전 결과만 전달한다. 이전 버전 검사 혼입을 막았다.
- `검사분류.최신분류`: 같은 버전을 재검증한 경우 최근 완료된 검증 묶음만 현재 문제로 표시한다. 첫 검증의 경고·반려 결과는 이력에서 삭제하지 않는다.
- 위 4건을 실패 시험으로 재현 후 수정했고 관련 Python **188개** 통과. 출처 전달 변경은 별도 읽기 전용 코드 검토에서도 중요 문제 없음으로 확인했다. 다른 화면/전체 저장소 모든 시험 통과를 주장하지 않는다.

## 남은 지적과 범위

재검증은 다음 기존 근거 표시 3건을 지적했다. 검증 AI의 지적이며 사람이 원표와 대조해 최종 판단한 결과가 아니다. 원래 나머지 방문을 유지하는 요청을 넘어 기존 근거를 임의 삭제·재해석하거나 통과로 강제하지 않았다.

1. 첫날 서문시장 점심에 붙은 R113: 원문 관광지 명칭 `서문시장(야시장)`을 낮 점심의 수요 수치로 해석하는 범위 문제.
2. 근대골목의 R114: `동성로/중구 시내 일원` 방문율을 개별 장소 수치처럼 표기하는 문제.
3. 향촌문화관·국채보상운동기념관의 R53: 일반 문화유산 응답을 개별 장소 수치처럼 읽히게 하는 문제. 일반 기획 배경과 장소별 측정치를 구분할 필요가 있다.

국일따로국밥의 공식 운영 출처 누락은 재검증에서 다시 지적되지 않았다. 그러나 새 식당 앞뒤 두 방향 이동시간·좌표와 실제 방문일 영업은 여전히 미확인이다. 모든 검증이 통과했다거나 이동 가능한 확정 상품이라는 결론으로 바꾸지 않는다.
