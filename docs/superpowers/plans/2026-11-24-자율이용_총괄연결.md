# 자율 이용 코스와 처음부터 관리하는 총괄

사용자 요청: 기존 변경 보존, 실제 AI 재실행 없음. 당일·1박2일 선택 유지. 권장 일정과 자유 이용 구간을 갖는 판매 상품 기획을 지원하되 미정인 사용처·혜택·예약·이용 시간은 만들지 않는다.

방향: 코드가 자료를 고르고 총괄 실행기가 자료 확인부터 요약·코스·검증까지 상태와 실패를 관리한다. 정해진 순서는 AI에게 묻지 않는다. 초안 작성 한 번에 A/B를 요청하고 각 안의 차이와 이유를 저장한다. 생성되지 않은 B안은 없다고 알린다. 지역·언어권·기간 등 필수 조건을 자동 변경하지 않는다.

- [x] 전체 단계 상태·실패·결정 이력을 관리하는 총괄을 연결한다.
- [x] 자율 이용 기획에서 집결·해산·식사·숙소 확정을 요구하지 않고 실제 충돌·잘못된 형식은 검사한다. 예약 등 고정 시간이 입력된 경우 유지한다.
- [x] 한 번의 코스 응답에서 A/B안 등록과 독립 검사. B안 누락·동일안·조건 위반 시험.
- [x] 관리자 기본 경로는 읽기 전용 로그로 제공한다. 기존 개발·수정 도구 파일과 API는 보존하지만 기획자에게 연결하지 않는다.
- [x] 기획자 화면에서 선택·자유 구간·미정 운영 조건을 설명한다. 기존 기록의 운영 입력을 삭제하거나 자동 확정하지 않는다.
- [x] 관련 지침과 반영 목록을 갱신하고 외부 AI를 막은 모의 시험으로 확인한다.

기존 판매 확정·홍보·산출물 규칙과 새 자율 이용 초안을 구분한다. 이번 구현은 실제 업체 계약·사용권·판매 확정·팀 합의를 대신하지 않는다. 커밋·push·원본 기록 변경은 하지 않는다.

확인: 선택 Python 143개·Node 화면 42개 통과. 실제 AI·B안 품질·전체 2분 완료는 미확인. 로컬 서버의 기획 화면·읽기 전용 로그 경로 HTTP 200 확인. 이번 변경의 새 화면은 브라우저 접근 불가로 육안 확인하지 못했다. 전체 시험에는 기존 asyncio 환경 제한과 누락된 기존 결과 fixture 문제가 남아 있다.
