# 담당자 화면 1단계 (화면 분리 + 지도) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/plan/` 담당자 화면에서 저장된 코스를 지도 · 시간표로 보고, `/admin/`은 팀용 관리자 창으로 구분한다.

**Architecture:** 기존 `app/관리자조회.py` HTTP 서버에 담당자용 읽기 API(`/api/plan/course`)와 정적 화면(`app/담당자화면/`)을 더한다. 요약 계산은 새 모듈 `app/담당자요약.py`가 맡고, 좌표는 장소 CSV의 새 `위도` · `경도` 열에서 `app/장소정보.py`가 읽는다. 화면은 시안(`app/시안/담당자화면_시안.html`) 디자인을 따르되 A/B안 · 다시 만들기 · 새 코스 실행은 이후 단계라 자리만 둔다.

**Tech Stack:** Python 3 표준 라이브러리(http.server, csv, unittest), 순수 JS, Leaflet 1.9.4(cdnjs) + OpenStreetMap 타일.

**Spec:** `docs/superpowers/specs/2026-11-23-담당자화면-design.md`

## Global Constraints
- 고객은 대구시 관광 담당자. 담당자 화면에 검사 코드 · 원문 · 경고ID를 보이지 않는다.
- 확인되지 않은 좌표를 확정값처럼 쓰지 않는다: 좌표 빈칸 → 지도에서 빼고 "좌표 미확인" 표시. 좌표를 추정해 채우지 않는다.
- 지도 선은 직선이며 실제 경로가 아님을 화면에 표시.
- 장소 CSV 헤더 기존 열은 바꾸지 않고 끝에 `위도`,`경도` 두 열만 추가. UTF-8 BOM 유지. data_spec.md 11-1 표에 두 열 기록.
- AI 호출 · 저장 기록 수정 없음(읽기 전용).
- 커밋 메시지 `종류: 내용` + `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus
- 저장본에 3단계 결과가 없는 실행(1·2단계만) → `/api/plan/course`가 400이 아니라 `{'일정':[]...}`와 "코스 없음" 안내. (Task 2 테스트)
- 장소명이 `대구광역시 중구 김광석길`, `자유식 · ... 권역`처럼 접두어가 붙음 → 기존 `_이름` 규칙으로 CSV와 매칭. (Task 1 테스트)
- 자유식 추천 후보가 여러 곳 → 첫 후보가 아니라 칸 이름으로 한 점만, 좌표는 미확인 처리. (Task 2 테스트)
- 숙박 · 2일차 자유시간처럼 시각이 미정인 칸 → 시간표에 "시각 미정"으로 남기고 순서는 칸목록 순. (Task 2 테스트)
- 잘못된 id(`../`) → 기존 저장소 경로 검사로 400. (Task 3 테스트)

### Task 2: 담당자용 코스 요약

**Files:**
- Create: `app/담당자요약.py`
- Test: `app/test_담당자요약.py`

**Interfaces:**
- Consumes: `장소정보.좌표`, `운영검토.출발가능요일`
- Produces: `코스요약(코스: dict, 조건: dict) -> dict` 반환 키:
  `{'조건': {...코스작성조건}, '일정': [{'순번':int,'일차':int|'미정','시각':'HH:MM'|'','시간칸':str,'장소명':str,'표시명':str,'좌표':[위도,경도]|None,'네이버':str}], '출발가능요일': list[str]|None, '확인할것': list[str], '코스있음': bool}`
  - `표시명`: 자유식이면 `"자유식 · <권역>"`, 그 외 장소명에서 `대구광역시 ` 접두어 제거.
  - `네이버`: `https://map.naver.com/p/search/` + URL 인코딩된 `"대구 " + 표시명`.
  - `확인할것`: 시각 미정 칸 ("숙박 시간 미정" 등), 좌표 미확인 장소 ("좌표 미확인: <표시명>"). 검사 코드 · 경고ID 넣지 않음.
- `요약_불러오기(실행서비스, 시험id: str) -> dict` — `3단계_결과.md`(JSON) + `3단계_입력.json`의 `코스작성조건`을 읽어 `코스요약` 호출. 결과 파일 없으면 `{'코스있음': False, '일정': [], ...}`.

- [ ] Step 1: 테스트 4개 — 기본 칸 3개(낮 · 점심 자유식 후보 2곳 · 숙박 시각 미정) 코스로: 순번 1..3, 자유식은 한 점이며 좌표 None, 숙박 `시각==''`이고 확인할것에 "숙박" 포함; 결과 파일 없는 시험 폴더 → `코스있음` False.
- [ ] Step 2: 실행 → FAIL
- [ ] Step 3: 구현 (칸목록 순서 유지, 일차·시각 오름차순 정렬하지 않음)
- [ ] Step 4: 전체 테스트 PASS
- [ ] Step 5: 커밋 `feat: 담당자 화면용 코스 요약 추가`
