# 도로 지도와 자유식 권역 표시

후속 사용자 요청으로 Three.js 입체 지도 방식으로 대체한다. 현재 계획은 승인 이력이며 실제 구현 기준은 `2026-11-24-입체지도_권역_캐릭터.md`다. Leaflet은 내려받았지만 화면에 연결하지 않았다.

사용자가 승인한 방향: 실제 도로·지명 바탕 지도, 식사 권역을 누르면 후보 표시, 좌표 없는 일정은 목록에 유지. 기존 변경·기록 보존, 실제 AI 호출 없음.

- Leaflet 1.9.4 배포 파일과 라이선스를 로컬 자산으로 제공한다. OpenStreetMap 표준 타일을 현재 화면 범위에서만 불러오고 저작권을 표시한다. 외부 스크립트 허용이나 타일 일괄 다운로드는 하지 않는다.
- 기존 SVG 동선 그림을 기본 지도에서 제거한다. 실제 보행 경로를 검증하지 않은 직선을 도로 경로처럼 표시하지 않는다.
- 식사는 공식 권역 대표점 또는 후보 분포를 기반으로 한 참고 권역으로 표시한다. 출입구·방문 확정·행정 경계로 단정하지 않는다. 권역을 누르면 해당 후보 목록과 위치만 펼친다.
- 위치가 없는 일정과 식사 권역도 시간표에 남긴다. 지도 누락 항목과 이유를 짧게 안내한다. 미정 숙소·자유시간은 선택 범위를 설명한다.
- 타일/라이브러리 실패 안내와 지도 링크·일정 목록을 남긴다. CSP는 로컬 스크립트를 유지하고 지도 타일 이미지의 정확한 호스트만 추가한다.
- 모의 지도 API로 권역 선택 전후·후보 접기·좌표 없는 일정·XSS 처리·안별 지도 정리를 시험한다. Python 회귀시험과 실제 HTTP 자산 응답 확인 후 유휴 서버만 재시작한다. 화면 육안 확인은 사용자에게 남긴다.
