# 입장·지난 코스·이동시간·카메라 보완

사용자가 강사 공개 저장소 참고와 첫 화면, 부유형 지난 코스, 일관된 메뉴, 큰 글씨, 경로 시간, 전체/구간 재생 및 가까운 정면 추적을 요청했다. 기존 코스·선택·자료·사용자 변경을 보존하고 실제 AI·커밋은 하지 않는다.

- 참고: maclovedany/daegu-tour-planner의 start.js(진입과 저장 기획), app.js(추적/낮은 카메라/구간 진행), index.html. 공개 첫 화면도 실제 브라우저로 확인했다. 앱 소스나 일러스트는 복제하지 않고 현재 구조에 맞춰 작성한다.
- 기본 진입은 입장 화면으로 한다. 새 조건 입력과 지난 코스 열기는 각각 명확한 버튼을 제공하며 열람은 AI를 시작하지 않는다. 지난 코스는 상시 고정 레일 대신 별도 부유 카드다. 코스 기획/운영 로그 메뉴를 같은 모양으로 맞춘다.
- 시간은 캐시된 도보 길찾기의 duration을 보완해 지도/구간에 '도보 약 N분'으로 표시한다. 원래 일정의 교통수단·시간은 바꾸지 않는다. 값이 없으면 추정하지 않는다.
- 전체 동선 재생/일시 정지와 각 구간 재생을 나눈다. 누락·날짜 경계는 직선으로 걸어간 척하지 않고 멈춰 안내한다. 순차 재생 상태는 순수 함수로 시험한다.
- 전체 보기/따라보기/정면 가까이 보기 카메라를 제공한다. 정면은 캐릭터 진행 방향 앞에서 카메라가 추적하며 정면 이미지를 크게 보여 준다. 실제 3D 리깅 모델로 설명하지 않는다.
- 지도와 목록 글씨를 키우고 카드 폭/접힘을 필요한 수준으로 조정한다. 읽기 전용 조회와 재생은 AI/코스 저장을 호출하지 않는다. 선택 시험과 실제 브라우저 동작을 확인한다.
