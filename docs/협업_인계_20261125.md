push는 내 브랜치를 GitHub에 올리는 작업이다. 다른 사람 브랜치나 통합 브랜치에 자동 반영되지 않는다. 현재 우리 브랜치의 기존 미전송 화면 커밋 17개와 이번 관련 커밋을 push 대상으로 확인했다. PR 생성·merge는 이번 범위에 포함하지 않는다.

## 합치는 순서

1. 우리는 현재 앱 변경을 커밋하고 자기 브랜치로 push한다.
2. 예진은 캐릭터·홍보물 변경을 자기 브랜치에서 커밋하고 push한다.
3. 통합 담당자가 양쪽 브랜치에서 integration/stage-1-5로 들어갈 변경을 비교하고 PR 또는 통합 작업으로 합친다. 서로의 폴더를 통째로 복사하거나 다른 쪽 버전으로 모두 덮어쓰지 않는다.
4. 통합 후 캐릭터 원본과 실제 앱 표시 자산을 연결하고, 지도와 홍보물에 모두 맞는지 확인한다. main 반영은 팀 검토 후 별도다.

확인한 예진 브랜치의 공통 조상 이후 변경에는 app/ 수정이 없었다. 캐릭터디자인_예시/와 지침/4_홍보검토/는 변경되어 있다. 이는 이 시점의 비교이며 예진의 추가 push 후 다시 확인해야 한다.

## 예진과 확인할 것

- 원본/기준: 캐릭터디자인_예시/README.md, 지침/4_홍보검토/7_시안_캐릭터.md.
- 실제 앱: app/담당자화면/characters/ 원본 GIF와 transparent/ 파생 APNG, app/단계4_홍보검토/캐릭터투명화.cs, app/시험/test_캐릭터자산.py.
- 원본을 합쳐도 앱 GIF/APNG가 자동 교체되지 않는다. 새 원본에 맞춰 파생 자산·manifest를 다시 만들고 기존 변환/해시/프레임 시험을 확인해야 한다.
- 새 정면 모션이 완전 정면이거나 시선 방향이 바뀌면 map-model.js의 characterMotion 족제비 좌우 반전 규칙을 재검토한다.
- 최신 예진 지침은 크로스백 상시, 랜턴은 저녁·밤 장면에만 사용하는 규칙이다. 현재 지도 모션은 랜턴 포함 클립이므로 낮/밤 모션 선택 연결은 별도 확인·구현이 남는다. 이번 커밋에서 지침 반영 완료로 주장하지 않는다.
- 4단계 지침 반영 후에는 app/단계4_홍보검토/홍보실행.py·홍보검사.py와 전달 필드를 함께 대조한다. 새 필드·포즈 허용값 변경은 검사와 산출물까지 맞춰야 한다. 실제 AI 실행은 별도 사용자 승인 전까지 하지 않는다.

## 이번 검증과 남은 것

- Node 74개·관련 Python 27개 통과, 지도 JS 구문·diff 공백 검사 통과.
- Python 전체 discover는 15개 진행 후 출력 없이 정체되어 중단했다. 전체 회귀 통과가 아니다.
- 정면 시선은 Chrome에서 확인했다. 마지막 바닥 보행길 보완 화면은 사용자 Esc 중단으로 재확인하지 못했다. SVG 대체 모드 육안 점검도 남는다.
- 실제 대중교통 노선 geometry는 미연결이다. 보유 자료의 시간·버스 번호만 표시하고 걷기 없이 명시적 도착지 전환을 사용한다.
- 실제 AI 성공·A/B 생성 품질·전체 소요시간은 이번 작업에서 재검증하지 않았다.
