# haruharu — 대구 체류 기획 에이전트

대구 관광 담당자(구·군청 관광 부서, 대구시, 관광재단 등)가 체류형 관광 상품을 기획할 때 단계마다 옆에서 돕는 AI 에이전트입니다. 관광객에게 맛집을 추천하는 챗봇이 아닙니다.

## 단계

| 단계 | 담당자가 하는 일 | 에이전트가 하는 일 |
|---|---|---|
| 1 기획 조건 | 계절 · 체류 기간 · 대상 국가를 고른다 | 이 조건으로 볼 수 있는 자료가 있는지 확인하고 알린다 |
| 2 수요 근거 | 기관 데이터를 올리거나 "없음"에 체크한다 | 근거표를 만들고, 근거가 약하면 경고를 단다 |
| 3 코스 검토 | 코스를 고치거나 확정한다 | 낮 · 저녁 · 숙박 코스, 휴무 · 이동 시간 충돌과 대체안 |
| 4 홍보 검토 | 문구 톤 · 번역 · 시안을 고른다 | 장면별 문구 · 번역 초안, 근거 없는 표현 걸러 내기 |

## main에 두는 것

main에는 서비스가 돌아가는 데 필요한 파일만 둡니다.

| 위치 | 내용 | 상태 |
|---|---|---|
| `CLAUDE.md` | 팀 · 에이전트 공통 규칙 | 있음 |
| `research/data/` | 에이전트가 읽는 데이터 표(정리본 CSV)와 `data_spec.md` | 있음 (신민지 브랜치의 최신 정리본으로 교체 예정) |
| `.claude/agents/`, `지침/` | 단계별 에이전트와 지침 | 신민지 · 이예진 브랜치에서 작성 중, PR로 합침 |

리서치 노트 · 원본 자료 · 밸류체인 · 페르소나 · 발표 자료 같은 기획 문서는 각 팀원 브랜치(신민지, 이예진, 밸류체인 등)에 있습니다.
