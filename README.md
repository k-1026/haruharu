# haruharu — 치킨의 수도, 하룻밤 머무는 도시로

대구의 관광지와 치킨·닭요리를 하나의 동선으로 잇는 **체류형 미식관광 상품**을, AI 에이전트가 관광객 유형별로 반복 기획하고 검증하는 프로젝트입니다.

- 트랙: AX 크리에이티브 (콘텐츠 & 뷰티) · 지역: 대구광역시
- 에이전트 사용자: 대구시 관광 담당자 · 대구관광재단 · 여행사 (관광객용 맛집 추천 챗봇이 아님)

> 팀 규칙 전체(파일명·출처 등급·교차검증·Git 규칙)는 [`CLAUDE.md`](CLAUDE.md)에 있습니다. 이 README는 처음 들어온 사람을 위한 안내판입니다.

## 프로젝트 요약

- **팀 자산 Top3:**
  1. 평화시장 닭똥집골목 (대구 동구, 지역 고유의 닭요리 문화와 K-치킨벨트 관광자원)
  2. 대구 치맥페스티벌 (대구 대표 음식문화 축제, 치킨 관광 인지도)
  3. 중구·동구 관광자원 (근대골목, 서문시장, 동성로, 동촌유원지 등 낮 관광과 저녁 상권 연계)
- **핵심 메시지:** "낮은 대구 여행, 저녁은 치킨이 붙잡는다."
- **페르소나 — 근거리 관광객 (초안, 담당 범위):** 대구 인근 영남권에 거주하는 20~30대 커플·친구. 주말에 자가용이나 대중교통으로 대구를 당일 방문하며, 맛집·사진·지역 관광에 관심이 있다. 낮 관광을 마친 뒤 저녁 전에 귀가할 수 있지만, 특별한 미식 경험이 있다면 저녁까지 머무를 가능성이 있는 관광객.
  - ※ 페르소나의 연령·여행 행동·체류 의향은 현재 가정이며, 추후 관광 데이터와 설문으로 검증한다.
- **페르소나 (초안):** 수도권 20~30대 커플·친구 - KTX로 동대구역 도착, 여행에서 음식을 중요하게 여기고 SNS로 코스를 저장, 당일치기로 왔다가 저녁 전에 돌아가곤 함
- **스토리보드 행동유도:** 코스 저장 → 대구 방문 및 낮 관광 → 치킨 저녁 코스 참여(패스·스탬프) → 저녁까지 체류 후 귀가

## 1. 현재 방향 (2026.11.5 기준)

**한 줄:** 낮은 대구 여행, 저녁은 치킨이 붙잡는다.

| 항목 | 내용 |
|---|---|
| 문제 | 대구 평균 체류시간 2022→2025년 −17.2% (전국 평균 −9.3%), 한국관광데이터랩 |
| 목표 | 대구 관광객의 체류시간 확대 — ① 당일 관광객을 저녁까지 ② 원거리 관광객은 숙박까지 |
| 하루 구조 | 낮: 중구·동구 관광지 (닭 관련 체험이 가능하면 우선) → 저녁: 평화시장 닭똥집골목 + 치맥 → 근거리는 귀가 / 원거리는 야경·숙박·다음 날 오전 |
| 타깃 | 거리(근거리 당일 / 원거리 1박) × 동행(커플·친구 / 가족) = **4개 코스**. 가족 코스는 술 없이 |
| 검증 범위 | 중구(동성로·근대골목·서문시장), 동구(평화시장·동촌유원지·땅땅치킨랜드 일대) |
| 검증 방법 | A/B 설문 — 낮 관광만 vs 낮 관광 + 치킨 저녁. 저녁까지 남을 의향·숙박 의향을 조합별로 비교 |

**방향 문서 이력**

| 판 | 날짜 | 핵심 |
|---|---|---|
| ver3 | 11/3~4 | 원문 확인으로 수치 수정 (낮 커피·베이커리 + 밤 치킨 → 폐기) |
| ver4 | 11/4 | '치킨 하루'(체험 → 닭똥집골목 → 치맥·야경), 거리·동행별 4개 코스 |
| ver5 | 작성 중 | 11/5 논의로 '낮 대구 여행 + 저녁 치킨'으로 수정 |

## 4. 작업 방법

1. 각자 **본인 이름 브랜치**에서 작업합니다 (`신민지`, `이예진`, …).
2. 작업 전 본인 브랜치와 main의 최신 내용을 받습니다.
3. 커밋 메시지는 `종류: 무엇을 바꿨는지` (`docs:` 문서 · `fix:` 오류 수정 · `feat:` 기능).
4. main 반영은 PR → 검토자 승인 → merge.
5. 공용 파일(`CLAUDE.md` · `keyword_map.md` · `sources.md` · `crosscheck.md` · `data_spec.md`)은 수정 전에 팀에 알립니다.

**자료 기준:** 공식·통계 자료를 우선하고, 기사 속 숫자는 원출처를 찾아 확인합니다. "대구는 치킨 도시"는 우리 말로 쓰지 않고 정부 자료의 사실만 인용합니다. 자세한 기준은 `CLAUDE.md` 5장.
